# Math 9 — Prerequisite Skills by Topic

*Maps the basic skills students need before each notes package. Designed to drive a practice web app that generates targeted warm-up problems.*

---

## Cross-Cutting Foundations

These skills appear as prerequisites across many topics. The app should be able to generate problems for each.

| Skill cluster | Used by |
|---|---|
| Fraction operations (simplify, LCD, +/−/×/÷) | Rational Numbers, Probability, Circle Geometry, Measurement |
| Negative number operations (+/−/×/÷) | Rational Numbers, Powers, Linear Equations, Polynomials |
| Order of operations (BEDMAS) | Powers, Polynomials, Linear Equations, Rational Numbers |
| Coordinate plane (plot points, read coordinates) | Linear Relations, Linear Equations, Statistics |
| Pythagorean theorem (a² + b² = c²) | Square Roots, Circle Geometry, Measurement |
| Distributive property: a(b + c) = ab + ac | Polynomials, Linear Equations |
| Area formulas (rectangle, triangle, circle, parallelogram) | Measurement, Similarity |
| Exponent rules (product, quotient, power of a power) | Powers, Polynomials, Square Roots |

## 1. Rational Numbers

### Pre-knowledge skills
- Identify integers on a number line (positive, negative, zero)
- Read and write fractions (numerator / denominator)
- Find equivalent fractions (multiply or divide both parts by the same number)
- Find least common denominator (LCM of two denominators)
- Compare and order positive fractions (e.g., which is larger: 3/5 or 2/3?)
- Convert a terminating decimal to a fraction (0.75 = 75/100 = 3/4)
- Plot positive fractions on a number line

### Vocabulary assumed
integer, fraction, numerator, denominator, equivalent, absolute value, decimal (terminating)

### Common gaps
- Reversing comparison logic for negatives: thinks −3/4 > −1/4 because 3/4 > 1/4
- Cannot place negative fractions on a number line
- Confuses "opposite" with "absolute value"

### Problem types for the app
1. Place a negative fraction on a number line
2. Compare two negative fractions (which is greater?)
3. Find an equivalent fraction
4. Find the LCD of two fractions
5. Convert a decimal to a fraction

## 2. Square Roots

### Pre-knowledge skills
- Know perfect squares from 1² to 12² by recall
- Evaluate simple exponents (e.g., 5² = 25)
- Multiply two-digit numbers (e.g., 11 × 11)
- Find the area of a square given a side length
- Identify the hypotenuse of a right triangle
- Apply Pythagorean theorem: a² + b² = c²
- Plot points on a coordinate plane

### Vocabulary assumed
perfect square, exponent, base, power, right angle, hypotenuse, legs

### Common gaps
- Thinks √9 = ±3 (confuses principal root with ± notation)
- Writes √2 = 1.414 with equals sign instead of ≈
- Tries to distribute: √(a + b) = √a + √b
- Thinks √(−16) = −4

### Problem types for the app
1. Name the perfect square (e.g., "What is 7²?")
2. Find the square root of a perfect square
3. Identify which two perfect squares a number falls between (e.g., √30 is between __ and __)
4. Find the missing side of a right triangle (given two sides)
5. Find the area of a square given a side, or the side given an area

## 3. Powers & Exponents

### Pre-knowledge skills
- Write repeated multiplication in exponent form (3 × 3 × 3 × 3 = 3⁴)
- Evaluate simple powers (2⁵, 10³)
- Multiply and divide whole numbers
- Apply order of operations (BEDMAS)
- Understand positive and negative integers
- Distinguish (−3)² from −3²

### Vocabulary assumed
base, exponent, power, product, factor, repeated multiplication

### Common gaps
- Confuses exponent with multiplication: thinks 3⁴ = 3 × 4 = 12
- Miscounts factors: thinks 2⁴ = 8 (only three 2s)
- Inconsistent with negative bases: (−2)³ vs −2³
- Applies exponent rules incorrectly: 2³ × 2⁴ = 2¹²

### Problem types for the app
1. Write repeated multiplication as a power
2. Evaluate a power (positive base)
3. Evaluate a power (negative base, with and without brackets)
4. Apply order of operations with exponents
5. Multiply/divide whole numbers (fluency)

## 4. Linear Relations

### Pre-knowledge skills
- Plot ordered pairs (x, y) on a coordinate plane
- Read coordinates from a graph
- Complete a table of values given a rule
- Recognize a constant difference in a sequence (e.g., 3, 7, 11, 15 → +4)
- Add, subtract, multiply with negative numbers
- Distinguish between input (independent) and output (dependent) variables

### Vocabulary assumed
coordinates, x-axis, y-axis, origin, ordered pair, table of values, variable, constant, pattern

### Common gaps
- Cannot identify the constant rate of change from a table
- Confuses slope (m) with y-intercept (b)
- Thinks "steeper = larger slope" without considering negatives
- Plots points with axes reversed (x on y, y on x)

### Problem types for the app
1. Plot a point given coordinates
2. Read coordinates from a plotted point
3. Find the pattern rule from a sequence (constant difference)
4. Complete a table of values given a rule like y = 2x + 1
5. Identify the independent and dependent variable in a scenario

## 5. Linear Equations

### Pre-knowledge skills
- Solve one-step equations: x + 5 = 12, 3x = 21
- Solve two-step equations: 2x + 3 = 11
- Add and subtract negative numbers
- Multiply and divide negative numbers
- Understand inverse operations (+ ↔ −, × ↔ ÷)
- Apply order of operations
- Understand that = means both sides are balanced

### Vocabulary assumed
equation, variable, solution, inverse operation, balance, isolate

### Common gaps
- Doesn't reverse inequality sign when multiplying/dividing by negative
- Adds/subtracts from only one side
- Cannot handle variables on both sides (5x − 3 = 2x + 9)
- Assumes every equation has exactly one solution

### Problem types for the app
1. Solve a one-step equation (addition/subtraction)
2. Solve a one-step equation (multiplication/division)
3. Solve a two-step equation
4. Evaluate an expression for a given value of x
5. Identify the inverse operation
6. Add/subtract/multiply/divide negative numbers

## 6. Polynomials

### Pre-knowledge skills
- Understand variable notation: 3x means 3 × x
- Identify like terms (3x and 5x are like; 3x and 3x² are not)
- Apply exponent rules: x² × x³ = x⁵
- Apply distributive property: a(b + c) = ab + ac
- Add and subtract positive and negative integers
- Multiply monomials: 3x × 2x = 6x²

### Vocabulary assumed
term, variable, coefficient, constant, exponent, degree, like terms, simplify

### Common gaps
- Combines unlike terms: 3x + 4x² = 7x²
- Confuses coefficient with degree: "2x³ has degree 2"
- Thinks x × x = 2x (confuses multiplication with addition)
- Doesn't distribute the negative: −(x² − 2x) = −x² − 2x instead of −x² + 2x
- Misses middle terms in FOIL: (x + 2)(x + 3) = x² + 6

### Problem types for the app
1. Identify the coefficient, variable, and degree of a term
2. Sort terms into like/unlike groups
3. Multiply monomials (e.g., 4x × 3x²)
4. Apply the distributive property
5. Add and subtract integers (fluency with negatives)
6. Evaluate x × x vs x + x

## 7. Circle Geometry

### Pre-knowledge skills
- Name parts of a circle: center, radius, diameter, chord
- Know that diameter = 2 × radius
- Measure line segments with a ruler
- Measure angles with a protractor
- Know angle sum in a triangle = 180°
- Identify a right angle (90°)
- Apply Pythagorean theorem: a² + b² = c²
- Understand perpendicular (meets at 90°)

### Vocabulary assumed
circle, center, radius, diameter, chord, arc, perpendicular, right angle, degrees, protractor

### Common gaps
- Thinks a chord is the same as a diameter
- Doesn't know that a longer chord is closer to the center (inverse relationship)
- Confuses inscribed angle = 90° as true for all inscribed angles (only for semicircles)
- Misidentifies hypotenuse in chord-radius-distance triangles

### Problem types for the app
1. Find the radius given the diameter (and vice versa)
2. Measure an angle with a protractor (image-based or estimate)
3. Find the missing angle in a triangle
4. Apply Pythagorean theorem to find a missing side
5. Identify parts of a circle from a diagram

## 8. Surface Area & Volume (Measurement)

### Pre-knowledge skills
- Calculate area of a rectangle: A = l × w
- Calculate area of a triangle: A = ½bh
- Calculate area of a circle: A = πr²
- Calculate circumference: C = 2πr
- Understand perimeter vs area
- Name 3D shapes: rectangular prism, cylinder, triangular prism, cone, sphere
- Convert between units (cm ↔ m, mm ↔ cm)
- Apply Pythagorean theorem for slant height

### Vocabulary assumed
area, perimeter, surface area, volume, face, edge, base, height, radius, diameter, net, composite shape

### Common gaps
- Confuses surface area with volume
- Misses faces when unfolding composite shapes
- Uses perimeter formula where area is needed
- Doesn't convert units before calculating
- Forgets to include both bases of a prism

### Problem types for the app
1. Find the area of a rectangle
2. Find the area of a triangle
3. Find the area of a circle (given radius or diameter)
4. Find the circumference of a circle
5. Convert between cm, m, mm
6. Name the 3D shape from a description

## 9. Similarity & Scale

### Pre-knowledge skills
- Write a ratio in a:b and a/b form
- Solve a proportion using cross-multiplication
- Find a scale factor: new ÷ original
- Identify corresponding sides and angles in two shapes
- Measure sides and angles of polygons
- Understand that congruent = same shape AND same size

### Vocabulary assumed
ratio, proportion, scale factor, similar, congruent, corresponding, enlargement, reduction

### Common gaps
- Thinks "similar" means "identical" (confuses with congruent)
- Writes scale factor backwards (original ÷ new)
- Assumes only one condition needed (equal angles OR proportional sides)
- Interprets scale factor < 1 as enlargement instead of reduction

### Problem types for the app
1. Write a ratio from a word problem
2. Solve a proportion (cross-multiply)
3. Find the scale factor between two similar figures
4. Determine if a scale factor is an enlargement or reduction
5. Find a missing side using a proportion

## 10. Statistics & Scatter Plots

### Pre-knowledge skills
- Read and create a table of values
- Plot points on a coordinate plane
- Label axes with appropriate scales
- Know independent variable (x) vs dependent variable (y)
- Understand what data is (collected measurements/observations)
- Calculate mean of a data set
- Know median and mode

### Vocabulary assumed
data, variable, table, graph, axis, scale, mean, median, mode, sample, population

### Common gaps
- Plots scatter plot with axes reversed (dependent on x)
- Connects scatter plot dots with lines (it's not a line graph)
- Confuses no correlation with no relationship
- Believes correlation proves causation

### Problem types for the app
1. Plot a point on a coordinate plane
2. Read a coordinate from a graph
3. Calculate the mean of a small data set
4. Find the median of a data set
5. Identify independent vs dependent variable in a scenario

## 11. Probability

### Pre-knowledge skills
- List all outcomes of a simple event (coin flip, die roll, spinner)
- Count outcomes systematically
- Write a fraction from a count: favorable / total
- Convert between fractions, decimals, and percents
- Know that probability is always between 0 and 1
- Understand "equally likely" outcomes
- Simplify fractions

### Vocabulary assumed
outcome, event, sample space, favorable, possible, probability, fair, random, likely, unlikely

### Common gaps
- Thinks theoretical probability predicts exact short-run results
- Gambler's Fallacy: thinks past outcomes affect future independent events
- States probability > 1 or < 0
- Expects a short experiment to match theory exactly
- Doesn't check whether outcomes are equally likely before applying P = favorable/total

### Problem types for the app
1. List all outcomes for a simple event
2. Count favorable outcomes
3. Write a probability as a fraction
4. Convert a fraction to a decimal and percent
5. Simplify a fraction
6. Determine if outcomes are equally likely
