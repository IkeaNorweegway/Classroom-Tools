::: tip
**For the adult:** Trace code one line at a time and write down what each variable holds. In code, = means "store this value", not "is equal to".
:::

## Worked example

::: example
**What does this Python code print?**
x = 5
x = x + 3
print(x)

1. Line 1: x stores 5.
2. Line 2: take x (5), add 3, store it back in x. Now x is 8.
3. Line 3: print shows 8.
:::
