## Step 1: Define the Brief

**The brief:** Build a choose-your-own-adventure story or simple game (your choice of format) in Scratch, with multiple branch points, a defined set of real endings, and at least one instance of an earlier choice affecting a later scene through a variable.

Format: ☐ Story ☐ Simple game

Two requirements that apply either way:
- Every path must reach a **real, distinct ending** — no dead ends, no path that loops forever
- At least one **earlier choice affects a later outcome**, using a variable

What does "done" look like — what would need to be true for someone playing it for the first time to reach a real ending, no matter which path they take?
