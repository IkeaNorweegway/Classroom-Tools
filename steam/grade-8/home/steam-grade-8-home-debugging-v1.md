::: tip
**For the adult:** Good debugging is a method, not guessing: make the bug happen, find where it goes wrong, change one thing, and test.
:::

## Worked example

::: example
**In a game, the character falls straight through a platform. Debug it.**

1. Make the bug happen again, so you can watch it.
2. Find the code that checks whether the character is touching the platform.
3. Change one thing, like stopping the fall when it touches the platform.
4. Test again. If it isn’t fixed, undo that change and try the next idea.
:::
