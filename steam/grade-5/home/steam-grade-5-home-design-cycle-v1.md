::: tip
**For the adult:** Change only one thing at a time when testing. That’s how your child learns what actually made the difference.
:::

## Worked example

::: example
**A paper airplane only flies 2 metres. Use the design cycle to improve it.**

1. Plan: choose one thing to change, like making the wings bigger.
2. Build: make that one change.
3. Test: throw it the same way three times and measure each flight.
4. Improve: keep the change if it helped, then try the next idea.
:::
