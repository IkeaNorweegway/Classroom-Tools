::: tip
**For the adult:** An algorithm is a set of exact steps. Try following your child’s steps literally, like a robot would. It’s fun, and it shows where steps are too vague.
:::

## Worked example

::: example
**Write an algorithm to move a robot three squares forward, turn right, then move one square.**

1. Sequence: forward, forward, forward, turn right, forward.
2. Loop: the first three steps repeat, so write "repeat 3 times: forward".
3. Shorter version: repeat 3 times: forward; turn right; forward.
:::
