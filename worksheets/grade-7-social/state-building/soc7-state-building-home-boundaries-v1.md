::: tip
**For the adult:** In 1867 Canada had only four provinces. The rest joined one at a time. Your child is practising putting events in order and asking *why* the map changed at each step.
:::

## Worked example

::: example
**Which joined first, British Columbia or Alberta? Why?**

1. Find each year: British Columbia joined in **1871**; Alberta became a province in **1905**.
2. The smaller year is earlier, so **British Columbia** joined first.
3. Ask why: BC joined because Canada promised a railway to the Pacific. Alberta was created once enough settlers had arrived by that railway.
:::
