::: tip
**For the adult:** Arrows point in the direction of the push or pull. Longer arrows mean bigger forces. Equal arrows in opposite directions are balanced.
:::

## Worked example

::: example
**A book sits still on a table. Draw the forces.**

1. Draw an arrow pointing down for gravity.
2. Draw an arrow pointing up for the table pushing back.
3. Make them the same length: the forces are balanced, so the book stays still.
:::
