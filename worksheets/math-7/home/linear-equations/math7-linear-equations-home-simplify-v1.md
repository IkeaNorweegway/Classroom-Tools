::: tip
**For the adult:** Like terms have the same letter part. Add their numbers: 2x + 3x = 5x. An x-term and a plain number never combine: 3x + 2 stays 3x + 2. With brackets, multiply the outside number by EVERY term inside: 2(x + 3) = 2x + 6.
:::

::: example
**Simplify 2(x + 3) + x.**
Step 1: 2(x + 3) is 2 groups of (x + 3). That is 2x + 6.
@viz tilerows rows="x;+3 | x;+3" labels="Group 1;Group 2" notes="x + 3;x + 3"
Step 2: Add the like terms: 2x + 6 + x = 3x + 6.
:::
