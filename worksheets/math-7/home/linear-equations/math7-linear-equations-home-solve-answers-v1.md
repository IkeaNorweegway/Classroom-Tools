::: tip
**For the adult:** The most common slips are doing a step to one side only, and "moving" a term across the = sign without changing its sign (4x + 1 = 2x + 7 is NOT 6x + 1 = 7). Subtract 2x from both sides instead.
:::

## Answers

**1.** x = 12 − 7 = **5**.

**2.** 2x = 8, so x = **4**. Check: 2(4) + 1 = 9. ✓

**3.** x = −1 + 4 = **3**.

**4.** 3x = −6, so x = **−2**. Check: 3(−2) + 5 = −1. ✓

**5.** Take 2x off both sides: 2x + 1 = 7. 2x = 6, so x = **3**. Check: 13 = 13. ✓
@viz tilerows rows="4x;+1 = 2x;+7"
**6.** 2x − 2 = 6. 2x = 8, so x = **4**. Check: 18 = 18. ✓

**7.** 10 + 3x = 16 + x. 2x = 6, so **3 GB**. Both cost $19.

**8.** Left: 2(2) + 5 = 9. Right: 4(2) − 1 = 7. Not equal, so **x = 2 is wrong**. Solve: 5 = 2x − 1, 6 = 2x, so **x = 3**. Check: 11 = 11. ✓
