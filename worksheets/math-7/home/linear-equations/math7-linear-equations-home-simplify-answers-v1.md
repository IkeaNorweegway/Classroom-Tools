::: tip
**For the adult:** The most common slips are 2x + 3x = 5x² (it is 5x), adding an x-term to a number (3x + 2 = 5x), and multiplying only the first term in brackets (2(x + 3) = 2x + 3).
:::

## Answers

**1.** 3x + 4x = **7x**.

**2.** 5x − 2x = 3x, so **3x + 3**.

**3.** 2x + 5 + x − 3 = **3x + 2**.
@viz tiles terms="2x;+5;x;-3" label="= [[3x + 2]]"
**4.** 2 × x + 2 × 5 = **2x + 10**.
@viz tilerows rows="x;+5 | x;+5" labels="Group 1;Group 2" notes=";2(x + 5) = [[2x + 10]]"
**5.** 3 × x − 3 × 4 = **3x − 12**.

**6.** −2 × x = −2x and −2 × 3 = −6, so **−2x − 6**.

**7.** 2x + 2 + 3x − 5 = **5x − 3**.

**8.** **No.** 3x and 2 are not like terms. 3x + 2 stays 3x + 2.
