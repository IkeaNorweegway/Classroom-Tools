::: tip
**For the adult:** A common slip is writing |−5| = −5. Absolute value is a distance, so it is never negative: |−5| = 5.
:::

## Answers

**1.** The opposite of −9 is **9**.

**2.** |−9| = **9** (9 steps from −9 to 0). |−3/4| = **3/4**.

**3.** **18** degrees. |−18| = 18.

**4.** **No.** Absolute value is the distance from 0. −5 is 5 steps from 0, and a distance can't be negative. So |−5| = 5.

**5.** The point is at **−2.5**.
@viz numberline min=-3 max=3 step=0.5 every=1 points="-2.5:[[−2.5]]" width=330
Opposite: **2.5**. Absolute value: **2.5**.

**6.** They are **1.5** and **−1.5**.
