::: tip
**For the adult:** Absolute value is the distance from 0, so it is never negative: |−4| = 4. The opposite is the same distance on the other side of 0: the opposite of −4 is 4.
:::

::: example
**Find the opposite of −3.5 and |−3.5|.**
@viz numberline min=-4 max=4 step=0.5 every=1 points="-3.5:;3.5:" jumps="-3.5>0>3.5" jumplabels="3.5 steps,3.5 steps" width=400
1. −3.5 is 3.5 steps left of 0. Its opposite is 3.5 steps right of 0: **3.5**.
2. The distance from 0 is 3.5. So |−3.5| = **3.5**.
:::
