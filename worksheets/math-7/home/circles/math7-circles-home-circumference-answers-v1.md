::: tip
**For the adult:** The most common slip is using the radius in C = 3.14 × d. If the radius is given, double it first. A quick check: the circumference is always a bit more than 3 diameters.
:::

## Answers

**1.** d = 2 × 9 = **18 cm**.

**2.** r = 14 ÷ 2 = **7 m**.

**3.** C ≈ 3.14 × 10 = **31.4 cm**.
@viz circle show=d dlabel="d = 10 cm" clabel="C ≈ [[31.4 cm]]" size=34
**4.** d = 2 × 30 = 60 cm. C ≈ 3.14 × 60 = **188.4 cm**.
@viz wheel dlabel="d = [[60 cm]]" clabel="one turn ≈ [[188.4 cm]]" size=22
**5.** d ≈ 62.8 ÷ 3.14 = **20 m**. Check: 3.14 × 20 = 62.8.

**6.** C ≈ 3.14 × 25 = 78.5. About **78.5 cm**.

**7.** **No.** C = 3.14 × d needs the diameter. d = 8 cm, so C ≈ 3.14 × 8 = 25.12, about **25.1 cm**.
