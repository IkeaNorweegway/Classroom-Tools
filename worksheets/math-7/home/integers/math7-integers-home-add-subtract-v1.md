::: tip
**For the adult:** Think of yellow chips as +1 and red chips as −1. A yellow and a red together make 0. To subtract, add the opposite: 7 − (−2) is the same as 7 + 2. "Two negatives make a positive" is only for × and ÷, so −3 + (−5) = −8.
:::

::: example
**Find −4 − (−6).**
Step 1: Show −4 with 4 red chips. We need to take away 6 red, so add 2 zero pairs. Take away 6 red.
@viz chips neg=4 add=2 xneg=6 result="−4 − (−6) = 2"
Step 2: Check with the rule. Add the opposite: −4 + 6 = 2.
:::
