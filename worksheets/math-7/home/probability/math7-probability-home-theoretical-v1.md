::: tip
**For the adult:** A probability is a number from 0 (impossible) to 1 (certain). When every outcome has the same chance: **P = favourable outcomes ÷ all outcomes**. It can be written as a fraction, a decimal or a percent: 1/2 = 0.5 = 50%.
:::

::: example
**A bag has 3 red counters and 1 blue counter. Find P(red).**
@viz bag counters="red:3;blue:1" out="?" outlabel="draw one"
Step 1: All the counters: 3 + 1 = 4. Red ones: 3.
Step 2: P(red) = 3/4 = 3 ÷ 4 = 0.75 = 75%.
:::
