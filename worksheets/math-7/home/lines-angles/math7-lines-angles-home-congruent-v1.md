::: tip
**For the adult:** Congruent shapes are the same size and shape. One fits exactly on the other, even if it is turned or flipped. In △ABC ≅ △RST, the letter order shows which parts match: A with R, B with S, C with T. Matching ticks show equal sides. Matching arcs show equal angles.
:::

::: example
**△ABC ≅ △RST. Find RS and ∠S.**
@viz polygon pts="0,0;6,0;2,3" names="A,B,C" sides="6 cm;;" angles=";37°;" ticks="1,0,0" arcs="0,1,0" pts2="0,0;6,0;2,3" names2="R,S,T" ticks2="1,0,0" arcs2="0,1,0" unit=20
Step 1: Match by position in the name. R is 1st, like A. S is 2nd, like B. So RS matches AB.
Step 2: RS = AB = 6 cm. ∠S matches ∠B, so ∠S = 37°. The marks agree: one tick, one arc.
:::
