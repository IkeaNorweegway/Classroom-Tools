## Core

### Simplify 4x + 2x and 4x + 2. Noor says 4x + 2x = 6x². Ben says 4x + 2 = 6x. Fix both mistakes.
@viz tiles terms="4x;2x" label="4x + 2x"
@viz tiles terms="4x;+2" label="4x + 2"
(lines 3)
=> 4x + 2x = 6x. Add the coefficients only. Six x tiles are 6x, not 6x². (LE1)
=> 4x + 2 stays 4x + 2. An x-term and a number are not like terms. Targets the "2x + 3x = 5x²" and "3x + 2 = 5x" mix-ups.

### Simplify.
a) 3(x + 2)
b) −2(x − 4)
c) 2(x − 3) + 5x − 1
@viz tilerows rows="x;+2 | x;+2 | x;+2" labels="Group 1;Group 2;Group 3" notes=";;3(x + 2) = [[3x + 6]]"
(work 3)
=> a) 3 × x + 3 × 2 = 3x + 6. (LE1)
=> b) −2 × x = −2x and −2 × (−4) = +8. So −2x + 8.
=> c) 2x − 6 + 5x − 1. Like terms: 2x + 5x = 7x and −6 − 1 = −7. So 7x − 7.

### Leo writes 4(x + 5) = 4x + 5. Look at the groups. Fix his mistake.

### Solve.
a) x − 6 = −2
b) −5x = 20
c) 2(x + 3) = 4
@viz tilerows rows="x;-6 = -2" labels="a)"

### Which equations are equivalent to 4x + 2 = 10? Write yes or no. Say what was done to both sides.
a) 4x = 8
b) 4x = 12
c) 2x + 1 = 5
d) 5x + 2 = x + 10
@viz balance left="4x;+2" right="+10"
(lines 3)
=> a) Yes: − 2 on both sides. (LE2)
=> b) No: 2 was added to the right side only. (4x = 12 gives x = 3, but 4x + 2 = 10 gives x = 2.)
=> c) Yes: ÷ 2 on both sides.
=> d) Yes: + x on both sides.

### Solve 5x + 3 = 2x + 15.
@viz balance left="5x;+3" right="2x;+15"
(work 3)
=> Subtract 2x from both sides: 3x + 3 = 15. (LE3)
=> Subtract 3 from both sides: 3x = 12. Divide by 3: x = 4.
=> Check: 5(4) + 3 = 23 and 2(4) + 15 = 23. ✓

### Zoe solves 5x + 1 = 2x + 13. Her first step is 7x + 1 = 13. Fix her mistake. Then solve.
@viz tilerows rows="5x;+1 = 2x;+13"
(work 3)
=> She moved 2x and kept its sign. Subtract 2x from BOTH sides: 5x − 2x + 1 = 13, so 3x + 1 = 13. (LE3)
=> 3x = 12. x = 4. Check: 5(4) + 1 = 21 and 2(4) + 13 = 21. ✓ Targets the "move a term across and keep its sign" mix-up.

### Solve 4x + 9 = x − 3. Verify your answer.
(work 3)
=> Subtract x from both sides: 3x + 9 = −3. Subtract 9: 3x = −12. Divide by 3: x = −4. (LE3)
=> Verify: 4(−4) + 9 = −16 + 9 = −7. −4 − 3 = −7. ✓ (LE4)

### Omar solves 2(x + 4) = x + 10. His first step is 2x + 4 = x + 10. He gets x = 6. He checks 2(6) + 4 = 16 and 6 + 10 = 16. Is x = 6 right?
(lines 3)
=> No. Check in the ORIGINAL: 2(6 + 4) = 20, but 6 + 10 = 16. Not equal. (LE4)
=> His first step is wrong: 2(x + 4) = 2x + 8. Then 2x + 8 = x + 10, so x = 2. Check: 2(6) = 12 and 2 + 10 = 12. ✓
=> Targets the "it works in my last equation, so it is right" mix-up.

### Plan A costs $15 a month plus $4 for each GB. Plan B costs $27 a month plus $1 for each GB. When do they cost the same?
@viz balance left="4x;+15" right="x;+27" caption="Each bag is one GB."
(work 3)
=> Let x = the number of GB. 15 + 4x = 27 + x. (LE4)
=> Subtract x: 15 + 3x = 27. Subtract 15: 3x = 12. x = 4.
=> Verify: 15 + 4(4) = 31 and 27 + 4 = 31. Both plans cost $31 for 4 GB.

### Solve 3(x − 2) = x + 4. Verify in the original equation and in one equivalent equation.
@viz balance left="x;-2;x;-2;x;-2" right="x;+4" text="3(x − 2) = x + 4"
(work 3)
=> 3x − 6 = x + 4. Subtract x: 2x − 6 = 4. Add 6: 2x = 10. x = 5. (LE3)
=> Original: 3(5 − 2) = 9 and 5 + 4 = 9. ✓ Equivalent: 2(5) − 6 = 4. ✓ (LE4)

### Solve 2(x − 3) = 4(x + 1).

=> Check: 2(−8) = −16 and 4(−4) = −16. ✓

### Sunpeak costs a $90 card plus $30 a day. Pine Ridge costs $60 a day.
a) After how many days do they cost the same?
b) Mia skis 5 days. Which hill is cheaper? By how much?
@viz flow steps="Let x = days|Sunpeak: 90 + 30x|Pine Ridge: 60x|90 + 30x = 60x"
(work 3)
=> a) 90 + 30x = 60x. Subtract 30x: 90 = 30x. x = 3 days. Check: 90 + 90 = 180 and 60(3) = 180. ✓ (LE4)
=> b) Sunpeak: 90 + 150 = $240. Pine Ridge: 60(5) = $300. Sunpeak is $60 cheaper.

### A chinook comes to Lethbridge. It is −11 °C and warms 4 °C each hour. Red Deer is −2 °C and warms 1 °C each hour. When are they the same? What is the temperature then?
@viz thermo min=-15 max=5 step=5 values="-11,-2" labels="Lethbridge;Red Deer"
(work 3)
=> Let x = hours. −11 + 4x = −2 + x. Subtract x: −11 + 3x = −2. Add 11: 3x = 9. x = 3 hours. (LE4)
=> −11 + 12 = 1 °C and −2 + 3 = 1 °C. Both are 1 °C.

### A rectangle is x + 3 long and x wide. A triangle has three sides of x + 4. They have the same perimeter. Find the perimeter.
@viz polygon pts="0,0;4.5,0;4.5,3;0,3" sides="x + 3;x;x + 3;x" pts2="0,0;3.6,0;1.8,3.1" sides2="x + 4;x + 4;x + 4" ticks2="1,1,1" unit=28
(work 3)
=> Rectangle: 2(x + 3) + 2x = 4x + 6. Triangle: 3(x + 4) = 3x + 12. (LE4)
=> 4x + 6 = 3x + 12. x = 6. Rectangle: 9 + 6 + 9 + 6 = 30. Triangle: 10 + 10 + 10 = 30. The perimeter is 30.
