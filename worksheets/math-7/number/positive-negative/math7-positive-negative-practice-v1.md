## Core

### Read each thermometer. How far is each temperature from 0 °C?
@viz thermo min=-20 max=15 step=5 values="-15,10,-5" labels="A;B;C"
A = [[−15 °C]], [[15]] degrees from 0
B = [[10 °C]], [[10]] degrees from 0
C = [[−5 °C]], [[5]] degrees from 0
=> A is −15 °C. |−15| = 15, so it is 15 degrees from 0. (PN1)
=> B is 10 °C. |10| = 10. C is −5 °C. |−5| = 5.

### Find each one.
a) |−8| = [[8]]
b) |8| = [[8]]
c) |−0.6| = [[0.6]]
d) |−{2/3}| = [[{2/3}]]
e) the opposite of −11 = [[11]]
f) the opposite of 4.25 = [[−4.25]]
=> Absolute value is the distance from 0, so it is never negative. (PN1)

### Circle every number that sits at the same point as −{2/5}.

@viz numberline min=-1 max=1 step=0.2

### Change each fraction to a decimal. Change each decimal to a fraction in simplest form.
a) {3/5} = [[0.6]]
b) −{1/4} = [[−0.25]]
c) −{3/8} = [[−0.375]] (use a calculator)
d) 0.8 = [[{4/5}]]
e) −0.25 = [[−{1/4}]]
f) −0.06 = [[−{3/50}]]
=> a) {3/5} = {6/10} = 0.6. b) {1/4} = {25/100} = 0.25, so −{1/4} = −0.25. c) 3 ÷ 8 = 0.375, so −{3/8} = −0.375. (PN3)

|---|---|
| Dead Sea shore | about −0.43 |
| Death Valley | −0.086 |
| Lowest point in the Netherlands | −0.007 |
| Edmonton | about 0.645 |
| Lake Louise | about 1.75 |
@viz vline min=-0.5 max=2 step=0.25 every=0.5 unit=" km" zero="sea level" water=1 height=240 width=300
Which place is closest to sea level? Use absolute value.
(work 3)
=> Order: −0.43 (Dead Sea shore), −0.086 (Death Valley), −0.007 (Netherlands), 0.645 (Edmonton), 1.75 (Lake Louise). (PN4)
=> Closest to sea level: the Netherlands point. |−0.007| = 0.007 is the smallest absolute value.

### Always, sometimes or never? Explain each one.
a) The absolute value of a number is positive.
b) A number and its opposite have the same absolute value.
c) The opposite of a number is negative.
(work 3)
=> a) Sometimes. |0| = 0, and 0 is not positive. Every other absolute value is positive. (PN1)
=> b) Always. Opposites are the same distance from 0.
=> c) Sometimes. The opposite of 5 is −5 (negative), but the opposite of −5 is 5 (positive).

### A diver is at −4.5 m. A bird is at 3.5 m. How far apart are they?
@viz vline min=-6 max=6 step=1 every=2 unit=" m" zero="sea level" water=1 height=200 width=280 points="3.5:bird;-4.5:diver"
(work 2)
=> The diver is |−4.5| = 4.5 m below sea level. The bird is |3.5| = 3.5 m above. (PN1)
=> They are on different sides of 0, so add the distances: 4.5 + 3.5 = 8 m apart.
