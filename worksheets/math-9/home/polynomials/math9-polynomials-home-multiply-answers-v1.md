::: tip
**For the adult:** Four cells means four terms before combining. If an answer has only two terms, a cell was probably missed.
:::

**1.** x², 5x, x, 5: **x² + 6x + 5**

**2.** **6x² − 12x**

**3.** x² + 7x + 3x + 21 = **x² + 10x + 21**

**4.** x² + 2x − 5x − 10 = **x² − 3x − 10**

**5.** 2x² − 6x + x − 3 = **2x² − 5x − 3**

**6.** (x + 2)(x + 3) = **x² + 5x + 6** square metres
