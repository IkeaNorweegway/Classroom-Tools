::: tip
**For the adult:** Only like terms combine: x² terms with x² terms, x terms with x terms, numbers with numbers. When subtracting a bracket, every sign inside it flips.
:::

## Worked example

::: example
**Simplify (4x² − x + 3) − (x² − 5x + 7).**

1. Subtracting a bracket: flip every sign inside. 4x² − x + 3 − x² + 5x − 7
2. Group like terms: (4x² − x²) + (−x + 5x) + (3 − 7)
3. Combine: 3x² + 4x − 4
:::
