**For the adult:** Finding the hypotenuse means adding the squares. Finding a leg means subtracting them.
:::

**1.** 36 + 64 = 100, so c = √100 = **10 cm**

**2.** 169 − 25 = 144, so a = √144 = **12 cm**

**3.** 81 + 144 = 225, so c = **15 m**

**4.** 100 − 36 = 64, so a = **8 cm**

**5.** 9 + 25 = 34, so c = √34 ≈ **5.8 cm**

**6.** 48² + 27² = 2304 + 729 = 3033
- √3033 ≈ 55.07, so about **55 inches**
