## Worked example

::: example
**Solve 5x − 3 = 2x + 9.**

1. Subtract 2x from both sides, so x is on one side only: 3x − 3 = 9
2. Add 3 to both sides: 3x = 12
3. Divide both sides by 3: x = 4
4. Check: 5(4) − 3 = 17 and 2(4) + 9 = 17. Both sides match. ✓
:::
