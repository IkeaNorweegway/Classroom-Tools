::: tip
**For the adult:** Inequalities are solved like equations, with one extra rule: multiplying or dividing both sides by a negative number flips the sign. Ask your child to test one number from their answer in the original question.
:::

## Worked example

::: example
**Solve −3x + 4 ≤ 19 and show it on a number line.**

1. Subtract 4 from both sides: −3x ≤ 15
2. Divide both sides by −3. It's a negative, so flip the sign: x ≥ −5
3. Test a number from the answer, like x = 0: −3(0) + 4 = 4, and 4 ≤ 19. ✓
4. Number line: a filled-in dot at −5 (≤ includes −5) and an arrow to the right.
:::
