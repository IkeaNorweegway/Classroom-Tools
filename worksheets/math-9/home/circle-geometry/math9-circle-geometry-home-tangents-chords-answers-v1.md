::: tip
**For the adult:** In every question the radius (or the distance to the centre) is the hypotenuse, because it sits across from the right angle.
:::

**1.** Half chord 4. d² = 25 − 16 = 9, so **d = 3 cm**

**2.** Angle OPT = **90°**. OT² = 36 + 64 = 100, so **OT = 10 cm**

**3.** Half chord 15. d² = 289 − 225 = 64, so **d = 8 cm**

**4.** Tangent² = 26² − 10² = 676 − 100 = 576, so the tangent is **24 cm**

**5.** Half chord² = 25² − 7² = 625 − 49 = 576, half chord = 24, so the chord is **48 cm**

**6.** Half² = 60² − 40² = 3600 − 1600 = 2000, half ≈ 44.7
- The board over the table is about 2 × 44.7 ≈ **89 cm**
