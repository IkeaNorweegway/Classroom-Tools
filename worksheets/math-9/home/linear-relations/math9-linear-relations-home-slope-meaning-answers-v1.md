::: tip
**For the adult:** Direct variation lines start at zero; partial variation lines start somewhere else.
:::

**1.** Joining fee **$50**, **$20** per month, 6 months: 20(6) + 50 = **$170**

**2.** **$16** per hour, **$0** for 0 hours, **direct variation** (it starts at zero)

**3.** **H = −2t + 30**
- The negative slope means the candle gets 2 cm **shorter** each hour.

**4.** **C = 2.5d + 4**
- 10 km: 2.5(10) + 4 = **$29**

**5.** 200 minutes: A = $30, B = $35, so **Plan A** is cheaper.
- 400 minutes: A = $50, B = $45, so **Plan B** is cheaper.

**6.** **(a) and (c)** are direct variation.
- They have no added number, so they start at zero. (b) starts at 2.
