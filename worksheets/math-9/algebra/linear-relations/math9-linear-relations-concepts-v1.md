# Linear Relations — Concept Summary
Grade 9 Mathematics · Alberta Curriculum

---

## Key Vocabulary

| Term | Meaning | Example |
|---|---|---|
| Linear relation | A relationship where equal changes in x produce equal changes in y | y = 3x + 2 |
| Slope (m) | Rate of change; steepness and direction of a line | m = rise/run |
| y-intercept (b) | Where the line crosses the y-axis (x = 0) | In y = 2x + 5, b = 5 |
| x-intercept | Where the line crosses the x-axis (y = 0) | Set y = 0 and solve |
| Direct variation | Linear relation with y-intercept = 0; passes through origin | y = kx |
| Partial variation | Linear relation with non-zero y-intercept | y = kx + b |
| Rate of change | How much y changes per unit increase in x; same as slope | $50/hour → m = 50 |

---

## Key Formulas

**Slope from two points:**

m = (y₂ − y₁) / (x₂ − x₁)

**Slope-intercept form:**

y = mx + b &nbsp;&nbsp; where m = slope and b = y-intercept

**Finding the equation given slope and a point (x₁, y₁):**

Substitute into y = mx + b and solve for b.

---

## The Rule of Four

Every linear relation can be shown four ways:

| Form | What it looks like |
|---|---|
| **Verbal** | "Starting at 8, increasing by 3 each time x increases by 1" |
| **Table** | x: 0, 1, 2, 3 → y: 8, 11, 14, 17 |
| **Equation** | y = 3x + 8 |
| **Graph** | Straight line, y-intercept 8, slope 3 |

---

## Worked Example 1 — Find slope and equation

**Two points: (1, 3) and (4, 12)**

> Slope: m = (12 − 3)/(4 − 1) = 9/3 = **3**
>
> Equation: Use y = mx + b → 3 = 3(1) + b → b = **0**
>
> Equation: **y = 3x** (direct variation — passes through origin)

---

## Worked Example 2 — Partial variation from context

**A plumber charges $80 call-out + $60/hour.**

> Starting value (b) = **80** (paid even with 0 hours)
>
> Rate of change (m) = **60** (per hour)
>
> Equation: **C = 60h + 80**
>
> Type: partial variation (y-intercept ≠ 0)

---

## Common Mistakes

| Mistake | Fix |
|---|---|
| y-intercept = where line crosses the x-axis | y-intercept is where it crosses the **y-axis** (at x = 0) |
| Slope is always positive | Slope is negative when the line falls left to right |
| Slope changes depending on which points you pick | Slope is constant on a straight line — any two points give the same m |
| y = 3x is partial variation | y = kx with no constant is **direct** variation (passes through origin) |
