**1.** Evaluate — rational or irrational?

| Expression | Value | Rational or irrational? |
|---|---|---|
| √64 | **8** | Rational (8 = 8/1) |
| √50 | **≈ 7.07 (irrational)** | Irrational (50 not a perfect square) |
| −√81 | **−9** | Rational (−9 = −9/1; negative in front, not inside) |
| √(4/25) | **2/5** | Rational (2/5 is a fraction of integers) |
| √(−9) | **Undefined** (no real solution) | Neither — not a real number |
| √(0.04) | **0.2** | Rational (= √(4/100) = 2/10) |

*Common mistake on √(−9):* A negative radicand has no real square root. Don't confuse with −√9 = −3 (which is defined).

**3.** Estimating square roots

**(a) √28**

> 5² = 25 < 28 < 36 = 6²
> So **5 < √28 < 6**
> 28 is closer to 25 (distance 3) than to 36 (distance 8)
> **√28 ≈ 5.3**

**(b) √63**

> 7² = 49 < 63 < 64 = 8²
> So **7 < √63 < 8**
> 63 is very close to 64 (distance 1)
> **√63 ≈ 7.9**

**(c) √95**

> 9² = 81 < 95 < 100 = 10²
> So **9 < √95 < 10**
> 95 is closer to 100 (distance 5) than to 81 (distance 14)
> **√95 ≈ 9.7**

**Number line:** √28 ≈ 5.3 | √63 ≈ 7.9 | √95 ≈ 9.7

**5.** Pythagorean theorem

**(a) Legs 6 cm and 8 cm — find hypotenuse**

> a² + b² = c²
> 6² + 8² = c²
> 36 + 64 = c²
> c² = 100
> **c = 10 cm**

*(3-4-5 triple × 2 — recognizing this saves work)*

**(b) Hypotenuse 17 m, leg 8 m — find other leg**

> 8² + b² = 17²
> 64 + b² = 289
> b² = 225
> **b = 15 m**

*(8-15-17 is a Pythagorean triple)*

**(c) Check: 9, 40, 41**

> 9² + 40² = 81 + 1600 = **1681**
> 41² = **1681**
> Equal ✓ → **Yes, right angle**

**6.** Rational or irrational?

**(a) √100**

> **Rational** — because √100 = 10, and 10 is an integer (expressible as 10/1)

**(b) √2**

> **Irrational** — because 2 is not a perfect square; its decimal expansion (1.41421...) never terminates or repeats

**(c) √(1/4)**

> **Rational** — because √(1/4) = 1/2, which is already a ratio of integers

**7.** √(9+16) ≠ √9 + √16

> **Left side:** √(9+16) = √25 = **5**
>
> **Right side:** √9 + √16 = 3 + 4 = **7**
>
> **Equal? No — 5 ≠ 7**
>
> Disproves: the rule √(a+b) = √a + √b — **radicals do NOT distribute over addition**

*Common mistake:* This error is especially tempting in Pythagorean contexts. √(a² + b²) ≠ a + b.

**8.** Alberta context — Lethbridge park path

**(a) Diagonal length**

> d = √(60² + 80²)
> = √(3600 + 6400)
> = √10000
> = **100 m**

*Common mistake:* Students sometimes add 60 + 80 = 140 without squaring. The diagonal is shorter than the perimeter path (100 < 140) — this makes physical sense.

**(b) Rational or irrational?**

> **Rational** — √10000 = 100, a whole number (60-80-100 is a 3-4-5 triple × 20)

**9.** Connecting to exponents

**(a)** 25^(1/2) = √25 = **5**

**(b)** 64^(1/2) = √64 = **8**

**(c)** (1/9)^(1/2) = √(1/9) = **1/3**

**(d)** (√7)² = **7**

> Explanation: squaring and square-rooting are inverse operations. (√7)² = (7^(1/2))² = 7^1 = 7.

---

**10.** Ladder problems

**(a) Ladder 15 m, base 9 m from wall**

> h² + 9² = 15²
> h² + 81 = 225
> h² = 144
> **h = 12 m**

**(b) Base moved to 12 m**

> h² + 12² = 15²
> h² + 144 = 225
> h² = 81
> **h = 9 m**

*Note: moving the base further out lowers the height — trade-off between horizontal reach and vertical reach.*
