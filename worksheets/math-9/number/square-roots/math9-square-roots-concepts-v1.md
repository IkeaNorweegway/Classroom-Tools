# Square Roots and Radicals — Concept Summary
Grade 9 Mathematics · Alberta Curriculum

---

## Key Vocabulary

| Term | Meaning | Example |
|---|---|---|
| Perfect square | An integer that is the square of another integer | 25 = 5², 49 = 7² |
| Principal square root | The **positive** square root; what √ always means | √25 = 5 (not ±5) |
| Radicand | The number under the radical symbol | In √49, radicand = 49 |
| Irrational number | Cannot be written as a/b; decimal never terminates or repeats | √2, √7, π |
| Hypotenuse | The side opposite the right angle — always the longest side | side c in a² + b² = c² |

---

## Key Rules

**Principal square root:** √a is always the **non-negative** root. √9 = 3, NOT ±3.

**Square roots of fractions:** √(a/b) = √a / √b &nbsp;&nbsp; → √(9/25) = 3/5

**What distributes:** √(a × b) = √a × √b ✓ &nbsp;&nbsp;&nbsp; √(a + b) ≠ √a + √b ✗

**Irrational numbers:** √n is irrational unless n is a perfect square.

**Pythagorean theorem** (right triangles only): a² + b² = c² &nbsp;&nbsp; where c = hypotenuse

**Estimating √n:** Find the two perfect squares on either side of n.
> √40: 36 < 40 < 49, so 6 < √40 < 7. Since 40 is closer to 36, √40 ≈ 6.3

**Connection to exponents:** √x = x^(1/2)

## Worked Example 1 — Evaluating square roots

**Evaluate: √(36/49) and √0.81**

> √(36/49) = √36/√49 = **6/7**
>
> √0.81 = √(81/100) = 9/10 = **0.9**

*Why does √(a/b) = √a/√b?* Because (√a/√b)² = (√a)²/(√b)² = a/b. It checks out.

---

## Worked Example 2 — Estimating irrational square roots

**Estimate √52 to one decimal place.**

> Perfect squares nearby: 49 < 52 < 64, so **7 < √52 < 8**
>
> 52 is closer to 49, so √52 is closer to 7.
>
> Try 7.2: 7.2² = 51.84 ≈ 52 ✓ &nbsp;&nbsp; **√52 ≈ 7.2**

---

## Worked Example 3 — Pythagorean theorem

**A right triangle has legs 7 cm and 24 cm. Find the hypotenuse.**

> a² + b² = c²
>
> 7² + 24² = c²
>
> 49 + 576 = c²
>
> c² = 625
>
> c = √625 = **25 cm** (rational — 625 is a perfect square ✓)

**A right triangle has hypotenuse 10 m and one leg 6 m. Find the other leg.**

> 6² + b² = 10²
>
> 36 + b² = 100
>
> b² = 64 → b = **8 m**

## Common Mistakes

| Mistake | Fix |
|---|---|
| √9 = ±3 | The principal root is positive only: √9 = 3 |
| √(9 + 16) = 3 + 4 = 7 | √25 = 5, not 7. Roots don't distribute over addition. |
| Using slant height instead of perpendicular height in Pythagorean theorem | Label the diagram carefully — hypotenuse is opposite the right angle |
| Saying √2 = 1.414... exactly | 1.414... is an approximation. The exact value is √2. |
