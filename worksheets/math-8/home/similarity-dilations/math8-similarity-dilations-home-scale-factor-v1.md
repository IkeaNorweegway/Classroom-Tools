::: tip
**For the adult:** Similar shapes have the same shape. Every length is multiplied by one number, the **scale factor** k. Find it by dividing: k = copy ÷ original. If k is more than 1, the copy is bigger. If k is between 0 and 1, it is smaller. Areas grow faster: they are multiplied by k × k.
:::

::: example
**Find the scale factor. Is the copy bigger or smaller?**
@viz polygon pts="0,0;4,0;4,3;0,3" sides="4 cm;3 cm;;" cap="Original" pts2="0,0;8,0;8,6;0,6" sides2="8 cm;6 cm;;" cap2="Copy" unit=12
k = 8 ÷ 4 = 2. Check the other side: 6 ÷ 3 = 2. Same k, so they are similar. k is more than 1: the copy is an **enlargement**.
:::
