::: tip
**For the adult:** The boundary number is the tricky test. In Q2, 5 ≥ 5 is true, so −1 is a solution. In Q4, 3 < 3 is false, so 6 is not. Also, one number that works does not mean every number works. For tickets (Q6), only whole numbers count.
:::

## Answers

**1.** 3(6) − 5 = 13. Is 13 > 12? **Yes**, 6 is a solution.

**2.** 2(−1) + 7 = 5. Is 5 ≥ 5? **Yes**, −1 is a solution.

**3.** **s ≤ 110**. Is 112 ≤ 110? **No**, 112 km/h is not legal.
@viz iqsign kind=speed value=110
**4.** 4: 2 < 3 ✓. 6: 3 < 3 ✗. 7.5: 3.75 < 3 ✗. Only **4** is a solution.

**5.** **w ≤ 1000**: closed dot at 1000, ray left. 980 ≤ 1000, so **980 kg is safe**. 1050 kg is **not**.
@viz iqline value=1000 dir=left closed=1 blank=1 min=900 max=1100 step=25 every=50 label="[[w ≤ 1000]]"
**6.** **3.5n ≤ 20**. Test 5: 17.50 ≤ 20 ✓. Test 6: 21 ≤ 20 ✗. She can buy **up to 5 tickets**.

**7.** 20 − 9 = 11. Is 11 > 12? **No.** Ali is wrong.
