::: tip
**For the adult:** < and > leave the boundary number out: draw an **open dot** ○. ≤ and ≥ include it: draw a **closed dot** ●. "Greater" goes to the right on the number line, "less" goes to the left. "At least" means ≥. "At most" or "no more than" means ≤.
:::

::: example
**Graph x ≤ −1.**
@viz iqline value=-1 dir=left closed=1 min=-6 max=3 label="x ≤ −1" marks="-3:test −3 ✓"
Step 1: The boundary is −1. ≤ includes it, so draw a closed dot.
Step 2: "Less" is to the left. Draw the ray left. Test −3: is −3 ≤ −1? Yes ✓
:::
