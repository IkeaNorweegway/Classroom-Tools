::: tip
**For the adult:** Your child describes patterns with two phrases: "starts at" (the value for figure 0) and "goes up by" (how much is added each time). In the equation, "goes up by" is multiplied by n, and "starts at" is added. Always check the equation with one row of the table.
:::

## Worked example

::: example
**Write an equation for: Figure 1 = 5, Figure 2 = 8, Figure 3 = 11.**

1. It goes up by 3 each time.
2. Go back one step to find Figure 0: 5 − 3 = 2. It starts at 2.
3. Equation: t = 3n + 2.
4. Check Figure 3: 3 × 3 + 2 = 11 ✓
:::
