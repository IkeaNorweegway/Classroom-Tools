::: tip
**For the adult:** The most common mistake is writing t = n + 3 when the pattern goes up by 3. Checking with a row of the table catches it.
:::

**1.** Goes up by **2**. Figure 0 = **2**. t = **2**n + **2**

**2.** Goes up by **3**. Figure 0 = **4**. **t = 3n + 4**

**3.** Goes up by 5; Figure 0 = −4. **t = 5n − 4**

**4.** Figure 4: 5 × 4 − 4 = 16 ✓

**5.** 2 × 10 + 5 = **25**

**6.** Figure 0 = 9 − 4 = 5, so **t = 4n + 5**. Figure 20 = 4 × 20 + 5 = **85**.
