::: tip
**For the adult:** Watch for 3(x + 5) written as 3x + 5. The 3 must multiply the 5 too.
:::

**1.** **3x + 15**

**2.** **4x − 8**

**3.** x + 1 = **6**, x = **5**

**4.** x − 6 = 5, so **x = 11** (or 2x − 12 = 10, 2x = 22, x = 11)

**5.** Way 1: x + 2 = 4, x = 2. Way 2: 3x + 6 = 12, 3x = 6, x = 2. **x = 2** both ways.

**6.** 2x + 2 = 7, 2x = 5, **x = 2.5** (or 5/2). Check: 2(2.5 + 1) = 2 × 3.5 = 7 ✓
