::: tip
**For the adult:** A number in front of brackets multiplies everything inside: 2(x + 3) = 2x + 6. There are two ways to solve: divide both sides by the number outside first, or multiply out the brackets first. Both give the same answer.
:::

## Worked example

::: example
**Solve 2(x + 3) = 14.**

1. Way 1: divide both sides by 2. x + 3 = 7, so x = 4.
2. Way 2: multiply out. 2x + 6 = 14. Subtract 6: 2x = 8. Divide by 2: x = 4.
3. Check: 2(4 + 3) = 2 × 7 = 14 ✓
:::
