::: tip
**For the adult:** A frequent slip is dividing first. In 2x + 1 = 9, take away the 1 before dividing by 2.
:::

**1.** 2x = **8**, x = **4**

**2.** 5x = **25**, x = **5**

**3.** 4x = **−4**, x = **−1**

**4.** x/3 = 5, so **x = 15**

**5.** −2x = 6, so **x = −3**

**6.** −2(−3) + 5 = 6 + 5 = 11 ✓

**7.** 2t + 12 = 20, 2t = 8, **t = 4 toppings**
