::: tip
**For the adult:** Two common slips: calling b the slope (in y = 4x + 2 the slope is 4, not 2), and mixing up the intercepts. The x-intercept is on the x-axis, so its y is 0. The y-intercept is on the y-axis, so its x is 0.
:::

## Answers

**1.** a) **m = 3, b = −2.** b) **m = −1, b = 5.**

**2.** b = 3. From (0, 3) to (2, 2): rise −1, run 2, m = −1/2. **y = −1/2 x + 3.**

**3.** For example **(0, −3), (1, −1), (2, 1)**. The line goes across the whole grid.

**4.** y-intercept: x = 0 gives y = −6, so **(0, −6)**. x-intercept: 0 = 2x − 6, so 2x = 6 and x = 3: **(3, 0)**.

**5.** **C = 2d + 3.** m = 2: **$2 for each km**. b = 3: the **$3 starting fee**, paid before you move. 8 km: 2(8) + 3 = **$19**.

**6.** **W = −4t + 40** (m = −4 L per minute, b = 40 L to start). Empty when W = 0: 4t = 40, so **t = 10 minutes**. The x-intercept is (10, 0).
