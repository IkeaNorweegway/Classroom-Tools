::: tip
**For the adult:** **Slope** tells how steep a line is. Slope = rise ÷ run: how far up, divided by how far across. Up to the right is positive; down is negative. A flat line has slope 0. A straight-up line has an **undefined** slope, because the run is 0.
:::

::: example
**Find the slope through (1, 2) and (3, 6).**
@viz lfslope pts="1,2;3,6" coords=1 rise="6 − 2 = 4" run="3 − 1 = 2" xmin=0 xmax=4 ymin=1 ymax=6 cell=16
Rise = 6 − 2 = 4. Run = 3 − 1 = 2. Slope = 4/2 = 2: up 2 for every 1 across.
:::
