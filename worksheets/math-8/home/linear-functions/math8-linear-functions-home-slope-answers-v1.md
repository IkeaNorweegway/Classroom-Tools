::: tip
**For the adult:** The most common slip is run over rise (across on top). A steep line should have a big slope, so if a steep line comes out as a small fraction, flip it. The other slip is "a flat line is undefined": flat is 0, straight up is undefined.
:::

## Answers

**1.** Run 4, rise 3. Slope = **3/4**.
@viz lfslope pts="0,1;4,4" rise="[[3]]" run="[[4]]" xmin=-1 xmax=5 ymin=0 ymax=4 cell=16
**2.** Rise = 7 − 1 = 6. Run = 5 − 2 = 3. Slope = 6/3 = **2**.

**3.** Rise = 2 − 4 = −2. Run = 3 − (−1) = 4. Slope = −2/4 = **−1/2**. It is **negative**: the line goes down to the right.

**4.** Ramp A: 1/12. Ramp B: 1/8. 1/8 is bigger, so **Ramp B is steeper**. (Same rise, shorter run.)
@viz lfhill kind=ramp rv=1 runv=12 rise="1 m" run="12 m" title="Ramp A" kind2=ramp rv2=1 runv2=8 rise2="1 m" run2="8 m" title2="Ramp B"
**5.** **Negative, zero, undefined, positive.**
@viz lfkinds lines="-2,0;0,1;x=1;1,0" titles="[[negative]];[[zero]];[[undefined]];[[positive]]"
**6.** **No.** A flat line has a rise of 0. 0 ÷ run = 0, so the slope is **0**. Only a vertical line (run 0) has an undefined slope.

**7.** Parallel: **3/5** (the same slope). Perpendicular: **−5/3** (flip it and change the sign).
