::: tip
**For the adult:** If an answer is longer than the hypotenuse, the squares were added instead of subtracted.
:::

**1.** 100 − 36 = 64. √64 = **8**

**2.** 289 − 64 = 225. √225 = **15**

**3.** 625 − 49 = 576. √576 = **24**

**4.** 25 − 4 = 21. √21 ≈ **4.6 m**

**5.** 8² + 15² = 64 + 225 = 289, and 17² = 289. They match, so **yes**, it is a right triangle.
