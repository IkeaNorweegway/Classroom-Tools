::: tip
**For the adult:** Four graphs, four jobs. Bar graph: compare groups. Line graph: show change over time. Circle graph: show parts of a whole (adds to 100%). Pictograph: compare groups with pictures (check the key). Ask, "What do we want the reader to see?"
:::

## Worked example

::: example
**Which graph shows the outside temperature every hour today?**

1. The data changes over time (hour by hour).
2. A line graph shows change over time.
3. So use a line graph.
:::
