::: tip
**For the adult:** The most common slip is flipping only the first sign when subtracting: (5x − 2) − (3x − 6) is not 2x − 8. The −6 becomes +6. The second is combining unlike terms: 3x² + 2x stays as it is.
:::

## Answers

**1.** 5x − 2x = 3x. 3 + 4 = 7. **3x + 7**.

**2.** **x² − 2x + 4**.
@viz posort bins="x² terms:2x²,−x²;x terms:3x,−5x;numbers:+4" totals="[[x²]];[[−2x]];[[+4]]"
**3.** **No.** They are not like terms, so they don't combine. With x = 2: 3x² + 2x = 12 + 4 = 16, but 5x³ = 40.

**4.** **x² − 3x + 5**. (Not x² + 3x + 5: the minus stays with 3x.)

**5.** **3x² − 2x + 3**.
@viz postack heads="x²;x;1" rows="2x²;+3x;−1 | +x²;−5x;+4" op="+" result="[[3x²]];[[−2x]];[[+3]]"
**6.** (3x + 2) + (x + 4) + (3x + 2) + (x + 4) = **8x + 12**.

**7.** 5x − 2 − 3x + 6 = **2x + 4**.
