::: tip
**For the adult:** Two common slips: adding the squares when a leg is missing (the answer then comes out longer than the hypotenuse, which can't be), and using the wrong side as c. c is always the longest side, across from the square corner.
:::

## Answers

**1.** **QR.** It is across from the right angle at P.
@viz polygon pts="0,0;4,0;0,3" names="P,Q,R" right="1" sides=";hypotenuse;" unit=26
**2.** 9² + 12² = 81 + 144 = 225. 15² = 225. They match: **yes**.

**3.** c² = 5² + 7² = 25 + 49 = 74. c = √74 = 8.60… ≈ **8.6 cm**.
@viz polygon pts="0,0;7,0;0,5" right="1" sides="7 cm;[[8.6 cm]];5 cm" unit=14
**4.** Subtract: a² = 10² − 6² = 100 − 36 = 64. a = √64 = **8 cm**.

**5.** The ladder is the hypotenuse. h² = 5.0² − 1.2² = 25 − 1.44 = 23.56. h = √23.56 = 4.85… ≈ **4.9 m**.
@viz ttscene kind=ladder w=1.2 h=4.85 a="h ≈ 4.9 m" b="1.2 m" c="5.0 m"
**6.** d² = 80² + 60² = 6400 + 3600 = 10 000. d = √10 000 = **100 m**.
@viz ttscene kind=field w=80 h=60 a="60 m" b="80 m" c="[[100 m]]"
