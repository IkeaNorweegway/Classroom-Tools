::: tip
**For the adult:** In a right triangle, the **hypotenuse** c is the side across from the square corner. It is the longest side. The theorem: a² + b² = c². Missing c? Add the squares, then √. Missing a shorter side (a **leg**)? Subtract: a² = c² − b².
:::

::: example
**Find the hypotenuse.**
@viz polygon pts="0,0;8,0;0,6" right="1" sides="8 cm;c;6 cm" unit=13
c² = 6² + 8² = 36 + 64 = 100. c = √100 = 10 cm.
:::
