## Core

### Put each number in the smallest box it fits: 8, −5, {2/7}, 0, −3.6, 31
@viz rnsets nat="[[8]];[[31]]" int="[[−5]];[[0]]" rat="[[2/7]];[[−3.6]]"
=> Natural: 8 and 31 (counting numbers). Integers: −5 and 0 (whole numbers that are not natural). (RN1)
=> Rational only: {2/7} and −3.6. All six numbers are rational.

### Jay says −4 is not a rational number, because it is not a fraction. Show he is wrong.
@viz numberline min=-5 max=1 points="-4:−4"
(lines 2)
=> −4 = {−4/1}. A rational number is any number you *can* write as {a/b}. Every integer is rational. (RN1)
=> Targets the "integers aren't rational" mix-up.

### Write each number as {a/b}.
a) 7 = [[{7/1}]]
b) −0.8 = [[−{4/5}]]
c) 3{1/2} = [[{7/2}]]
d) −1.25 = [[−{5/4}]]
=> a) 7 = {7/1}. b) −0.8 = −{8/10} = −{4/5}. (RN1)
=> c) 3{1/2} = {6/2} + {1/2} = {7/2}. d) −1.25 = −{125/100} = −{5/4}.

### Divide to write each fraction as a decimal. Use bar notation if it repeats.
@viz rndiv a=4 b=11 steps=3 blank=1 title="4 ÷ 11"
a) {4/11} = [[0.{bar:36}]]
b) {5/8} = [[0.625]]
c) {7/9} = [[0.{bar:7}]]
d) −{1/6} = [[−0.1{bar:6}]]
=> a) 40 ÷ 11 = 3 R 7, 70 ÷ 11 = 6 R 4. The remainder 4 is back, so 3 and 6 repeat: 0.{bar:36}. (RN2)
=> b) 5 ÷ 8 = 0.625 (ends). c) 7 ÷ 9 = 0.777… = 0.{bar:7}. d) 1 ÷ 6 = 0.1666…, so −{1/6} = −0.1{bar:6}. The bar goes over the 6 only.

### Mia says {1/3} = 0.3. Use the number line to show she is wrong.
@viz numberline min=0.29 max=0.35 step=0.01 every=0.01 points="0.3:0.3"
(lines 2)
=> 0.3 = {3/10}, and it stops. 1 ÷ 3 = 0.333… never stops. So {1/3} = 0.{bar:3} is a little to the right of 0.3. (RN2)
=> Targets the "0.333… is 0.3" mix-up.

### Mark each number on the line with its letter. Then order them from least to greatest.

@viz numberline min=-1 max=0.5 step=0.05 every=0.25 width=600 keypoints="-0.75:A;-0.7:E;-0.6667:C;0.3333:D;0.4:B"
[[−{3/4}, −0.7, −{2/3}, {1/3}, 0.4]]
=> Decimals: −0.75, 0.4, −0.{bar:6}, 0.{bar:3}, −0.7. (RN2)
=> Left to right: −{3/4}, −0.7, −{2/3}, {1/3}, 0.4.

### Find two numbers between 0.5 and 0.6.
@viz numberline min=0.5 max=0.6 step=0.01 every=0.05 keypoints="0.52:0.52;0.57:0.57"
(lines 1)
=> Any two from 0.51 to 0.59, or more digits like 0.505. Example: 0.52 and 0.57. (RN2)
=> There are endless numbers between. Targets the "nothing between 0.5 and 0.6" mix-up.

### Find each sum or difference.
a) −{1/2} + {1/3} = [[−{1/6}]]
b) {1/4} − {3/4} = [[−{1/2}]]
c) −2.5 − (−4.1) = [[1.6]]
d) −1.8 + (−2.7) = [[−4.5]]
=> a) −{3/6} + {2/6} = −{1/6}. Not {0/5}: you need a common denominator. Targets the "add tops and bottoms" mix-up. (RN3)
=> b) −{2/4} = −{1/2}. c) −2.5 + 4.1 = 1.6. d) −4.5.

### Find each product or quotient.
a) −{2/5} × {3/4} = [[−{3/10}]]
b) (−1.5) × (−6) = [[9]]
c) −{3/4} ÷ (−{1/8}) = [[6]]
d) 7.2 ÷ (−0.9) = [[−8]]
=> a) {6/20} = {3/10}; one negative, so −{3/10}. b) Same signs: 9. (RN3)
=> c) {3/4} × 8 = 6; same signs, so positive. d) 72 ÷ 9 = 8; different signs: −8.

### At 6 a.m. in Red Deer it was −7.5 °C. By 2 p.m. it was 4.3 °C warmer. Then it dropped 5.6 °C by 10 p.m. What was the temperature at 10 p.m.?
@viz vjumps min=-10 max=0 step=1 every=2 unit=" °C" zero="" jumps="-7.5>-3.2>-8.8" jumplabels="+4.3;−5.6" points="-7.5:6 a.m." height=230
(lines 2)
=> −7.5 + 4.3 = −3.2. Then −3.2 − 5.6 = −8.8. It was −8.8 °C at 10 p.m. (RN3)

### Evaluate. Estimate first.
a) −4 + 5 × (−0.6)
b) ({2/3} − 1) × (−9)
@viz flow steps="Brackets|Powers|× and ÷|+ and −"
(work 3)
=> a) Estimate −4 + (−3) = −7. Multiply first: 5 × (−0.6) = −3. Then −4 + (−3) = −7. (RN4)
=> Not (−4 + 5) × (−0.6) = −0.6. Multiply before you add.
=> b) Brackets: {2/3} − 1 = −{1/3}. Then −{1/3} × (−9) = 3.

### Sam's bank balance is $45.20. He buys 3 games at $18.75 each. What is his balance now? Estimate first.
@viz vline min=-20 max=50 step=10 prefix="$" zero="" height=200 width=300 points="45.2:start" above="has money" below="owes money"
(lines 2)
=> Estimate: 45 − 3 × 20 = −15. Exact: 45.20 − 3 × 18.75 = 45.20 − 56.25 = −11.05. (RN4)
=> His balance is −$11.05. He owes $11.05. Close to the estimate, so it is reasonable.

## Challenge

### Is every rational number an integer? Is every integer a rational number? Give an example for each.
@viz rnsets nat="3" int="−2" rat="1/2"
(lines 3)
=> No: {1/2} is rational but not an integer. Yes: every integer n = {n/1}, like −2 = {−2/1}. (RN1)

### Without dividing all the way, decide which fractions end and which repeat: {7/20}, {5/12}, {9/40}, {4/15}. Explain.
(lines 3)
=> In simplest form, a bottom made only of 2s and 5s gives an ending decimal. (RN2)
=> 20 = 2 × 2 × 5 and 40 = 2 × 2 × 2 × 5: {7/20} = 0.35, {9/40} = 0.225 end.
=> 12 = 2 × 2 × 3 and 15 = 3 × 5 have a 3: {5/12} = 0.41{bar:6}, {4/15} = 0.2{bar:6} repeat.

### Order from greatest to least: 0.4545… (the 45 repeats), 0.45, 0.4555… (the 5 repeats), {5/11}
@viz numberline min=0.45 max=0.46 step=0.001 every=0.01 ticklabels="0.45:0.45;0.455:0.455;0.46:0.46" keypoints="0.45:0.45;0.4545:A;0.4556:B"
(lines 2)
=> {5/11} = 5 ÷ 11 = 0.4545… So {5/11} = 0.4545… (A on the line). 0.4555… is B. (RN2)
=> 0.4555… > 0.4545… = {5/11} > 0.45. In bar notation: 0.4{bar:5} > 0.{bar:45} = {5/11} > 0.45.

### Find a fraction between −{5/7} and −{4/7}. Then find one between −{5/7} and your fraction.
@viz numberline min=-0.75 max=-0.55 step=0.01 every=0.05 points="-0.7143:−5/7;-0.5714:−4/7" keypoints="-0.6429:−9/14;-0.6786:−19/28"
(lines 2)
=> −{5/7} = −{10/14} and −{4/7} = −{8/14}, so −{9/14} is between. (RN2)
=> −{10/14} = −{20/28} and −{9/14} = −{18/28}, so −{19/28} is between. You can keep going forever.

### Evaluate: −{3/4} + {5/6} × (−{3/10})
(work 3)
=> × first: {5/6} × (−{3/10}) = −{15/60} = −{1/4}. (RN4)
=> Then −{3/4} + (−{1/4}) = −1.

### A stock is worth $24.60. It changes by −$1.35, +$0.80, −$2.15 and −$0.40 over four days. Find the value now and the mean daily change.
| Day | Mon | Tue | Wed | Thu |
|---|---|---|---|---|
| Change ($) | −1.35 | +0.80 | −2.15 | −0.40 |
(lines 3)
=> Total change: −1.35 + 0.80 − 2.15 − 0.40 = −3.10. Value: 24.60 − 3.10 = $21.50. (RN3, RN4)
=> Mean change: −3.10 ÷ 4 = −$0.775, about −$0.78 per day.

### Kim says (−2.4) ÷ 0.08 is about −0.3. Estimate, then find the real answer. Is Kim's answer reasonable?
(lines 2)
=> Estimate: −2.4 ÷ 0.08 ≈ −2.4 ÷ 0.1 = −24. Dividing by a small number makes it bigger. (RN4)
=> Exact: −240 ÷ 8 = −30. Kim is not reasonable: the size is about 30, not 3.
