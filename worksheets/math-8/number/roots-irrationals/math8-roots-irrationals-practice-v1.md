## Core

### Write each as repeated multiplication and as a power. Then find the value.
a) A square Lego plate with 6 studs on each side
b) A square tile with sides of 0.4 m
@viz sqside n=6 side="6 studs" fill=sun cell=16 labels="6 × 6 = [[6²]];= [[36]] studs"
=> a) 6 × 6 = 6² = 36 studs. (SR1)
=> b) 0.4 × 0.4 = 0.4² = 0.16 m².

### Perfect square or not? Explain each one.
a) {16/25} b) {3/4} c) 0.49 d) 0.5
(lines 3)
=> a) Yes: 16 = 4² and 25 = 5², so {16/25} = ({4/5})². (SR1)
=> b) No: 3 is not a perfect square. c) Yes: 0.49 = {49/100} = 0.7².
=> d) No: 0.5 = {1/2}, and 2 is not a perfect square.

### Use the area model to show that {4/9} is a perfect square.
@viz area a=2/3 b=2/3 result="[[2/3]] × [[2/3]] = 4/9"
(lines 1)
=> Shade {2/3} of the rows and {2/3} of the columns. The overlap is {4/9}. So {4/9} = ({2/3})². (SR1)

### Kai says √64 = 32, because it is half of 64. Show he is wrong.
@viz squares shapes="8x8" labels="8 × 8 = 64" cell=9
(lines 2)
=> √64 = 8, because 8 × 8 = 64. 32 × 32 = 1024, not 64. The root is the side of the square, not half the number. (SR1)
=> Targets the "square root is half" mix-up.

### Find both square roots of each number.
a) 36 b) {1/9} c) 0.64 d) 0
@viz numberline min=-7 max=7 keypoints="-6:−6;6:6" caption="The two square roots of 36"
=> a) 6 and −6. b) {1/3} and −{1/3}. (SR2)
=> c) 0.8 and −0.8. d) Only 0, because 0 × 0 = 0.

### Find each value.
a) √121 b) −√121 c) ±√121 d) √−121
(lines 2)
=> a) 11 (the principal root). b) −11. c) ±11, which means 11 and −11. (SR2)
=> d) No real answer. 11² = 121 and (−11)² = 121. No real number squared gives −121.
=> Targets "√25 = ±5" (a) and "√−9 = −3" (d).

### Mo writes √−16 = −4. Use the mapping to explain his mistake.
@viz mapping in="−4,4" out="16,−16" arrows="−4>16;4>16" inlabel="number" outlabel="squared"
(lines 2)
=> (−4) × (−4) = 16, not −16. Both 4 and −4 square to 16. Nothing squares to −16, so √−16 has no real answer. (SR2)
=> Targets the "√−9 = −3" mix-up.

### Solve each equation.
a) x² = 100 b) x² = {25/49} c) x² = 0.09
(lines 2)
=> a) x = ±√100 = ±10. b) x = ±{5/7}. c) x = ±0.3. (SR2)

### Estimate √40 to one decimal place. Then check with a calculator.
@viz srbench lo=6 hi=7 n=40 keydot=1 est="√40 ≈ [[6.3]]"
(lines 2)
=> Benchmarks: 6² = 36 and 7² = 49. 40 is 4 past 36 and 9 below 49, so closer to 6. (SR3)
=> Try 6.3: 6.3² = 39.69. Calculator: √40 = 6.324… ≈ 6.3.

### Nia says √70 ≈ 8.5 because 70 is between 64 and 81. Is that a good estimate?
@viz srbench lo=8 hi=9 n=70 mid=1 keydot=1
(lines 2)
=> Not quite. 8.5² = 72.25, more than 70. 70 is 6 past 64 and 11 below 81, so √70 is closer to 8. (SR3)
=> √70 = 8.366… ≈ 8.4. Targets the "halfway" mix-up.

### A square garden in Medicine Hat has an area of 60 m². Find the side to the nearest tenth. How much fence goes around it?
@viz sqside n=7.75 grid=0 side="s" fill=plant cell=18 fence=1 labels="Area = 60 m²;Perimeter = ?"
(lines 3)
=> Side: s = √60. Benchmarks 49 < 60 < 64, so 7 < s < 8, closer to 8. (SR3)
=> Calculator: √60 = 7.745… ≈ 7.7 m.
=> Fence: 4 × 7.745… = 30.98… ≈ 31.0 m.

### Rational or irrational? Explain each one.
a) √49 b) √48 c) 0.{bar:12} d) π e) {22/7}
@viz srreal nat="[[√49]]" int="" rat="[[0.{bar:12}]];[[22/7]]" irr="[[√48]];[[π]]"
=> a) Rational: √49 = 7. b) Irrational: 48 is not a perfect square. (SR4)
=> c) Rational: it repeats. d) Irrational: it never ends or repeats. e) Rational: it is a fraction (close to π, but not π).

## Challenge

### Is {50/72} a perfect square? Is 0.144? Explain.
(lines 3)
=> {50/72} = {25/36} in simplest form. 25 = 5² and 36 = 6², so yes: ({5/6})². (SR1)
=> 0.144 = {144/1000} = {18/125}. 125 is not a perfect square, so no. (12² = 144, but 0.12² = 0.0144.)

### Solve x² − 7 = 57. Then explain why a square with area 64 cm² has only one side length.
(lines 3)
=> x² = 64, so x = ±8. (SR2)
=> A length can't be negative, so the side is √64 = 8 cm.

### Between which two whole numbers is each root? a) √95 b) √130 c) −√30
@viz numberline min=-7 max=13 keypoints="-5.477:−√30;9.747:√95;11.402:√130"
=> a) 9² = 81 and 10² = 100: between 9 and 10. b) 11² = 121, 12² = 144: between 11 and 12. (SR3)
=> c) √30 is between 5 and 6, so −√30 is between −6 and −5.

### A square ice rink has a perimeter of 80 m. A second square rink has double the area. Find the side of the second rink to the nearest tenth.
@viz squares shapes="4x4;6x6" labels="Rink 1: P = 80 m;Rink 2: double the area" cell=10
(lines 3)
=> Rink 1 side: 80 ÷ 4 = 20 m. Area: 20² = 400 m². (SR3)
=> Rink 2 area: 800 m². Side: √800 = 28.28… ≈ 28.3 m. (Not 40 m: doubling the area does not double the side.)

### Order from least to greatest: √7, 2.{bar:6}, {8/3}, 2.6, π − 0.5
(lines 2)
=> √7 = 2.6457…, 2.{bar:6} = 2.666…, {8/3} = 2.666…, π − 0.5 = 2.6415… (SR4)
=> Order: 2.6, π − 0.5, √7, then 2.{bar:6} and {8/3} (equal).

### Jo says "√2 = 1.414, because my calculator says so." Show her that 1.414 is not exact.
@viz numberline min=1.413 max=1.415 step=0.0005 every=0.001 points="1.414:1.414" keypoints="1.41421:√2"
(lines 2)
=> 1.414² = 1.999396, not 2. √2 = 1.41421356… never ends or repeats, so any decimal is approximate: √2 ≈ 1.414. (SR4)
=> Targets the "1.41 is √2" mix-up.

### Find one rational and one irrational number between 6 and 6.5.
(lines 2)
=> Rational: 6.25 (or {25/4}). Irrational: √40 = 6.32… (any √n with 36 < n < 42.25, not a perfect square). (SR4)
