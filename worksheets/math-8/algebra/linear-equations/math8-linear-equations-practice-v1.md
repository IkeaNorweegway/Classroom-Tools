### Write the equation shown by each balance. Solve it.
@viz balance left="2x" right="+10" text="a)"

@viz balance left="3x;+2" right="+11" text="b)"

### Solve. Verify each answer.
a) 7x = 56, x = [[8]]
b) {x/6} = 4, x = [[24]]
c) −5x = 30, x = [[−6]]
d) {x/3} = −7, x = [[−21]]

a) 2x + 5 = 17

b) 4x − 3 = 21
(work 2)

c) {x/2} + 1 = 9
(work 2)

d) −3x + 4 = 19

### Expand each expression.
a) 2(x + 6) = [[2x + 12]]
b) 5(x − 3) = [[5x − 15]]
c) −4(x + 1) = [[−4x − 4]]

### Solve. Use either way (divide first or expand first).
a) 3(x + 4) = 21
(work 2)
=> x + 4 = 7, x = 3
b) 2(x − 7) = 10
(work 2)
=> x − 7 = 5, x = 12
c) 4(x + 2) = 6
(work 2)

### A bowling alley charges $4 for shoes and $6 per game. Kim paid $28. Write an equation and find how many games she bowled.
(work 3)
=> 6g + 4 = 28, 6g = 24, g = 4 games.

## Challenge

### Find and fix the mistake in each solution.
a) 5x + 2 = 17 → 5x = 19 → x = 3.8
(work 2)
=> Line 2 should be 5x = 15 (subtract 2). x = 3.
b) 3(x − 2) = 12 → 3x − 2 = 12 → 3x = 14
(work 2)
=> Expand correctly: 3x − 6 = 12, 3x = 18, x = 6.

### Write a story problem that matches {x/4} + 2 = 9. Solve it and answer in words.
(work 4)
=> Example: four friends share a pizza bill equally, and each also pays $2 for a drink. Each pays $9. x/4 = 7, so the pizza cost $28.

### Solve and verify: −2(x − 5) = 3
(work 3)
=> −2x + 10 = 3, −2x = −7, x = 3.5. Verify: −2(3.5 − 5) = −2(−1.5) = 3 ✓

### The perimeter of the rectangle is 50 cm. Write an equation and find x.
@viz squares shapes="6x3" labels="length = x + 7 cm, width = 6 cm" cell=16
(work 3)
=> 2(x + 7) + 2(6) = 50. 2x + 14 + 12 = 50. 2x = 24. x = 12 cm. (Or 2(x + 7 + 6) = 50 → x + 13 = 25 → x = 12.)

### Taylor says the equation 3(x + 1) = 3x + 3 has "too many answers." Try x = 0, 1 and 10. What do you notice? Explain.
(work 3)
=> Every value works: both sides are always equal, because 3(x + 1) is just 3x + 3 written another way. It is not really an equation to solve; it is true for all x.

### A phone plan costs $15 a month plus $2 for each GB of data. Another costs $25 a month with unlimited data. How many GB make the plans cost the same?
(work 3)
=> 2g + 15 = 25, 2g = 10, g = 5 GB.
