## Core

### Solve {1/4}x + 2 = 5. Multiply every term by 4 first.
@viz semult top="{1/4}x;+ 2;=;5" by="× 4" bottom="[[x]];+ [[8]];=;[[20]]"
(work 3)
=> × 4 on every term: x + 8 = 20. (SE1)
=> Subtract 8: x = 12. Check: {1/4}(12) + 2 = 3 + 2 = 5. ✓

### Maya solves {1/3}x − 2 = 4. She writes x − 2 = 12. Explain her mistake. Then solve.
@viz semult top="{1/3}x;− 2;=;4" by="× 3" bottom="x;− 2;=;12" miss="2"
(lines 3)
=> She multiplied the x-term and the 4 by 3, but not the 2. Every term must be multiplied. (SE1)
=> x − 6 = 12, so x = 18. Check: {1/3}(18) − 2 = 6 − 2 = 4. ✓ Targets the "multiply only the fraction term by the LCD" mix-up.

### Solve 0.6x + 1.5 = 4.5.
@viz semult top="0.6x;+ 1.5;=;4.5" by="× 10" bottom="[[6x]];+ [[15]];=;[[45]]"
(work 3)
=> × 10: 6x + 15 = 45. (SE1)
=> Subtract 15: 6x = 30. Divide by 6: x = 5. Check: 0.6(5) + 1.5 = 3 + 1.5 = 4.5. ✓

### Which equations are equivalent to {1/2}x − 1 = 3? Write yes or no. Say what was done.
a) x − 2 = 6
b) x − 1 = 6
c) 2x − 4 = 12
d) {1/2}x = 4
(lines 3)
=> a) Yes: × 2 on every term. (SE1)
=> b) No: the 1 was not multiplied by 2.
=> c) Yes: × 4 on every term.
=> d) Yes: + 1 on both sides. All the "yes" equations have x = 8.

### Solve {3/4}x = 9. Use the bar.
@viz sebar parts=4 shade=3 value="[[3]]" whole="x"
(work 2)
=> 3 parts are 9, so each part is 3. Four parts: x = 12. (SE1)
=> Or × 4: 3x = 36, so x = 12. Check: {3/4}(12) = 9. ✓

### Solve −3(x − 5) = 12.
@viz sedist factor="−3" terms="x;− 5" result="[[−3x]];[[+ 15]]"
(work 3)
=> Distribute: −3x + 15 = 12. Subtract 15: −3x = −3. x = 1. (SE2)
=> Or ÷ −3 first: x − 5 = −4, so x = 1. Check: −3(1 − 5) = −3(−4) = 12. ✓

### Leo writes {1/2}(x + 10) = {1/2}x + 10. Fix his mistake. Then solve {1/2}(x + 10) = 9.
@viz sedist factor="{1/2}" terms="x;+ 10" result="[[{1/2}x]];[[+ 5]]"
(lines 3)
=> Half of 10 is 5, so {1/2}(x + 10) = {1/2}x + 5. He gave the factor to the first term only. (SE2)
=> {1/2}x + 5 = 9. {1/2}x = 4. x = 8. Check: {1/2}(18) = 9. ✓ Targets the "distribute to the first term only" mix-up.

### Solve 0.5(x + 6) = 4.5.
(work 2)
=> × 2 on both sides: x + 6 = 9. x = 3. (SE2)
=> Check: 0.5(3 + 6) = 0.5(9) = 4.5. ✓

### Solve 4x + 3 = x + 8. Your answer will be a fraction.
@viz balance left="4x;+3" right="x;+8"
(work 3)
=> Subtract x: 3x + 3 = 8. Subtract 3: 3x = 5. x = {5/3}. (SE3)
=> Check: 4({5/3}) + 3 = {20/3} + {9/3} = {29/3}. {5/3} + 8 = {5/3} + {24/3} = {29/3}. ✓

### Ravi solves 1.2x − 3 = 0.4x + 1. His first step is 0.8x − 3 = 0.4x + 1. Explain his mistake. Then solve.
@viz flow steps="1.2x − 3 = 0.4x + 1|0.8x − 3 = 0.4x + 1|?"
(lines 3)
=> He took 0.4x off the left side only. The right side still has 0.4x, so it is not equivalent. (SE3)
=> 0.8x − 3 = 1. 0.8x = 4. x = 5. Check: 6 − 3 = 3 and 2 + 1 = 3. ✓ Targets the "do it to one side only" mix-up.

### Solve {1/2}x + 3 = {1/4}x + 5.
@viz semult top="{1/2}x;+ 3;=;{1/4}x;+ 5" by="× 4" bottom="[[2x]];+ [[12]];=;[[x]];+ [[20]]"
(work 3)
=> × 4 on every term: 2x + 12 = x + 20. (SE3)
=> Subtract x: x + 12 = 20. x = 8. Check: 4 + 3 = 7 and 2 + 5 = 7. ✓

### A taxi costs $3.50 to start plus $1.75 per km. A fare is $21. How far was the ride?
@viz receipt title="Taxi fare" items="Start fee:$3.50;x km at $1.75 per km:1.75x;Fare:$21.00"
(work 3)
=> Let x = km. 3.50 + 1.75x = 21. (SE4)
=> × 100: 350 + 175x = 2100. 175x = 1750. x = 10. Check: 3.50 + 17.50 = 21. ✓ The ride was 10 km.

## Challenge

### Solve {2/3}x + {1/2} = {1/6}x + 2.
@viz semult top="{2/3}x;+ {1/2};=;{1/6}x;+ 2" by="× 6" bottom="[[4x]];+ [[3]];=;[[x]];+ [[12]]"
(work 3)
=> × 6: 4x + 3 = x + 12. 3x = 9. x = 3. (SE3)
=> Check: 2 + {1/2} = 2{1/2} and {1/2} + 2 = 2{1/2}. ✓

### Solve −{1/2}(4x − 6) = x + 9.
@viz sedist factor="−{1/2}" terms="4x;− 6" result="[[−2x]];[[+ 3]]"
(work 3)
=> −2x + 3 = x + 9. −6 = 3x. x = −2. (SE2)
=> Check: −{1/2}(−8 − 6) = −{1/2}(−14) = 7 and −2 + 9 = 7. ✓

### Solve 0.25(x − 8) = 0.5x + 1.
(work 3)
=> 0.25x − 2 = 0.5x + 1. Subtract 0.25x: −2 = 0.25x + 1. −3 = 0.25x. x = −12. (SE3)
=> Check: 0.25(−20) = −5 and 0.5(−12) + 1 = −5. ✓

### Solve {x − 1/3} = {x + 3/5}.
(work 3)
=> × 15 on both sides: 5(x − 1) = 3(x + 3). 5x − 5 = 3x + 9. 2x = 14. x = 7. (SE3)
=> Check: {6/3} = 2 and {10/5} = 2. ✓

### Gym A costs $45 to join plus $19.75 a month. Gym B costs $27.25 a month. When do they cost the same? Which is cheaper for a full year?
@viz flow steps="Let x = months|A: 45 + 19.75x|B: 27.25x|45 + 19.75x = 27.25x"
(work 3)
=> 45 = 7.5x. x = 6 months. Both cost $163.50. (SE4)
=> 12 months: A = 45 + 237 = $282. B = $327. Gym A is cheaper for a year.

### Use F = 1.8C + 32. At what temperature are °F and °C the same number?
(work 3)
=> Put F = C: C = 1.8C + 32. Subtract 1.8C: −0.8C = 32. C = −40. (SE4)
=> Check: 1.8(−40) + 32 = −72 + 32 = −40. ✓ −40 °C is −40 °F.

### A rectangle is {2/3}x + 1 long and {1/3}x wide. Its perimeter is 20 cm. Find the length and width.
@viz polygon pts="0,0;7,0;7,3;0,3" sides="⅔x + 1;⅓x;;" unit=30
(work 3)
=> 2({2/3}x + 1) + 2({1/3}x) = 20. {4/3}x + 2 + {2/3}x = 20. 2x + 2 = 20. x = 9. (SE4)
=> Length 7 cm, width 3 cm. Check: 2(7 + 3) = 20. ✓

### Ana makes {2/3} of a muffin recipe. She uses {1/2} cup of sugar. How much sugar is in the full recipe?
@viz sebar parts=3 shade=2 value="[[{1/4}]]" whole="x cups"
(work 3)
=> {2/3}x = {1/2}. × 6: 4x = 3. x = {3/4} cup. (SE4)
=> Check: {2/3} × {3/4} = {6/12} = {1/2}. ✓
