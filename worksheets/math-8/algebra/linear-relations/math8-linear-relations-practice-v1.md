## Challenge

### Ravi says the equation for the table below is y = x + 3, "because it goes up by 3." Test his equation. Write the correct one.
| x | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| y | 5 | 8 | 11 | 14 |
(work 3)
=> x = 2: 2 + 3 = 5, not 8. Wrong. Up by 3 means 3x. Figure 0 would be 2. y = 3x + 2. Check: 3(4) + 2 = 14 ✓

### Draw Figure 4 of a pattern that has the equation t = 4n + 1. Explain what the "4" and the "1" look like in your picture.
(work 4)
=> Figure 4: 1 square in the middle plus 4 groups of 4 (17 squares). The 1 is the square that never changes; the 4 is the number of squares added each time.

### The point (7, 30) is on the relation y = 4x + b. Find b. Then find y when x = 12.
(work 3)
=> 30 = 4(7) + b = 28 + b, so b = 2. y = 4(12) + 2 = 50.

### A pool has 1200 L of water. It drains at 80 L per minute. Write an equation, make a table for 0, 5, 10, 15 minutes, and find when it is empty.
(work 4)
=> w = 1200 − 80t. t = 0: 1200; 5: 800; 10: 400; 15: 0. Empty after 15 minutes.
