## Core

### Write each one in symbols. a) x is greater than −2. b) y is at most 7. c) n is at least 4.5. d) k is less than {1/2}.
(lines 2)
=> a) x > −2 b) y ≤ 7 c) n ≥ 4.5 d) k < {1/2} (IQ1)
=> At most means ≤. At least means ≥.

### True or false? a) 6 ≥ 6 b) 6 > 6 c) −3 < −7 d) 0.75 ≤ {3/4}
@viz numberline min=-8 max=1 step=1 points="-7:−7;-3:−3"
(lines 2)
=> a) True: 6 equals 6, and ≥ lets equal in. b) False: equal is not greater. (IQ1)
=> c) False: −3 is right of −7, so −3 > −7. d) True: 0.75 = {3/4}.

### Ben says x < 5 includes 5. Is he right? Test 5 to show it.
@viz iqline value=5 dir=left closed=0 min=0 max=9 label="x < 5" marks="5:5 < 5 ?"
(lines 2)
=> No. 5 < 5 is false, because 5 equals 5. So 5 is not a solution: open dot. (IQ1)
=> Targets the "x < 3 includes 3" mix-up.

### Rewrite with the variable first. a) 9 > x b) −1 ≤ y c) 0 < m
(lines 2)
=> a) x < 9 b) y ≥ −1 c) m > 0 (IQ1)
=> The symbol still points at the smaller amount. Targets reading 3 < x backwards.

### Graph x > −1. Then test 2.
@viz iqline value=-1 dir=right closed=0 blank=1 min=-5 max=4 label="x > −1"
(lines 1)
=> Open dot at −1. Ray to the right. (IQ2)
=> Test 2: 2 > −1 is true, and 2 is on the ray. ✓

### Ria graphed x > 3 like this. Fix her graph.
@viz iqline value=3 dir=left closed=0 min=-2 max=7 label="x > 3"
(lines 2)
=> The ray must go right. Greater numbers are to the right. Test 5: 5 > 3 is true, but 5 is not on her ray. (IQ2)
=> Keep the open dot. Targets the "x > 2 points left" mix-up.

### Is x = 4 a solution of 3x − 2 > 9? Is x = 3?
(lines 2)
=> x = 4: 3(4) − 2 = 10. 10 > 9 is true. Yes. (IQ3)
=> x = 3: 3(3) − 2 = 7. 7 > 9 is false. No.

### Which are solutions of 2x + 5 ≥ 1? Test −3, −2 and 0.5.
@viz iqline value=-2 dir=right closed=1 blank=1 min=-5 max=3 step=0.5 every=1 marks="-3:−3;-2:−2;0.5:0.5"
(lines 3)
=> −3: 2(−3) + 5 = −1. −1 ≥ 1 is false. No. (IQ3)
=> −2: 2(−2) + 5 = 1. 1 ≥ 1 is true. Yes (the boundary).
=> 0.5: 2(0.5) + 5 = 6. 6 ≥ 1 is true. Yes. The graph is x ≥ −2.

### Write an inequality for each. a) Riders must be at least 122 cm tall. b) Drive no faster than 30 km/h in a playground zone. c) The temperature is below freezing.
@viz iqsign kind=height value=122
(lines 3)
=> a) h ≥ 122. At least means ≥, not ≤. Targets the "at least means less than" mix-up. (IQ4)
=> b) s ≤ 30. c) t < 0, with t in °C.

### A canoe holds at most 3 people. Write the inequality. Graph the solutions.
@viz iqline value=3 dir=left closed=1 whole=1 nodot=1 blank=dir min=0 max=6 label="p ≤ 3"
(lines 2)
=> p ≤ 3. People are whole numbers, so the solutions are dots at 0, 1, 2 and 3. Not a ray. (IQ4)

## Challenge

### Write two different inequalities that 4 is a solution of, and 5 is not.
(lines 2)
=> Answers vary. For example x ≤ 4, x < 5, x < 4.5. (IQ1)
=> Check: 4 ≤ 4 true, 5 ≤ 4 false. ✓

### Sort into "includes −2" and "does not include −2": x > −2, x ≥ −2, −2 ≥ x, −2 < x.
@viz iqline value=-2 dir=right closed=1 min=-6 max=2 label="x ≥ −2"
(lines 2)
=> Includes −2: x ≥ −2 and −2 ≥ x (the same as x ≤ −2). (IQ1, IQ2)
=> Does not include −2: x > −2 and −2 < x (the same as x > −2). Strict symbols leave the boundary out.

### A graph has a closed dot at −{3/4} and a ray to the left. Write the inequality two ways.
@viz iqline value=-0.75 dir=left closed=1 min=-3 max=1 step=0.25 every=1
(lines 2)
=> x ≤ −{3/4} and −{3/4} ≥ x. (IQ2)

### Find the smallest whole number that is a solution of 4x − 3 > 13. Test values to show it.
(lines 3)
=> x = 4: 16 − 3 = 13. 13 > 13 is false. (IQ3)
=> x = 5: 20 − 3 = 17. 17 > 13 is true. The smallest whole number is 5.

### Jen says the graph shows 12 − 2x ≤ 4. Test three numbers. Is she right?
@viz iqline value=4 dir=right closed=1 min=0 max=8 label="12 − 2x ≤ 4" marks="2:test 2;4:test 4;6:test 6"
(lines 3)
=> 2: 12 − 4 = 8. 8 ≤ 4 false, and 2 is off the ray. ✓ (IQ3)
=> 4: 12 − 8 = 4. 4 ≤ 4 true: closed dot. ✓ 6: 12 − 12 = 0. 0 ≤ 4 true, on the ray. ✓ She is right.

### Is y = −{1/2} a solution of 1 − 4y > 3?
(lines 2)
=> 1 − 4(−{1/2}) = 1 + 2 = 3. 3 > 3 is false. No. It is the boundary. (IQ3)

### An elevator holds at most 1000 kg. Six people of 80 kg get on with a 450 kg cart. Is the load safe? Write and test the inequality.
@viz iqsign kind=limit top="ELEVATOR" value="1000 kg" unit="MAXIMUM LOAD"
(lines 3)
=> Let w = the load in kg. w ≤ 1000. (IQ4)
=> w = 6(80) + 450 = 480 + 450 = 930. 930 ≤ 1000 is true. Safe.

### Concert tickets cost $25 each, plus a $10 fee for the order. Ali can spend no more than $90. Write an inequality. How many tickets can he buy?
(lines 3)
=> Let n = tickets. 25n + 10 ≤ 90. (IQ4)
=> n = 3: 85 ≤ 90 true. n = 4: 110 ≤ 90 false. He can buy 0, 1, 2 or 3 tickets (whole numbers, so dots).
