## Core

### Write each term as a product of factors: a) 6x² b) −x³. Then write 2 · x · x · x as a term.
@viz poterm c="6" v="x" e="2" clabel="coefficient" elabel="exponent"
(work 2)
=> a) The coefficient is 6. The exponent 2 means two factors of x. 6x² = 6 · x · x. (PO1)
=> b) The coefficient of −x³ is −1. −x³ = −1 · x · x · x.
=> c) The number factor is 2. There are three x's. 2 · x · x · x = 2x³.

### Tom says x² and 2x are the same. Test his idea with x = 3. Then explain.
@viz potiles rows="x2 | 2x" labels="x²;2x"
(lines 3)
=> x = 3: x² = 3 · 3 = 9. 2x = 3 + 3 = 6. They are not equal. (PO1)
=> x² means x · x (a square). 2x means x + x (two thin tiles). Targets the "x² means 2x" mix-up.
=> (They happen to match at x = 2, since 2 · 2 = 2 + 2. One match does not make them the same.)

### Write in conventional form. a) 1x³ b) 4x¹ c) −1x d) 7x⁰ e) 3x² + 0x + 1x⁰
(lines 2)
=> a) x³ (a coefficient of 1 is not written). (PO1)
=> b) 4x (an exponent of 1 is not written).
=> c) −x
=> d) x⁰ = 1, so 7x⁰ = 7.
=> e) 0x = 0 drops out. 1x⁰ = 1. So 3x² + 1.

### Sort into polynomials and non-polynomials: 5x³ − 2, {4/x} + 1, √x, −8, x⁻² + x. Explain each "no."
@viz posort bins="Polynomial:[[5x³ − 2]],[[−8]];Not a polynomial:[[4/x + 1]],[[√x]],[[x⁻² + x]]"
(lines 3)
=> Polynomials: 5x³ − 2 (exponents 3 and 0) and −8 (a constant, degree 0). (PO2)
=> {4/x} + 1: {4/x} = 4x⁻¹. A negative exponent is not allowed.
=> √x: x is under a root. It is not x to a counting-number power.
=> x⁻² + x: the exponent −2 is negative.

### Name each polynomial by its number of terms and by its degree. a) 3x² − x + 4 b) x³ + 1 c) −7x d) 12
@viz potiles rows="3x2;-x;+4" labels="a)"
(lines 3)
=> a) 3 terms, highest exponent 2: a quadratic trinomial, degree 2. (PO2)
=> b) 2 terms, highest exponent 3: a cubic binomial, degree 3.
=> c) 1 term, exponent 1: a linear monomial, degree 1.
=> d) 1 term, no x (12 = 12x⁰): a constant monomial, degree 0.

### Nia says 2x + x³ has degree 2 because it has two terms. Is she right? Explain.
@viz poterm c="" v="x" e="3" elabel="exponent" note="degree = highest exponent = [[3]]"
(lines 2)
=> No. The degree is the highest exponent, not the number of terms. (PO2)
=> The exponents are 1 and 3. The degree is 3. It is a cubic binomial. Targets the "degree = number of terms" mix-up.

### Sort the like terms. Then simplify: 5x² − 3x + 4 − x² + 2x − 6
@viz posort bins="x² terms:[[5x²]],[[−x²]];x terms:[[−3x]],[[+2x]];constants:[[+4]],[[−6]]" totals="[[4x²]];[[−x]];[[−2]]"
(work 2)
=> x² terms: 5x² − x² = 4x². (PO3)
=> x terms: −3x + 2x = −1x = −x.
=> Constants: 4 − 6 = −2.
=> Answer: 4x² − x − 2.

### Jay simplifies 3x² + 2x and gets 5x³. Explain his mistake. Give the right answer.
@viz potiles rows="3x2;2x"
(lines 3)
=> 3x² and 2x are not like terms. Their exponents are different. (PO3)
=> They are different shapes of tile, so they can't be counted together. Adding never changes an exponent.
=> 3x² + 2x is already simplified. Check with x = 2: 3x² + 2x = 12 + 4 = 16, but 5x³ = 5 · 8 = 40. Targets the "3x² + 2x = 5x³" mix-up.

### Write 4 − 2x + 5x³ − x² in descending order and in ascending order. Sam writes 5x³ + x² + 2x + 4. Fix his answer.
@viz posort bins="degree 3:[[+5x³]];degree 2:[[−x²]];degree 1:[[−2x]];degree 0:[[+4]]"
(lines 3)
=> Degrees: 4 is 0, −2x is 1, 5x³ is 3, −x² is 2. (PO3)
=> Descending: 5x³ − x² − 2x + 4. Ascending: 4 − 2x − x² + 5x³.
=> Sam dropped two − signs. Each sign moves with its term: −x² and −2x. Targets the "reorder and drop the sign" mix-up.

### Add (2x² + 3x − 1) + (x² − 5x + 4).
@viz potiles rows="2x2;3x;-1 | x2;-5x;+4" labels="2x² + 3x − 1;+ (x² − 5x + 4)"
(work 2)
=> Remove the brackets: 2x² + 3x − 1 + x² − 5x + 4. (PO4)
=> x²: 2x² + x² = 3x². x: 3x − 5x = −2x. Constants: −1 + 4 = 3.
=> Answer: 3x² − 2x + 3.

### Ana subtracts (5x − 2) − (3x − 6) and gets 2x − 8. Find her mistake. Then subtract.
@viz potiles rows="5x;-2 | -3x;+6" labels="5x − 2;Opposite of 3x − 6"
(lines 3)
=> Subtracting means adding the opposite. The opposite of 3x − 6 is −3x + 6. (PO4)
=> 5x − 2 − 3x + 6 = 2x + 4.
=> Ana flipped only the 3x. She kept −6 instead of +6. Targets the "subtract only the first term" mix-up.

### A rectangle is 3x + 2 long and x + 4 wide. Find its perimeter.
@viz polygon pts="0,0;5,0;5,2.4;0,2.4" sides="3x + 2;x + 4;3x + 2;x + 4" unit=32
(work 2)
=> Add the four sides: (3x + 2) + (x + 4) + (3x + 2) + (x + 4). (PO4)
=> x terms: 3x + x + 3x + x = 8x. Constants: 2 + 4 + 2 + 4 = 12.
=> Perimeter: 8x + 12.

## Challenge

### Write a polynomial for each description. a) a cubic trinomial in descending order with constant term −5 b) a quadratic monomial with coefficient −1 c) a linear binomial in ascending order
(lines 3)
=> Answers vary. a) x³ + 2x − 5 (degree 3, three terms, ends in −5). (PO2, PO3)
=> b) −x²
=> c) 4 + 3x (the constant comes first).

### Two garden plots have areas 2x² + 3x and x² + 5x + 2. Find the total area. Then find Plot B − Plot A. Check both with x = 2.
@viz potiles rows="2x2;3x | x2;5x;+2" labels="Plot A;Plot B"
(work 3)
=> Total: 2x² + 3x + x² + 5x + 2 = 3x² + 8x + 2. (PO4)
=> B − A: x² + 5x + 2 − 2x² − 3x = −x² + 2x + 2.
=> Check x = 2: A = 8 + 6 = 14. B = 4 + 10 + 2 = 16. Total 30 and 3(4) + 16 + 2 = 30 ✓. B − A = 2 and −4 + 4 + 2 = 2 ✓.

### A triangle has perimeter 4x² + 3x + 6. Two sides are x² + 2x and 2x² + 1. Find the third side.
@viz polygon pts="0,0;6,0;2.2,3" sides="2x² + 1;[[x² + x + 5]];x² + 2x" unit=34
(work 3)
=> Third side = perimeter − the two sides. (PO4)
=> 4x² + 3x + 6 − (x² + 2x) − (2x² + 1) = 4x² + 3x + 6 − x² − 2x − 2x² − 1.
=> = x² + x + 5. Check: (x² + 2x) + (2x² + 1) + (x² + x + 5) = 4x² + 3x + 6 ✓.

### What must you subtract from 3x³ − 2x + 1 to get x³ + x² − 2x?
(lines 3)
=> The missing polynomial is (3x³ − 2x + 1) − (x³ + x² − 2x). (PO4)
=> = 3x³ − 2x + 1 − x³ − x² + 2x = 2x³ − x² + 1.
=> Check: 3x³ − 2x + 1 − (2x³ − x² + 1) = x³ + x² − 2x ✓.

### Kim simplifies (2x² − 4x + 3) − (−x² + x − 5) and gets x² − 5x − 2. Find her mistake. Fix it with the columns.
@viz postack heads="x²;x;1" rows="2x²;−4x;+3 | [[+x²]];[[−x]];[[+5]]" op="+" result="[[3x²]];[[−5x]];[[+8]]"
(lines 3)
=> The opposite of −x² + x − 5 is +x² − x + 5. (PO4)
=> Kim flipped only the x term. She kept −x² and −5.
=> Right answer: 2x² + x² − 4x − x + 3 + 5 = 3x² − 5x + 8. Targets the "flip only some signs" mix-up.

### Figure x of tile pattern A has x² + 3x + 2 tiles. Figure x of pattern B has 2x² + x tiles. Find B − A. Which pattern has more tiles in Figure 1? In Figure 4?
@viz potiles rows="x2;3x;+2 | 2x2;x" labels="Pattern A;Pattern B"
(work 3)
=> B − A = 2x² + x − x² − 3x − 2 = x² − 2x − 2. (PO4)
=> Figure 1: 1 − 2 − 2 = −3. A has 3 more (A = 6, B = 3).
=> Figure 4: 16 − 8 − 2 = 6. B has 6 more (A = 30, B = 36).

### Simplify x³ + 2x − x³ − 2x + 7. Is the answer still a polynomial? Name it by terms and degree.
@viz posort bins="x³ terms:x³,−x³;x terms:2x,−2x;constants:+7" totals="[[0]];[[0]];[[7]]"
(lines 2)
=> x³ − x³ = 0 and 2x − 2x = 0. The answer is 7. (PO2, PO3)
=> Yes. 7 = 7x⁰ is a polynomial: a constant monomial, degree 0.
