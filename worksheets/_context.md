# Worksheets
*Practice and application tasks — ready to print*

**Pedagogical framework:** `_meta-context.md` governs how to think and design. This file governs structure and format. Read both.

**Worksheets vs. workbooks:** A worksheet targets one concept for focused practice and diagnosis. A unit workbook deliberately interleaves multiple concepts — that is a different artifact with a different purpose. Do not apply the one-concept rule to workbooks. For full workbook design rules, read `worksheets/workbooks-context.md`.

---

## Purpose
Worksheets give students structured practice on a specific concept. They are not busywork — every item should require thinking, not just recall or copying.

## Design principles
- **One concept per worksheet.** Don't combine two skills — it makes diagnosis impossible. (Exception: unit workbooks, which are intentionally interleaved — see `_meta-context.md`.)
- **Scaffold, then release.** Start with a guided example or worked model, move to prompted practice, end with independent application.
- **Leave room to think.** White space is not wasted space. Students need room to show work.
- **Include a "stretch" item.** One question that requires transfer or deeper reasoning — optional for most, expected for some.

## File naming
`[subject]-[unit]-[type]-v[N].md`
Example: `sci6-forces-workbook-v1.md`

## What to include in every worksheet
1. **Header:** Subject, concept, grade, student name/date line
2. **Learning target:** One sentence — "I can ___" — at the top
3. **Worked example or model** (where appropriate)
4. **Practice items** — 6–12 questions, scaffolded
5. **Stretch item** — one transfer question
6. **Reflection line:** "One thing I'm still unsure about: ___"
