## What's the big idea?

Same language, new **hardware**. Your code now has to talk to real motors. A **hardware map** tells the program which port each motor and sensor is plugged into. **Motor objects** let you control them by name. **Servos** turn to exact positions, and **sensors** let the robot make decisions with conditionals, on real hardware this time.
