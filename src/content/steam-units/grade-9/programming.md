## What's the big idea?

You already know the logic from block coding. Now you'll write it as **typed code**. Java needs a **class** and a **main method**. Python uses **indentation** to show structure. Both use **variables**, **loops** and **conditionals**, plus **functions** (Python) or **methods** (Java) that you can reuse. Errors come in three kinds: **syntax**, **runtime** and **logic**. Each one is a clue.
