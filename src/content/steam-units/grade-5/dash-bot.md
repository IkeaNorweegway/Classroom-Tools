## What's the big idea?

An **algorithm** is a set of steps in order. Robots do exactly what you tell them, nothing more. You'll program **Dash** to drive a maze using a **sequence**, then shorten your code with a **loop**, then make Dash react to the world with **sensors** and **conditionals**. When Dash crashes, that's not failure. It's a clue about which step to fix.
