### Example 1: From a pattern to an equation

**A pattern has 5, 8, 11, 14 tiles in Figures 1, 2, 3, 4.**

1. **Goes up by?** 3 each time.
2. **Starts at?** Go back one step from Figure 1: 5 − 3 = 2.
3. **Equation.** t = 3n + 2.
4. **Check Figure 4.** 3 × 4 + 2 = 14 ✓
   *Say:* "Does your equation work for Figure 4?"

**Common slip:** t = n + 3. Check Figure 2: 2 + 3 = 5, but the pattern says 8.

### Example 2: Reading a graph

**A 24 cm candle burns 3 cm every hour.**

1. **Up or down?** The candle gets shorter, so the relation is decreasing.
2. **Starts at?** 24 cm.
3. **Changes by?** −3 cm each hour. Equation: h = 24 − 3t.
4. **When does it burn out?** 24 ÷ 3 = 8 hours.
   *Say:* "What would the graph look like?"
