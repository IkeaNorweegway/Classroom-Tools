### Example 1: A two-step equation

**Solve 3x + 4 = 19.**

1. **Undo + 4.** Subtract 4 from both sides: 3x = 15.
2. **Undo × 3.** Divide both sides by 3: x = 5.
3. **Check.** 3 × 5 + 4 = 19 ✓
   *Say:* "What was the last thing done to x? Undo that first."

**Common slip:** dividing by 3 first and getting x + 4 = 6.33… It can work, but only if you divide the 4 too.

### Example 2: An equation with brackets

**Solve 2(x + 3) = 14.**

1. **Way 1: divide first.** 14 ÷ 2 = 7, so x + 3 = 7 and x = 4.
2. **Way 2: multiply out.** 2x + 6 = 14, so 2x = 8 and x = 4.
3. **Check.** 2(4 + 3) = 14 ✓
   *Say:* "What does the 2 multiply?"

**Common slip:** 2x + 3 = 14, so x = 5.5. The 2 must multiply both the x and the 3.
