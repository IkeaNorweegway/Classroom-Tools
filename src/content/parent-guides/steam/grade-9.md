### Example 1: Reading code line by line

**What does this Python code print?**

```python
x = 5
x = x + 3
print(x)
```

1. **Line 1:** x stores 5.
2. **Line 2:** take x (5), add 3, and store the result back in x, so x is now 8.
3. **Line 3:** print shows **8**.
   *Say:* "What's in the box called x after each line?"

**Common slip:** reading line 2 as an equation with no answer. In code, = means "store this value".

### Example 2: A trebuchet is a lever

**Why does a trebuchet have a short arm with a heavy weight and a long arm with the throwing sling?**

1. **The pivot** sits closer to the heavy counterweight.
2. **When the weight drops a short distance,** the long arm swings a much longer distance.
3. **So the end of the long arm moves very fast,** flinging the object far.
   *Say:* "What happens if you move the pivot?"
