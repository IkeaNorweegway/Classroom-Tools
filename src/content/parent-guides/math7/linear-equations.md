plainSummary: "Your child is learning to solve equations like 5x + 2 = 3x + 10. First they tidy each side: they combine matching terms (2x + 3x = 5x) and multiply out brackets (2(x + 3) = 2x + 6). ### Example 1: Simplify 3(x − 2) + 4x

1. **Multiply out the brackets.** 3 × x = 3x and 3 × 2 = 6. So 3x − 6.
2. **Combine the x-terms.** 3x − 6 + 4x = 7x − 6.
   *Say:* "Did the 3 multiply both things in the brackets?"

**Common slip:** writing 3x − 2 + 4x, so only the x got multiplied.

### Example 2: Solve 5x + 2 = 3x + 10

1. **Get x on one side.** Subtract 3x from both sides: 2x + 2 = 10.
2. **Get the numbers on the other side.** Subtract 2 from both sides: 2x = 8.
3. **Divide.** x = 4.
4. **Check in the first equation.** 5(4) + 2 = 22 and 3(4) + 10 = 22. ✓
   *Say:* "What did you do to the left side? Did you do it to the right side too?"

**Common slip:** "moving" 3x to the left as +3x: 8x + 2 = 10.

### Example 3: Two phone plans

Plan A is $20 a month plus $5 a GB. Plan B is $35 a month plus $2 a GB. When do they cost the same?

1. **Write each plan.** Let x be the number of GB. Plan A: 20 + 5x. Plan B: 35 + 2x.
2. **Make them equal and solve.** 20 + 5x = 35 + 2x. Subtract 2x: 20 + 3x = 35. Subtract 20: 3x = 15. So x = 5.
3. **Check.** 20 + 25 = 45 and 35 + 10 = 45. Both cost $45 for 5 GB.
   *Say:* "Which plan is cheaper if you use only 2 GB?"

**Common slip:** writing 5x + 2x = 35 + 20, which adds the plans instead of setting them equal.
