### Example 1: Is it a function?

Is (1, 3), (2, 3), (3, 7) a function?

1. **Look at each input.** 1 goes to 3. 2 goes to 3. 3 goes to 7.
2. **Does any input have two outputs?** No. So it is a function.
   *Say:* "Does any input appear twice with different outputs?"

**Common slip:** saying "no" because 1 and 2 both give 3. Sharing an output is allowed.

### Example 2: Graph a table

A trough gets 20 L of water each minute. It starts empty.

1. **Make a table.** 0, 1, 2, 3 minutes give 0, 20, 40, 60 L.
2. **Plot the pairs.** Minutes go across. Litres go up.
3. **Dots or a line?** Time can be any amount, like 1.5 minutes. So join the dots with a line.
   *Say:* "Could the hose run for half a minute? Then the line goes there too."

**Common slip:** leaving dots for time, or joining dots for counted things like tickets.

### Example 3: Domain and range with a limit

A bus seats 40. Each rider pays $3.

1. **Domain (the inputs).** Riders are counted and can't be negative. Whole numbers from 0 to 40.
2. **Range (the outputs).** 0 × 3 = 0 up to 40 × 3 = 120. So $0, $3, $6 and so on, up to $120.
   *Say:* "Which number goes in, and which comes out?"

**Common slip:** writing the money as the domain and the riders as the range.
