### Example 1: A phone plan

**A plan costs $15 a month plus $0.05 per minute. Write an equation, and find the cost for 300 minutes.**

1. **Find the starting value.** With 0 minutes you still pay $15. That's the y-intercept, b = 15.
2. **Find the rate.** Each minute adds $0.05. That's the slope, m = 0.05.
   *Say:* "What do you pay before you make a single call?"
3. **Write the equation.** C = 0.05m + 15, where m is minutes.
4. **Use it.** C = 0.05(300) + 15 = 15 + 15 = $30.

### Example 2: From a table to an equation

**x: 0, 1, 2, 3 and y: 4, 7, 10, 13. Write the equation.**

1. **How much does y change each time x goes up by 1?** It goes up by 3, so m = 3.
2. **What is y when x = 0?** 4, so b = 4.
3. **Equation:** y = 3x + 4.
4. **Check another row.** When x = 3: 3(3) + 4 = 13. ✓

**Common slip:** writing y = 4x + 3, swapping the slope and the starting value.

### Example 3: Direct or partial variation

**Compare: a job paying $15 an hour, and a taxi charging $3.50 plus $2 per km.**

1. **Job:** P = 15h. Work 0 hours and you earn $0. The line starts at zero, so this is **direct variation**.
2. **Taxi:** C = 2d + 3.5. Even at 0 km you pay $3.50. There's a starting amount, so this is **partial variation**.
   *Say:* "What does it cost when the number is zero?"
