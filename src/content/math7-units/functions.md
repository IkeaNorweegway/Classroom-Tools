## What's the big idea?

A **function** is like a machine. An input goes in. The machine follows a rule. One output comes out. Bowling costs $6 a game, so 2 games cost $12. Each input has only ONE output. You can show a function as a table, as pairs like (2, 12), as arrows or as a graph. Some graphs get dots, like games or tickets you count. Some get a line, like time or water that can be any amount. The **domain** is all the inputs. The **range** is all the outputs. Real life sets limits. Time can't be negative, and a bus is full at 40 riders.
