## What's the big idea?

Roll a die. It can land on 1, 2, 3, 4, 5 or 6. Each one is an **outcome**. A **probability** tells how likely something is. It is a number from 0 (impossible) to 1 (certain). When all the outcomes have the same chance, **probability = favourable outcomes ÷ all outcomes**. Rolling a 6 is 1/6, not 1/2. That is the **theory**. An **experiment** shows what really happens: times it happened ÷ number of trials. A few trials can be far from the theory. Many trials get close to it. A coin has no memory, so each flip is a new start.
