## What's the big idea?

A **view** is what an object looks like from one direction, drawn flat. It shows the outline only: hidden cubes don't show. On a grid, shapes can **slide** (translate), **flip** (reflect) or **turn** (rotate). Each move has a coordinate rule, like (x, y) → (x, −y) for a flip in the x-axis. Slides, flips and turns never stretch a shape, so the image is always **congruent**: same size, same shape.
