## Part A — Choose the Answer
Circle the best answer. 1 mark each.

### [IQ1 · 1] Which inequality is non-strict?
- A) x > −2
- B) 5 < y
- C) n ≥ 0.5
- D) t < 12
=> **C.** ≥ includes the boundary, so it is non-strict.
=> Common mistakes: A, B and D use > or <, which leave the boundary out.

### [IQ1 · 1] Which means "w is at least 18"?
- A) w > 18
- B) w ≤ 18
- C) w < 18
- D) w ≥ 18
=> **D.** At least 18 means 18 or more.
=> Common mistakes: B and C read "least" as "less". A leaves 18 out.

### [IQ2 · 1] Which graph shows x ≤ 4?
- A) open dot at 4, ray to the left
- B) closed dot at 4, ray to the left
- C) closed dot at 4, ray to the right
- D) open dot at 4, ray to the right
=> **B.** ≤ lets 4 in (closed dot). "Less" is to the left.
=> Common mistakes: A leaves 4 out. C and D point the wrong way.

### [IQ2 · 1] Which inequality matches the graph?
@viz iqline value=-1 dir=right closed=0 min=-5 max=4
- A) x > −1
- B) x ≥ −1
- C) x < −1
- D) −1 > x
=> **A.** Open dot at −1, so strict. The ray goes right, so greater.
=> Common mistakes: B needs a closed dot. C and D point left.

### [IQ3 · 1] Which number is a solution of 2x − 3 > 5?
- A) 4
- B) 3
- C) 0
- D) 5
=> **D.** 2(5) − 3 = 7, and 7 > 5 is true.
=> Common mistakes: A gives 5 > 5, which is false (4 is the boundary). B gives 3 and C gives −3.

### [IQ3 · 1] Is x = −2 a solution of 1 − 3x ≥ 7?
- A) Yes, because 7 ≥ 7 is true.
- B) No, because −5 ≥ 7 is false.
- C) No, because 7 is not greater than 7.
- D) Yes, because −5 < 7.
=> **A.** 1 − 3(−2) = 1 + 6 = 7. ≥ lets equal in.
=> Common mistakes: B works out 1 − 6. C reads ≥ as >. D tests the wrong inequality.

### [IQ4 · 1] A hockey team can dress no more than 20 players. Which inequality fits, with p for players?
- A) p < 20
- B) p ≥ 20
- C) p ≤ 20
- D) p > 20
=> **C.** "No more than 20" means 20 or fewer.
=> Common mistakes: A leaves out 20. B and D are the wrong direction.

### [IQ4 · 1] A freezer must stay at −18 °C or colder. Which inequality fits, with t for temperature?
- A) t ≥ −18
- B) t ≤ −18
- C) t < −18
- D) t > −18
=> **B.** Colder means lower, and −18 itself is allowed.
=> Common mistakes: A and D point to warmer temperatures. C leaves −18 out.

## Part B — Show Your Work
Show your steps.

### [IQ1 · 3] Write each in symbols. Use the letter given. a) A bridge holds at most 5 t (m). b) More than 300 people came to the game (p). c) The temperature was −12 °C or warmer (t).
(lines 3)
=> a) m ≤ 5 (1 mark).
=> b) p > 300 (1 mark).
=> c) t ≥ −12 (1 mark).

### [IQ1 · 3] True or false? Give a reason for each. a) −2.5 ≤ −2.5 b) −7 > −3 c) {3/4} < 0.7
@viz numberline min=-8 max=1 step=1 points="-7:−7;-3:−3;-2.5:−2.5"
(lines 3)
=> a) True: they are equal, and ≤ lets equal in (1 mark).
=> b) False: −7 is to the left of −3, so it is less (1 mark).
=> c) False: {3/4} = 0.75, and 0.75 is greater than 0.7 (1 mark).

### [IQ2 · 3] Graph x > −1.5. Then name one number that is a solution and one that is not.
@viz iqline value=-1.5 dir=right closed=0 blank=1 min=-4 max=2 step=0.5 every=1 label="x > −1.5"
(lines 1)
=> Open dot at −1.5 (1 mark).
=> Ray to the right (1 mark).
=> A solution such as 0 and a non-solution such as −2 (or −1.5 itself) (1 mark).

### [IQ2 · 3] Write the inequality for the graph two ways: with x first, and with x second. Is 2 a solution?
@viz iqline value=2 dir=left closed=1 min=-3 max=6
(lines 2)
=> x ≤ 2 (1 mark).
=> 2 ≥ x (1 mark).
=> Yes: the dot is closed, so 2 is included (1 mark).

### [IQ3 · 3] Test x = −1, x = 2.5 and x = 3 in 4x + 2 ≤ 12. Which are solutions?
(work 3)
=> x = −1: 4(−1) + 2 = −2. −2 ≤ 12, so yes (1 mark).
=> x = 2.5: 4(2.5) + 2 = 12. 12 ≤ 12, so yes (1 mark).
=> x = 3: 4(3) + 2 = 14. 14 ≤ 12 is false, so no (1 mark).

### [IQ3 · 3] Jin says x = −4 is a solution of 10 − x < 12, because 10 − 4 = 6 and 6 < 12. Find his mistake. Is −4 a solution?
(lines 3)
=> He replaced x with 4, not −4 (1 mark).
=> 10 − (−4) = 10 + 4 = 14 (1 mark).
=> 14 < 12 is false, so −4 is not a solution (1 mark).

### [IQ4 · 3] Two paddlers, 68 kg and 74 kg, share a canoe. Write an inequality for the mass of gear g they can bring. Test g = 120 and g = 130.
@viz iqsign kind=limit top="CANOE" value="270 kg" unit="MAXIMUM LOAD"
(work 3)
=> 68 + 74 + g ≤ 270, or 142 + g ≤ 270 (1 mark).
=> g = 120: 142 + 120 = 262. 262 ≤ 270, so 120 kg is safe (1 mark).
=> g = 130: 142 + 130 = 272. 272 ≤ 270 is false, so 130 kg is too much (1 mark).

## Part C — Put It Together
A farmer near Camrose plants canola once the soil is at least 10 °C. She checks the soil each morning for a week.

| Mon | Tue | Wed | Thu | Fri |
|---|---|---|---|---|
| 7.5 °C | 10 °C | 12.5 °C | 9 °C | 11 °C |

### [IQ1 · 2] (a) Write an inequality for a soil temperature t that is warm enough. Is it strict or non-strict? How do you know?
(lines 2)
=> t ≥ 10 (1 mark).
=> Non-strict: "at least" lets 10 °C in (1 mark).

### [IQ2 · 2] (b) Graph your inequality.
@viz iqline value=10 dir=right closed=1 blank=1 min=5 max=15 label="t ≥ 10"
=> Closed dot at 10 (1 mark).
=> Ray to the right (1 mark).

### [IQ3 · 2] (c) On which days is the soil warm enough to plant?
(lines 1)
=> Tuesday, Wednesday and Friday (2 marks; 1 mark if one day is missing or extra).

### [IQ4 · 2] (d) She covers young plants on nights when the air is below 0 °C. Write the inequality. Does she cover them at −0.5 °C? At 0 °C?
(lines 2)
=> t < 0 (1 mark).
=> −0.5 °C: yes, because −0.5 < 0. 0 °C: no, because 0 < 0 is false (1 mark).

## Part D — Explain Your Thinking

### [IQ4 · 3] A sign at a water slide says, "Riders must be under 90 kg." Sam writes m ≤ 90. Lea writes m < 90. Who is right? Does it matter for a rider who is exactly 90 kg? Explain.
(lines 4)
=> Model answer: Lea is right. "Under 90" means less than 90, so 90 itself is not allowed: m < 90. It matters for a 90 kg rider: 90 ≤ 90 is true, so Sam's inequality lets that rider on, but 90 < 90 is false, so Lea's keeps them off, which is what the sign says.
