## Section 1: Strict and non-strict
Target: I can read and write inequalities in words and in symbols. (IQ1)
### Write in symbols: a) m is no more than 12. b) t is greater than −4. c) The Highway 2 sign, with s for speed.
@viz iqsign kind=speed value=110
(lines 2)
=> a) m ≤ 12 b) t > −4 c) s ≤ 110
### Write 7 < x with x first.
(lines 1)
=> x > 7
### Is 9 a solution of x ≤ 9? Is it a solution of x < 9? Explain how you know.
(lines 2)
=> 9 ≤ 9 is true, so yes. 9 < 9 is false, so no. ≤ lets the boundary in; < leaves it out.

## Section 2: Inequalities on a number line
Target: I can graph an inequality and write one from a graph. (IQ2)
### Graph x ≥ −2.
@viz iqline value=-2 dir=right closed=1 blank=1 min=-6 max=3 label="x ≥ −2"
(lines 1)
=> Closed dot at −2. Ray to the right.
### Write the inequality for this graph.
@viz iqline value=1.5 dir=left closed=0 min=-2 max=5 step=0.5 every=1
(lines 1)
=> x < 1.5
### Sam drew x > 0 with a ray to the left. Explain how you know he is wrong.
(lines 2)
=> Greater numbers are to the right. Test 3: 3 > 0 is true, but 3 is not on his ray.

## Section 3: Checking solutions
Target: I can check if a number is a solution by putting it in. (IQ3)
### Is x = −3 a solution of 4 − x > 6?
@viz flow steps="4 − x > 6|4 − (−3) > 6|[[7]] > 6|[[True]]"
(lines 2)
=> 4 − (−3) = 7. 7 > 6 is true. Yes.
### Is x = 2.5 a solution of 2x + 1 ≤ 5?
(lines 2)
=> 2(2.5) + 1 = 6. 6 ≤ 5 is false. No.
### x = 4 makes 3x − 2 ≥ 10 true. Does that mean every number works? Explain how you know.
(lines 2)
=> No. One test only shows that 4 works. Test 0: 3(0) − 2 = −2. −2 ≥ 10 is false.

## Section 4: Real-world inequalities
Target: I can write an inequality for a real situation and check it. (IQ4)
### A ride at Calaway Park needs riders at least 107 cm tall. Write the inequality. Can a 104 cm child ride?
@viz iqsign kind=height value=107
(lines 2)
=> h ≥ 107. 104 ≥ 107 is false. No.
### Snacks cost $4 each. Leah has no more than $18. Write an inequality for n snacks. How many can she buy?
(lines 2)
=> 4n ≤ 18. n = 4: 16 ≤ 18 true. n = 5: 20 ≤ 18 false. She can buy 0 to 4 snacks.
### Should the snacks graph be dots or a ray? Explain how you know.
(lines 2)
=> Dots. You cannot buy 2.5 snacks, so only whole numbers work.
