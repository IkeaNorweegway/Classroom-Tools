### [IQ2 · 2] Ella says x ≤ 5 and x < 5 have the same graph. Explain her mistake.
(lines 3)
=> x ≤ 5 includes 5, so its dot is closed. x < 5 leaves 5 out, so its dot is open (1 mark).
=> Both rays go left. Only the dot changes (1 mark).
