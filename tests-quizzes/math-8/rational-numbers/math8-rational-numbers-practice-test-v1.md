## Part A — Choose the Answer
Circle the best answer. 1 mark each.

### [RN1 · 1] Which number is an integer but **not** a natural number?
- A) 7
- B) 0.5
- C) −4
- D) {3/4}
=> **C.** −4 is an integer. Natural numbers are 1, 2, 3, … so negatives are not natural.
=> Common mistakes: A is natural (and also an integer). B and D are rational but not integers.

### [RN1 · 1] Which statement is true?
- A) Every integer is a rational number.
- B) Every rational number is an integer.
- C) 0 is not a rational number.
- D) −{2/5} is an integer.
=> **A.** Any integer can be written over 1, like −6 = {−6/1}.
=> Common mistakes: B mixes up the boxes ({1/2} is rational, not an integer). C: 0 = {0/1}.

### [RN2 · 1] What is {4/11} as a decimal?
- A) 0.36
- B) 0.{bar:4}
- C) 0.3{bar:6}
- D) 0.{bar:36}
=> **D.** 4 ÷ 11 = 0.363636…, and the block 36 repeats.
=> Common mistakes: A stops too soon. C puts the bar over only the 6.

### [RN2 · 1] Which number is between −0.7 and −0.6?
- A) −0.56
- B) −0.65
- C) −0.75
- D) −0.07
=> **B.** −0.7 < −0.65 < −0.6.
=> Common mistakes: A is greater than −0.6. C is less than −0.7. D is much closer to 0.

### [RN3 · 1] −{2/5} + {1/2} = ?
- A) −{1/10}
- B) {1/10}
- C) −{9/10}
- D) −{1/7}
=> **B.** −{4/10} + {5/10} = {1/10}.
=> Common mistakes: A has the wrong sign. C subtracts instead of adding. D adds the tops and the bottoms.

### [RN3 · 1] (−1.5) × (−4) = ?
- A) −6
- B) −5.5
- C) 5.5
- D) 6
=> **D.** Negative × negative = positive. 1.5 × 4 = 6.
=> Common mistakes: A has the wrong sign. B and C add instead of multiplying.

### [RN4 · 1] −8 + 12 ÷ (−4) = ?
- A) −11
- B) −1
- C) 1
- D) 5
=> **A.** Divide first: 12 ÷ (−4) = −3. Then −8 + (−3) = −11.
=> Common mistakes: B works left to right: (−8 + 12) ÷ (−4) = −1.

### [RN4 · 1] Which is the best estimate for 4.92 × (−3.1)?
- A) −12
- B) 15
- C) −15
- D) −20
=> **C.** Round to 5 × (−3) = −15.
=> Common mistakes: B has the wrong sign. A and D round too far.

## Part C — Put It Together
Mia measures the water level of a slough near Red Deer each week. The table shows the change each week, in centimetres.

| Week 1 | Week 2 | Week 3 | Week 4 |
|---|---|---|---|
| −2.5 | +{3/4} | −3.25 | −{1/2} |

### [RN2 · 2] (a) Order the four changes from least to greatest.
(lines 1)
=> −3.25, −2.5, −{1/2}, {3/4} (2 marks; 1 mark if one pair is swapped).

### [RN3 · 2] (b) Find the total change over the four weeks.
(work 2)
=> −2.5 + 0.75 + (−3.25) + (−0.5) (1 mark) = −5.5 cm (1 mark).

### [RN4 · 2] (c) Estimate the mean weekly change first. Then calculate it.
(work 2)
=> Estimate: about −6 ÷ 4 ≈ −1.5 cm (1 mark).
=> Mean: −5.5 ÷ 4 = −1.375 cm (1 mark).

### [RN3 · 2] (d) The level keeps changing by the mean for 6 more weeks. How much will it change in those 6 weeks?
(work 2)
=> (−1.375) × 6 (1 mark) = −8.25 cm, a drop of 8.25 cm (1 mark).
