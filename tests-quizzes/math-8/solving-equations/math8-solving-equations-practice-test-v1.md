## Part A — Choose the Answer
Circle the best answer. 1 mark each.

### [SE1 · 1] What is the least number you can multiply every term by to clear the fractions in {x/6} − {3/4} = 2?
- A) 24
- B) 12
- C) 10
- D) 6
=> **B.** The LCD of 6 and 4 is 12.
=> Common mistakes: A works but is not the least. C adds the denominators. D clears only {x/6}.

### [SE1 · 1] Which equation has no decimals and is equivalent to 0.6x + 1.2 = 3?
- A) 6x + 12 = 3
- B) 6x + 1.2 = 30
- C) 6x + 12 = 30
- D) 60x + 12 = 30
=> **C.** Multiply every term by 10.
=> Common mistakes: A does not multiply the 3. B does not multiply the 1.2. D multiplies 0.6 by 100.

### [SE2 · 1] Expand −5(x − 2).
- A) −5x − 10
- B) −5x − 2
- C) 5x + 10
- D) −5x + 10
=> **D.** −5 × x = −5x and −5 × (−2) = +10.
=> Common mistakes: A has the wrong sign on 10. B multiplies only the x. C drops the negative.

### [SE2 · 1] Solve 3(x + 4) = 21.
- A) x = 3
- B) x = 17
- C) x = {17/3}
- D) x = 7
=> **A.** Divide by 3: x + 4 = 7. Subtract 4: x = 3.
=> Common mistakes: D stops at x + 4 = 7. C multiplies only the x by 3. B subtracts 4 from 21.

### [SE3 · 1] Which first step keeps 7x − 4 = 3x + 8 balanced?
- A) 4x − 4 = 3x + 8
- B) 10x − 4 = 8
- C) 7x = 3x + 4
- D) 4x − 4 = 8
=> **D.** Subtract 3x from both sides.
=> Common mistakes: A takes 3x from one side only. B adds 3x on the left. C should be 7x = 3x + 12.

### [SE3 · 1] Solve 2x + 5 = 5x − 4.
- A) x = 3
- B) x = −3
- C) x = {1/3}
- D) x = {9/7}
=> **A.** Subtract 2x: 5 = 3x − 4. Add 4: 9 = 3x. x = 3.
=> Common mistakes: B is a sign slip. C divides the wrong way. D adds 2x and 5x.

### [SE4 · 1] A number is tripled, then 7 is added. The result is 1 less than 5 times the number. Which equation fits?
- A) 3(x + 7) = 5x − 1
- B) 3x + 7 = 1 − 5x
- C) 3x + 7 = 5x − 1
- D) 3x + 7 − 1 = 5x
=> **C.** "Tripled, then 7 added" is 3x + 7. "1 less than 5 times" is 5x − 1.
=> Common mistakes: A adds 7 before tripling. B reverses "1 less than". D takes the 1 from the wrong side.

### [SE4 · 1] A gym costs $25 to join plus $12 a month. Gwen has paid $121 in all. Which equation and answer are right?
- A) 25x + 12 = 121, x = 4.36
- B) 12x + 25 = 121, x = 8
- C) 12x = 121 + 25, x = 12.17
- D) 37x = 121, x = 3.27
=> **B.** 12x + 25 = 121. 12x = 96. x = 8 months.
=> Common mistakes: A swaps the fee and the monthly cost. C adds the fee instead of subtracting. D adds the two prices.

## Part B — Show Your Work
Show your steps.

### [SE1 · 3] Solve {x/3} + {1/2} = {5/6}.
(work 3)
=> Multiply every term by 6 (1 mark).
=> 2x + 3 = 5 (1 mark).
=> 2x = 2, so x = 1 (1 mark).

### [SE1 · 3] Solve 0.15x − 0.4 = 0.35. Check your answer.
(work 3)
=> Multiply every term by 100: 15x − 40 = 35 (1 mark).
=> 15x = 75, so x = 5 (1 mark).
=> Check: 0.15(5) − 0.4 = 0.75 − 0.4 = 0.35. ✓ (1 mark).

### [SE2 · 3] Solve −{1/2}(x + 6) = 4. Check your answer.
(work 3)
=> Multiply both sides by −2: x + 6 = −8 (1 mark).
=> x = −14 (1 mark).
=> Check: −{1/2}(−14 + 6) = −{1/2}(−8) = 4. ✓ (1 mark).

### [SE2 · 3] Solve 4(x − 1) − (x + 5) = 6.
(work 3)
=> 4x − 4 − x − 5 = 6 (the − in front of the second bracket changes both signs) (1 mark).
=> 3x − 9 = 6 (1 mark).
=> 3x = 15, so x = 5 (1 mark).

### [SE3 · 3] Solve {2/3}x − 1 = {1/2}x + 2. Check your answer.
(work 3)
=> Multiply every term by 6: 4x − 6 = 3x + 12 (1 mark).
=> Subtract 3x and add 6: x = 18 (1 mark).
=> Check: {2/3}(18) − 1 = 11 and {1/2}(18) + 2 = 11. ✓ (1 mark).

### [SE3 · 3] Solve 3(x + 2) = 5x − 1.5. Your answer may be a decimal.
(work 3)
=> 3x + 6 = 5x − 1.5 (1 mark).
=> 7.5 = 2x (1 mark).
=> x = 3.75 (1 mark).

### [SE4 · 3] Candle A is 24 cm tall and burns 1.5 cm each hour. Candle B is 18 cm tall and burns 0.75 cm each hour. When will they be the same height? Check your answer in the story.
(work 3)
=> 24 − 1.5t = 18 − 0.75t (1 mark).
=> 6 = 0.75t, so t = 8 hours (1 mark).
=> Check: A: 24 − 12 = 12 cm. B: 18 − 6 = 12 cm. ✓ They are the same height after 8 hours (1 mark).

## Part C — Put It Together
Two shops rent kayaks at Sylvan Lake.

| Shop | Fee to rent | Price per hour |
|---|---|---|
| Lakeside | $18 | $6.50 |
| Bay Paddle | $0 | $9.50 |

### [SE3 · 2] (a) Write an equation for when the two shops cost the same for h hours. Solve it.
(work 2)
=> 18 + 6.5h = 9.5h (1 mark).
=> 18 = 3h, so h = 6 hours (1 mark).

### [SE4 · 2] (b) Check your answer in the story. Which shop is cheaper for 8 hours?
(work 2)
=> 6 hours: Lakeside 18 + 39 = $57. Bay Paddle 9.5 × 6 = $57. ✓ (1 mark).
=> 8 hours: Lakeside $70, Bay Paddle $76. Lakeside is cheaper (1 mark).

### [SE1 · 2] (c) On Tuesdays Bay Paddle charges half price. Tara paid $38 on a Tuesday. Write and solve an equation to find how many hours she rented.
(work 2)
=> {1/2}(9.5h) = 38 (1 mark).
=> Multiply both sides by 2: 9.5h = 76, so h = 8 hours (1 mark).

### [SE4 · 2] (d) Mo says, "Lakeside is always the better deal, because $6.50 is less than $9.50." Is he right? Use your answers to explain.
(lines 2)
=> No. For less than 6 hours Bay Paddle is cheaper, because Lakeside has the $18 fee (1 mark).
=> Example: 2 hours costs $31 at Lakeside and $19 at Bay Paddle (1 mark).

## Part D — Explain Your Thinking

### [SE1 · 3] To solve 0.5x + 2 = 0.25x + 3, Ivy multiplies every term by 10. Leo multiplies every term by 100. Will both get the right answer? Which choice clears all the decimals? Explain.
(lines 4)
=> Model answer: Both get x = 4, because multiplying every term on both sides by the same number keeps the equation balanced. Ivy gets 5x + 20 = 2.5x + 30, which still has a decimal, so 2.5x = 10 and x = 4. Leo gets 50x + 200 = 25x + 300, so 25x = 100 and x = 4. Only 100 clears every decimal, because 0.25 has two decimal places.
