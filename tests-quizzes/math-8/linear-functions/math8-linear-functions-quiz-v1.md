### [LF1 · 2] Count the rise and the run. Find the slope.
@viz lfslope pts="0,1;4,4" rise="[[3]]" run="[[4]]" xmin=-1 xmax=6 ymin=0 ymax=6
(lines 1)
=> Rise 3, run 4 (1 mark). m = {3/4} (1 mark).

### [LF1 · 2] Find the slope through (−2, −1) and (3, 9).
(work 3)
=> m = {9 − (−1)/3 − (−2)} (1 mark) = {10/5} = 2 (1 mark).

### [LF1 · 2] Which ski run is steeper? Show the slope of each.
@viz lfhill kind=hill rv=2 runv=5 rise="100 m" run="250 m" title="Run A" rv2=1 runv2=2 rise2="150 m" run2="300 m" title2="Run B"
(lines 2)
=> A: {100/250} = {2/5}. B: {150/300} = {1/2} (1 mark). {1/2} > {2/5}, so Run B is steeper (1 mark).

### [LF2 · 3] Find the slope through each pair. Write positive, negative, zero or undefined.

### [LF2 · 2] Is this table linear? Explain.

### [LF3 · 3] Find m and b for each line.
a) y = −4x + 1
b) y = 7 + {1/2}x
c) y = x
(lines 3)
=> a) m = −4, b = 1. b) m = {1/2}, b = 7. c) m = 1, b = 0. 1 mark each.

### [LF3 · 2] Write the equation of the line.
@viz lfgraph lines="-1/2,2" points="0,2;4,0" xmin=-2 xmax=6 ymin=-2 ymax=4
(lines 1)
=> b = 2 (1 mark). Rise −2, run 4, m = −{1/2}: y = −{1/2}x + 2 (1 mark).

### [LF3 · 3] A line has slope 2 and goes through (2, 1). Graph it. Write its equation.

(lines 1)
=> Points plotted with right 1, up 2 (1 mark). Line drawn across the grid (1 mark). y = 2x − 3 (1 mark).

### [LF3 · 2] Kim says the line y = 3x + 5 has slope 5. Explain your thinking: is she right?
(lines 2)
=> No (1 mark). 3 is the number times x, so m = 3. The 5 is b: the line crosses the y-axis at (0, 5) (1 mark).
