## Part A — Choose the Answer
Circle the best answer. 1 mark each.

### [LF1 · 1] What is the slope of the line through (2, 3) and (6, 5)?
- A) 2
- B) {1/2}
- C) −{1/2}
- D) {5/3}
=> **B.** Rise 5 − 3 = 2. Run 6 − 2 = 4. {2/4} = {1/2}.
=> Common mistakes: A is run over rise. C has the wrong sign. D divides the y by the x of one point.

### [LF1 · 1] Which ramp is the steepest?
- A) rise 1 m, run 8 m
- B) rise 2 m, run 10 m
- C) rise 3 m, run 18 m
- D) rise 1 m, run 4 m
=> **D.** Slopes: A {1/8}, B {1/5}, C {1/6}, D {1/4}. {1/4} is the greatest.
=> Common mistakes: C has the biggest rise, but also a long run.

### [LF2 · 1] What is the slope of the line through (−3, 4) and (5, 4)?
- A) 0
- B) undefined
- C) 1
- D) 8
=> **A.** Rise 4 − 4 = 0. {0/8} = 0. The line is horizontal.
=> Common mistakes: B mixes up horizontal and vertical. D is the run.

### [LF2 · 1] Line k has slope {2/5}. What is the slope of a line perpendicular to k?
- A) {2/5}
- B) −{2/5}
- C) {5/2}
- D) −{5/2}
=> **D.** Flip the fraction and change the sign.
=> Common mistakes: A is a parallel line. B only changes the sign. C only flips.

### [LF3 · 1] What is the slope of y = −{1/3}x + 4?
- A) 4
- B) {1/3}
- C) −{1/3}
- D) −3
=> **C.** The slope m is the number times x, with its sign.
=> Common mistakes: A is b. B drops the sign. D flips the fraction.

### [LF3 · 1] Which line has slope 2 and y-intercept −5?
- A) y = −5x + 2
- B) y = 2x + 5
- C) y = 2x − 5
- D) y = 2 − 5x
=> **C.** y = mx + b with m = 2 and b = −5.
=> Common mistakes: A and D swap m and b. B has the wrong sign on b.

### [LF4 · 1] What is the x-intercept of y = 2x + 6?
- A) (0, 6)
- B) (−3, 0)
- C) (3, 0)
- D) (0, −3)
=> **B.** Set y = 0: 0 = 2x + 6, so x = −3.
=> Common mistakes: A is the y-intercept. C is a sign slip. D mixes up the order of the ordered pair.

### [LF4 · 1] Which is the equation of the vertical line through (−4, 1)?
- A) x = −4
- B) y = −4
- C) y = 1
- D) x = 1
=> **A.** Every point on a vertical line has the same x.
=> Common mistakes: C is the horizontal line through the point. B and D use the wrong coordinate.

## Part B — Show Your Work
Show your steps.

### [LF1 · 3] Find the slope of the line through (−3, 5) and (1, −3).
(work 3)
=> Rise: −3 − 5 = −8 (1 mark).
=> Run: 1 − (−3) = 4 (1 mark).
=> m = {−8/4} = −2 (1 mark).

### [LF1 · 3] Find the slope of each roof. Which roof is steeper?
@viz lfhill kind=roof rv=3 runv=6 rise="3 m" run="6 m" title="Roof A" kind2=roof rv2=4 runv2=5 rise2="4 m" run2="5 m" title2="Roof B"
(lines 2)
=> Roof A: {3/6} = {1/2} (1 mark).
=> Roof B: {4/5} (1 mark).
=> Roof B is steeper, because {4/5} = 0.8 is greater than {1/2} = 0.5 (1 mark).

### [LF2 · 3] Line A goes through (0, 1) and (2, 5). Line B goes through (1, −1) and (3, 3). Line C goes through (0, 3) and (4, 1). Which two lines are parallel? Which line is perpendicular to them?
(work 3)
=> Slopes: A {4/2} = 2, B {4/2} = 2, C {−2/4} = −{1/2} (1 mark).
=> A and B are parallel: same slope (1 mark).
=> C is perpendicular to both: −{1/2} is the negative reciprocal of 2 (1 mark).

### [LF2 · 3] Is each table linear? For the linear one, give the slope.
| x | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| Table 1: y | 10 | 7 | 4 | 1 |
| Table 2: y | 1 | 2 | 5 | 10 |
(lines 2)
=> Table 1 is linear: y goes down 3 each time (1 mark).
=> Table 2 is not linear: y goes up 1, then 3, then 5 (1 mark).
=> Slope of Table 1: −3 (1 mark).

### [LF3 · 3] Write the equation of the line.
@viz lfgraph lines="3/2,-3" points="0,-3;2,0;4,3" xmin=-2 xmax=5 ymin=-4 ymax=4
(lines 1)
=> b = −3 (1 mark).
=> From (0, −3) to (2, 0): rise 3, run 2, so m = {3/2} (1 mark).
=> y = {3/2}x − 3 (1 mark).

### [LF3 · 3] Graph y = {2/3}x − 1. Name two points on your line.
@viz lfgraph keylines="2/3,-1" keypoints="0,-1;3,1;-3,-3" xmin=-4 xmax=5 ymin=-4 ymax=4
(lines 1)
=> Start at b: (0, −1) (1 mark).
=> Right 3, up 2: (3, 1) (or left 3, down 2: (−3, −3)) (1 mark).
=> A straight line through the points, across the grid (1 mark).

### [LF4 · 3] Find both intercepts of y = −2x + 5. Write them as ordered pairs.
(work 3)
=> y-intercept: x = 0 gives y = 5, so (0, 5) (1 mark).
=> x-intercept: 0 = −2x + 5, so 2x = 5 (1 mark).
=> x = 2.5, so (2.5, 0) (1 mark).

## Part C — Put It Together
A hiker in Jasper starts at a trailhead and climbs at a steady rate. The table shows her height above sea level.

| Time (h) | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| Height (m) | 1200 | 1450 | 1700 | 1950 |

### [LF4 · 2] (a) Find the rate of change. Give the units.
(lines 1)
=> 250 (1 mark) metres per hour (1 mark).

### [LF3 · 2] (b) Write an equation for her height h after t hours.
(lines 1)
=> m = 250 (1 mark), b = 1200: h = 250t + 1200 (1 mark).

### [LF4 · 2] (c) What does 1200 mean in the story? Write it as an ordered pair.
(lines 2)
=> Her height at the start, before she climbs (1 mark).
=> (0, 1200), the y-intercept (1 mark).

### [LF4 · 2] (d) The summit is 2450 m above sea level. When does she reach it?
(work 2)
=> 250t + 1200 = 2450, or extend the table by 250 each hour (1 mark).
=> t = 5 hours (1 mark).

## Part D — Explain Your Thinking

### [LF2 · 3] Ali says the lines y = 3x + 1 and y = 3x − 2 must cross somewhere, "because all lines cross if you go far enough." Is he right? Explain.
(lines 4)
=> Model answer: No. Both lines have slope 3, so they are parallel. They start at different y-intercepts (1 and −2), and each one goes up 3 for every 1 across, so they stay 3 apart forever. At x = 10, for example, they are at 31 and 28. Parallel lines never cross.
