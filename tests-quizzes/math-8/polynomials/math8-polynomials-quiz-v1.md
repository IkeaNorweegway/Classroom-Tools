### [PO1 · 2] Write 4x³ as a product of factors. Then write −1 · x · x as a term.
@viz poterm c="4" v="x" e="3" clabel="coefficient" elabel="exponent"
(lines 1)
=> 4 · x · x · x (1 mark). −x² (1 mark).

### [PO1 · 3] Write in conventional form. a) 1x³ b) −1x¹ c) 2x² + 9x⁰
(lines 2)
=> a) x³ b) −x c) 2x² + 9. 1 mark each.

### [PO1 · 2] Name the coefficient and the exponent of each term. a) −7x b) x²
(lines 1)
=> a) coefficient −7, exponent 1 (1 mark). b) coefficient 1, exponent 2 (1 mark).

### [PO2 · 3] Is each a polynomial? Write yes or no. a) 3x² − 1 b) {2/x} + x c) −9
(lines 2)
=> a) yes b) no ({2/x} = 2x⁻¹, a negative exponent) c) yes (a constant). 1 mark each.

### [PO2 · 3] Name the polynomial the tiles show. Give the number of terms, the degree, and the name by degree.
@viz potiles rows="2x2;-x;-4"
(lines 2)
=> 2x² − x − 4 (accept any order). Trinomial (1 mark). Degree 2 (1 mark). Quadratic (1 mark).

### [PO2 · 2] Ben says x³ − 5 has degree 2 because it has two terms. Explain his mistake. Give the degree.
(lines 2)
=> Degree is the highest exponent, not the number of terms (1 mark). The degree is 3 (1 mark).

### [PO3 · 2] Circle the like terms: 5x², 5x, −2x², 5, x³.

### [PO3 · 3] Simplify 2x³ + 4x − x³ + 6 − 7x. Write the answer in descending order.
(lines 2)
=> x³ (1 mark), −3x (1 mark), +6. Answer in order: x³ − 3x + 6 (1 mark).

### [PO3 · 2] Write −3x + x² + 8 in descending order and in ascending order.

(lines 1)
=> Descending: x² − 3x + 8 (1 mark). Ascending: 8 − 3x + x² (1 mark).
