## Section 1: Terms, coefficients and powers
Target: I can write a term as a coefficient times a power of x. (PO1)
### Name the coefficient and the exponent of the term in the picture. Then write it as a product of factors.
@viz poterm c="−5" v="x" e="2" clabel="coefficient" elabel="exponent"
(lines 1)
=> Coefficient −5. Exponent 2. −5x² = −5 · x · x.
### Write in conventional form: a) 1x² b) 3x¹ c) 8x⁰
(lines 1)
=> a) x² b) 3x c) 8
### Is x³ the same as 3x? Explain how you know.
(lines 2)
=> No. x³ = x · x · x, but 3x = x + x + x. With x = 2: x³ = 8 and 3x = 6.

## Section 2: Naming polynomials
Target: I can tell if an expression is a polynomial. I can name it by its terms and degree. (PO2)
### Name the polynomial the tiles show. Give its number of terms and its degree.
@viz potiles rows="x2;-3x;+2"
(lines 1)
=> x² − 3x + 2: a trinomial of degree 2 (quadratic).
### Is 2x² + {5/x} a polynomial?
(lines 1)
=> No. {5/x} = 5x⁻¹. The exponent −1 is not a counting number.
### Leah says 6 + x³ has degree 2. Explain how you know she is wrong.
(lines 2)
=> Degree is the highest exponent, not the number of terms. The exponents are 0 and 3. The degree is 3.

## Section 3: Like terms and order
Target: I can find like terms, combine them, and write a polynomial in order. (PO3)
### Simplify 4x² − 3x + 2 − x² + 5x. Write it in descending order.
@viz posort bins="x² terms:4x²,−x²;x terms:−3x,+5x;constants:+2" totals="[[3x²]];[[+2x]];[[+2]]"
(lines 1)
=> 3x² + 2x + 2
### Write 7 − x + 2x³ in ascending order and in descending order.
(lines 1)
=> Ascending: 7 − x + 2x³. Descending: 2x³ − x + 7.
### Can 2x² + 3x be simplified to 5x³? Explain how you know.
(lines 2)
=> No. 2x² and 3x are not like terms: their exponents differ. Adding never changes an exponent. It stays 2x² + 3x.

## Section 4: Adding and subtracting
Target: I can add and subtract polynomials by combining like terms. (PO4)
### Add (x² + 4x − 3) + (2x² − x + 5).
@viz postack heads="x²;x;1" rows="x²;+4x;−3 | +2x²;−x;+5" op="+" result="[[3x²]];[[+3x]];[[+2]]"
(lines 1)
=> 3x² + 3x + 2
### Subtract (6x + 1) − (2x − 4).
(lines 1)
=> 6x + 1 − 2x + 4 = 4x + 5
### Max writes (3x − 2) − (x + 5) = 2x + 3. Explain how you know he is wrong.
(lines 2)
=> Subtract every term: 3x − 2 − x − 5 = 2x − 7. He did not flip the sign of +5.
