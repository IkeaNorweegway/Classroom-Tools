## Section 1: One-step equations
Target: I can solve one-step equations with inverse operations. (LE1)
### Solve and verify: −6x = 42
(work 1)
=> x = −7; −6(−7) = 42 ✓
### Solve: {x/8} = 3
(lines 1)
=> x = 24

## Section 2: Two-step equations
Target: I can solve two-step equations by undoing in reverse order. (LE2)
### Solve and verify: 5x − 4 = 26
(work 2)
=> 5x = 30, x = 6; 5(6) − 4 = 26 ✓
### Which step do you do first in {x/3} + 5 = 9? Why?
(lines 2)
=> Subtract 5 first, because + 5 was the last thing done to x.

## Section 3: Equations with brackets
Target: I can solve equations with brackets. (LE3)
### Solve 4(x − 2) = 20 two ways.
(work 3)
=> Divide: x − 2 = 5, x = 7. Expand: 4x − 8 = 20, 4x = 28, x = 7.

## Section 4: Writing and checking equations
Target: I can write and solve an equation for a problem. (LE4)
### A school trip costs $50 for the bus plus $8 per student. The total is $290. How many students went? Write the equation, solve and answer in words.
(work 3)
=> 8s + 50 = 290, 8s = 240, s = 30. Thirty students went.
