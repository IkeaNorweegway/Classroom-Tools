## Section 1: Perfect and non-perfect squares
Target: I can tell if a fraction or decimal is a perfect square. (SR1)
### Write as repeated multiplication and as a power: the overlap in the area model.
@viz area a=3/5 b=3/5 result="[[3/5 × 3/5]] = [[(3/5)²]] = [[9/25]]"
=> {3/5} × {3/5} = ({3/5})² = {9/25}
### Perfect square or not? a) {36/81} b) 0.8
(lines 1)
=> a) Yes: ({6/9})² = ({2/3})². b) No: 0.8 = {4/5}, and 5 is not a perfect square.
### Is 0.81 a perfect square? Explain how you know.
(lines 2)
=> Yes. 0.81 = {81/100}, and 81 = 9² and 100 = 10². So 0.81 = 0.9².

## Section 2: Two square roots (±)
Target: I can find both square roots of a number. (SR2)
### Find each value: a) √81 b) −√81 c) ±√{4/9}
@viz numberline min=-10 max=10 every=2 keypoints="-9:−9;9:9"
=> a) 9 b) −9 c) ±{2/3}
### Solve x² = 0.25.
(lines 1)
=> x = ±0.5
### Does √−25 have a real answer? Explain how you know.
(lines 2)
=> No. 5² = 25 and (−5)² = 25. No real number times itself is negative.

## Section 3: Estimating square roots
Target: I can estimate a square root, then check it. (SR3)
### Estimate √85 to one decimal place.
@viz srbench lo=9 hi=10 n=85 keydot=1 est="√85 ≈ [[9.2]]"
(lines 1)
=> 81 < 85 < 100, closer to 81. 9.2² = 84.64. √85 = 9.219… ≈ 9.2.
### A square garden has an area of 30 m². Find its side to the nearest tenth.
(lines 1)
=> √30 = 5.477… ≈ 5.5 m
### Is √50 about 25, 7.5 or 7.1? Explain how you know.
(lines 2)
=> 7.1. 7² = 49 is just under 50, so √50 is just over 7. (25² = 625 and 7.5² = 56.25 are both too big.)

## Section 4: Irrational numbers and the real number line
Target: I can sort and order rational and irrational numbers. (SR4)
### Mark each number with its letter. Then order them: **A** = √5 · **B** = 2.{bar:2} · **C** = 2.3 · **D** = 2.2
@viz numberline min=2.1 max=2.35 step=0.01 every=0.05 width=600 keypoints="2.2361:A;2.2222:B;2.3:C;2.2:D"
(lines 1)
=> √5 ≈ 2.236, 2.{bar:2} = 2.222… Order: 2.2, 2.{bar:2}, √5, 2.3.
### Rational or irrational? a) √100 b) √10 c) 3.14
(lines 1)
=> a) rational (10) b) irrational c) rational (it ends)
### Is π equal to 3.14? Explain how you know.
(lines 2)
=> No. π = 3.14159… never ends or repeats. 3.14 ends, so it is only an approximation: π ≈ 3.14.
