## Part A — Choose the Answer
Circle the best answer. 1 mark each.

### [SR1 · 1] Which number is a perfect square?
- A) 0.4
- B) {2/9}
- C) 50
- D) {25/36}
=> **D.** {25/36} = ({5/6})².
=> Common mistakes: A: 0.4 = {4/10}, and 10 is not a perfect square. B: 2 is not a perfect square.

### [SR1 · 1] 1.2² = ?
- A) 2.4
- B) 1.44
- C) 14.4
- D) 0.144
=> **B.** 1.2 × 1.2 = 1.44.
=> Common mistakes: A doubles. C and D put the decimal point in the wrong place.

### [SR2 · 1] √{81/100} = ?
- A) {9/10}
- B) ±{9/10}
- C) {81/50}
- D) {9/100}
=> **A.** ({9/10})² = {81/100}. The √ sign means the positive root only.
=> Common mistakes: B: ± belongs to solving x² = {81/100}, not to √. C halves the bottom.

### [SR2 · 1] How many real square roots does −16 have?
- A) two: 4 and −4
- B) one: −4
- C) none
- D) one: 4
=> **C.** 4² = 16 and (−4)² = 16. No real number squared gives −16.
=> Common mistakes: B: (−4)² is +16, not −16.

### [SR3 · 1] √40 is between which two whole numbers?
- A) 20 and 21
- B) 5 and 6
- C) 6 and 7
- D) 7 and 8
=> **C.** 36 < 40 < 49, so 6 < √40 < 7.
=> Common mistakes: A halves 40. B: 6² = 36 is still less than 40.

### [SR3 · 1] Which is the best estimate for √99?
- A) 9.9
- B) 9.5
- C) 10.1
- D) 49.5
=> **A.** 99 is just below 100, so √99 is just below 10.
=> Common mistakes: B uses halfway. C: 10.1² is more than 100. D halves 99.

### [SR4 · 1] Which number is irrational?
- A) 0.{bar:12}
- B) √49
- C) −{5/3}
- D) √13
=> **D.** 13 is not a perfect square, so √13 never ends or repeats.
=> Common mistakes: A repeats, so it is rational. B = 7.

### [SR4 · 1] Which value is exact, not rounded?
- A) 3.14 for π
- B) √5
- C) 2.24 for √5
- D) 1.41 for √2
=> **B.** √5 is the exact number. 3.14, 2.24 and 1.41 are rounded.

## Part C — Put It Together
Leah is planning a square community garden in Lethbridge. The garden will have an area of 50 m².

### [SR3 · 2] (a) Estimate the side length, √50, to one decimal place. Show your benchmarks.
(lines 2)
=> 49 < 50 < 64, and 50 is very close to 49 (1 mark).
=> √50 ≈ 7.1 m (1 mark; 7.0 or 7.1 accepted with a check).

### [SR4 · 2] (b) Is √50 rational or irrational? Is your answer to (a) exact or approximate?
(lines 2)
=> Irrational: 50 is not a perfect square, so √50 never ends or repeats (1 mark).
=> 7.1 is approximate (rounded) (1 mark).

### [SR3 · 2] (c) Fencing is sold in 1 m pieces. How many pieces does Leah need to go all the way around?
(work 2)
=> Perimeter ≈ 4 × 7.07 ≈ 28.3 m (or 4 × 7.1 = 28.4 m) (1 mark).
=> She needs 29 pieces: 28 pieces would be too short (1 mark).

### [SR4 · 2] (d) Order from least to greatest: 7.1, √48, 6.9, √50. Show how squaring helps.
(lines 2)
=> 6.9² = 47.61 and 7.1² = 50.41. So 47.61 < 48 < 50 < 50.41 (1 mark).
=> 6.9, √48, √50, 7.1 (1 mark).

## Part D — Explain Your Thinking

### [SR2 · 3] Ty says, "√49 = ±7, because both 7 and −7 squared make 49." Explain the difference between √49 and solving x² = 49.
(lines 4)
=> Model answer: √49 means the principal (positive) root, so √49 = 7. The equation x² = 49 asks for every number that squares to 49, so x = 7 or x = −7, written x = ±7. Ty is right that both square to 49, but the √ sign alone gives only 7.
