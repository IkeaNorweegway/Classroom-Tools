# Linear Equations and Inequalities — Mid-Unit Quiz — Answer Key
Teacher use only · Keep off student copies

1. 2x = 12, so **x = 6**. (2 marks)
2. x − 2 = 4, so **x = 6**. (2 marks)
3. −2x < 6, divide by −2 and reverse the sign: **x > −3**. (2 marks)
4. Open circle at −3, arrow pointing right (−3 is not included). (2 marks)
5. **5t + 3 = 28.** (2 marks)
6. 5t = 25, so **t = 5** tickets. (2 marks)
7. Ana bought 5 tickets. Any answer that connects the value of t to the number of tickets. (2 marks)
8. 4x ≥ 8, so **x ≥ 2**. (2 marks)

**Common errors to watch for:** forgetting to reverse the inequality when dividing by a negative (Q3); answering with the equation's solution but not the context (Q7).
