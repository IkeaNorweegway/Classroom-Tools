## Part B — Short Answer

**9.** 5 − x/2 = 9, so −x/2 = 4, so x = **−8**. Verify: 5 − (−8)/2 = 5 + 4 = 9 ✓
- 1 mark: subtracts 5 (−x/2 = 4)
- 1 mark: x = −8
- 1 mark: substitutes −8 into the original equation and gets 9

**10.** 6x − 3 = 4x + 9, so 2x − 3 = 9, so 2x = 12, so x = **6**.
- 1 mark: expands to 6x − 3
- 1 mark: collects terms (2x = 12)
- 1 mark: x = 6

**11.** The student only multiplied the x by 4: 4(x − 3) is 4x − 12, not 4x − 3. Correct: 4x − 12 = 2x + 6, so 2x = 18, so x = **9**.
- 1 mark: names the error

- 1 mark: x = 9

**12.** Multiply every term by 10: 5x + 2x = 70, so 7x = 70, so x = **10**.
- 1 mark: multiplies every term by 10 (or another common multiple)
- 1 mark: 7x = 70
- 1 mark: x = 10

**13.** Multiply by 10: 6x − 15 = 3x + 9, so 3x = 24, so x = **8**. (Or with decimals: 0.3x = 2.4.)
- 1 mark: clears the decimals or collects terms
- 1 mark: 3x = 24 (or 0.3x = 2.4)

**14.** 3x ≤ 12, so **x ≤ 4**. Graph: closed circle at 4, shaded to the left.

**15.** −2x < 6. Divide by −2 and flip: **x > −3**. Graph: open circle at −3, shaded to the right.
- 1 mark: −2x < 6

**16.** (a) 5 − 3(−2) = 5 + 6 = 11, and 11 > 10, so **yes**.
- 1 mark

(b) −3x > 5, so x < −5/3 (about −1.67). −2 is less than −5/3, so **yes, it agrees**.
- 1 mark: x < −5/3 (with the flip)

**17.** Let n = the first integer. n + (n + 1) + (n + 2) = 72, so 3n + 3 = 72, so n = 23. The integers are **23, 24 and 25**.

**18.** Let v = the number of visits. 40 + 12v ≤ 160, so 12v ≤ 120, so v ≤ 10. **Maya can afford at most 10 visits.**

## Part D — Thinking

**20.** Model answer: Ali is not correct. In x − 4 > −6 there are negative numbers, but I add 4 to both sides and get x > −2. No flip is needed. Check: x = 0 works (0 − 4 = −4, which is greater than −6). In −2x > 6 I divide both sides by −2, so I flip: x < −3. Check: x = −4 gives 8 > 6 ✓, but x = 0 gives 0 > 6 ✗, so the flip was needed. The sign flips only when you multiply or divide both sides by a negative number, because that reverses the order of numbers: 2 < 3, but −2 > −3.
