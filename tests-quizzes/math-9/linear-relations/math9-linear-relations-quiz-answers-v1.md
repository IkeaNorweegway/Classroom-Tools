# Linear Relations — Mid-Unit Quiz — Answer Key
Teacher use only · Keep off student copies

1. **y = 3x + 2.** (2 marks: slope 3, intercept 2)
2. **Slope = 3.** Each increase of 1 in x gives an increase of 3 in y: the rate of change. (2 marks: value, meaning)
3. **y-intercept = 2.** When x = 0, y = 2: the starting value. (2 marks: value, meaning)
4. y = 3(10) + 2 = **32**. (2 marks)
5. Slope = (10 − 4) ÷ (2 − 0) = **3**. (2 marks)
6. **7.** (2 marks)
7. 20 = 3x + 2, so 3x = 18 and **x = 6**. (2 marks)
8. The y-values increase by the same amount (3) each time x goes up by 1, so the rate is constant. (2 marks)

**Common errors to watch for:** slope given as 2 instead of 3 (Q2); y-intercept given as the x-value (Q3); confusing the slope with the y-intercept (Q5, Q6).
