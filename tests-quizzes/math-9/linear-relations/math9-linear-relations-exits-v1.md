# Answer Key — Linear Relations Exit Tickets

## Section 1
1. Each time x increases by 1, y increases by 2 (slope = 2). At x = 0, y = 3 (y-intercept). Equation: y = 2x + 3.
2. With the equation, you can: find y for any x instantly (e.g., x = 50 → y = 103); identify the slope and starting value; determine when y equals a specific target value; compare patterns from different tables.

## Section 2
1. slope = (13 − 5)/(6 − 2) = 8/4 = 2. For every 1-unit increase in x, y increases by 2.
2. Slope of −3: line falls steeply left-to-right. Real-world example: a car's fuel level drops 3 litres per hour of driving (y = litres remaining, x = hours). The −3 represents a decrease of 3 units per unit increase in x.

## Section 3
1. slope = −2, y-intercept = 7. Parallel line through origin: y = −2x (same slope, no y-intercept means b = 0).
2. 50 = rate of saving ($50 per week). 200 = starting amount ($200 already saved). After 6 weeks: y = 50(6) + 200 = 500.

## Section 4
1. First taxi: direct variation, y = 2.5x (passes through origin). Second taxi: partial variation, y = 3x + 5 (non-zero y-intercept).
2. Direct variation: line passes through the origin (0, 0) — when x = 0, y = 0. Partial variation: line has a non-zero y-intercept — when x = 0, there is still a starting value. The y-intercept in partial variation is the fixed/initial amount before any variable change happens.
