# Polynomials — Mid-Unit Quiz — Answer Key
Teacher use only · Keep off student copies

1. (3x + 2) + (x − 5) = **4x − 3**. (2 marks)
2. (5x² + 2x) − (2x² + 7x) = **3x² − 5x**. (2 marks)
3. (x + 2)(x + 3) = x² + 3x + 2x + 6 = **x² + 5x + 6**. (2 marks)
4. (x − 4)(x + 1) = x² + x − 4x − 4 = **x² − 3x − 4**. (2 marks)
5. A rectangle with sides x + 2 and x + 3, split into x² (1 tile), x (5 tiles) and 1 (6 tiles) regions. Accept any correct labelled area model. (2 marks)
6. The x² tile is the area of a square with side x. (2 marks)
7. 2(x + 4) − (x − 1) = 2x + 8 − x + 1 = **x + 9**. (2 marks)
8. Like terms have the same variable raised to the same power, e.g. 3x and x in Question 1. (2 marks)

**Common errors to watch for:** multiplying only the first terms in Q3 and Q4 (FOIL errors); losing the sign on subtracting a bracket (Q2, Q7).
