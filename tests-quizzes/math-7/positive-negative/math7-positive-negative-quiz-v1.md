### [PN1 · 2] Find the opposite and the absolute value of −6.5.
(lines 1)
=> Opposite: 6.5 (1 mark). |−6.5| = 6.5 (1 mark).

### [PN1 · 2] Read the thermometer. How many degrees from 0 °C is it?
@viz thermo min=-25 max=5 step=5 values="-20" labels="Fort McMurray"
(lines 1)
=> −20 °C (1 mark). |−20| = 20, so it is 20 degrees from 0 (1 mark).

### [PN1 · 2] Noor's bank balance is −$8.40. Use absolute value to say how much she owes.
(lines 1)
=> |−8.40| = 8.40 (1 mark). She owes $8.40 (1 mark).

### [PN2 · 3] Write the number at each point.
@viz numberline min=-2 max=1 step=0.25 every=1 points="-1.75:A;-0.25:B;0.5:C"
(lines 1)
=> A = −1.75 or −1{3/4}; B = −0.25 or −{1/4}; C = 0.5 or {1/2} (1 mark each).

### [PN3 · 3] Write each fraction as a decimal: {3/4}, −{2/5}, −{1/8}
(lines 2)
=> 0.75, −0.4, −0.125 (1 mark each).

### [PN3 · 3] Write each decimal as a fraction in simplest form: 0.5, −0.75, −0.04
(lines 2)
=> {1/2}, −{3/4}, −{1/25} (1 mark each). −0.04 = −{4/100} = −{1/25}.

### [PN3 · 3] Omar says {3/5} = 3.5. Is he right? Explain your thinking.
(lines 3)
=> No (1 mark). {3/5} means 3 ÷ 5 = 0.6 (1 mark). {3/5} is less than 1, but 3.5 is more than 3 (1 mark for a reason that uses size or division).
