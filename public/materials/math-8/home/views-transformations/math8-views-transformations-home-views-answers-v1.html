Top, Front and Side Views — Answers

One skill: drawing the views of an object built from blocks · about 15 minutes

Need a reminder? See the filled-in class notes: Section 1: Top, front and side views

For the adult: If a view has more squares than you can see from that direction, hidden blocks were counted.

1. Top view: 1 square. Front view: 1 column, 3 squares tall.

2. Top view: an L of 3 squares (2 in the front row, 1 behind the left one).

3. Front view: 2 squares side by side (the back block hides behind the front-left one). Right side view: 2 squares side by side (front and back).

4. Answers vary. The test is whether someone else can build the same shape from the three views.
