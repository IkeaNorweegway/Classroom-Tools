Part A — Choose the Answer

Circle the best answer. [1 mark each]   /8

1. A pattern goes 4, 7, 10, 13. How much does it go up each time?

A) 4B) 3C) 7D) 1
Answer B · Why: 7 − 4 = 3 · Common mistakes: A: used the first number

2. In the pattern 4, 7, 10, 13, Figure 1 has 4. How many would Figure 0 have?

A) 1B) 0C) 3D) 4
Answer A · Why: Go back 3 from 4: 1 · Common mistakes: B: thinks Figure 0 is always 0

3. Which equation matches the table?

x1234
y57911
A) y = x + 2B) y = 3x + 2C) y = 2x + 5D) y = 2x + 3
Answer D · Why: Up by 2 means 2x; 2(1) + 3 = 5 · Common mistakes: A: "up by 2" written as + 2

4. For y = 4x − 1, what is y when x = 5?

A) 20B) 21C) 19D) 9
Answer C · Why: 4(5) − 1 = 19 · Common mistakes: B: added 1

5. Which point is on the relation y = 2x + 3?

A) (2, 7)B) (1, 6)C) (3, 8)D) (4, 10)
Answer A · Why: 2(2) + 3 = 7

6. You graph the number of tickets sold and the money raised. How should you show the points?

A) connect them with a lineB) as a circle graphC) as a bar graphD) dots only, not joined
Answer D · Why: You can't sell part of a ticket, so the points stay as dots · Common mistakes: A: connects counted data

7. A graph starts at 40 and goes down 5 each step. The relation is

A) increasing, starts at 5B) decreasing, starts at 40C) increasing, starts at 40D) decreasing, starts at 5
Answer B · Why: Goes down, starts at 40 · Common mistakes: D: mixed up the start and the change

8. A candle's height is h = 50 − 4t, where t is hours. How tall is it after 6 hours?

A) 24 cmB) 46 cmC) 26 cmD) 74 cm
Answer C · Why: 50 − 4(6) = 50 − 24 = 26 · Common mistakes: B: subtracted 4 only

[3]10. Write an equation for the toothpick pattern in Question 9. Use t for toothpicks and n for the figure number. Check your equation with Figure 3.

Answer t = 3n + 1. Check Figure 3: 3(3) + 1 = 10 ✓
  • 1 mark: 3n (the "up by 3")
  • 1 mark: + 1
  • 1 mark: the check

11. A pizza costs c = 2k + 10 dollars, where k is the number of toppings.

[1](a) Find the cost with 4 toppings.

[2](b) A pizza costs $22. How many toppings does it have?

Answer (a) 2(4) + 10 = $18
  • 1 mark

(b) 22 = 2k + 10, so 2k = 12, so k = 6 toppings. (Or guess and check: 2(6) + 10 = 22.)

  • 1 mark: method
  • 1 mark: 6

[3]12. Ana wrote y = x + 3 for this table.

x123
y4710

1. Check Ana's equation with x = 2. 2. Write the right equation. 3. Check it.

Answer Check x = 2: y = 2 + 3 = 5, but the table says 7, so Ana is wrong. The table goes up by 3, so the equation is y = 3x + 1. Check: 3(2) + 1 = 7 ✓
  • 1 mark: shows Ana's equation fails
  • 1 mark: y = 3x + 1
  • 1 mark: a check

y

[3]14. Do these points make a linear relation? Explain how you know.

x1234
y35810
Answer No. The y-values go up by 2, then 3, then 2. A linear relation goes up by the same amount each time.
  • 1 mark: finds the changes
  • 1 mark: notices they are not equal
  • 1 mark: says no

16. A bowling alley in Calgary charges $6 to rent shoes, plus $4 for each game.

[2](a) Complete the table.

Games01234
Cost ($)

[2](b) Write an equation for the cost, C, of g games.

[2](c) Graph the relation. Should you join the points? Why?

[2](d) Jon has $38. How many games can he bowl? Show how you know.

Answer (a) 6, 10, 14, 18, 22
  • 2 marks: all five (1 mark for three or four)

(b) C = 4g + 6

  • 1 mark: 4g
  • 1 mark: + 6

(c) Five points in a line: (0, 6), (1, 10), (2, 14), (3, 18), (4, 22). Don't join them: you can only bowl whole games.

  • 1 mark: points plotted
  • 1 mark: dots only, with the reason

(d) 4g + 6 = 38, so 4g = 32, so g = 8 games. (Or extend the table to 8 games: $38.)

  • 1 mark: method
  • 1 mark: 8 games

17. A pattern goes 7, 12, 17, 22. Figure 1 has 7. Dev says:

“It goes up by 5, so the equation is y = x + 5.”

Is Dev right? Check his equation, then write the right one.

Answer Model answer: Dev is not right. Check Figure 1: 1 + 5 = 6, but Figure 1 has 7. Going up by 5 each time means 5 × the figure number: 5x. 5(1) = 5, so we need 2 more. The equation is y = 5x + 2. Check: 5(2) + 2 = 12 ✓
