Part A — Choose the Answer/8

Circle the best answer. 1 mark each.

1.
Which term has coefficient −1 and exponent 2?
A−2x
B−x²
Cx²
D−x
Answer B. −x² means −1 · x · x.
Common mistakes: A swaps the numbers (coefficient −2, exponent 1). C has coefficient +1. D has exponent 1.

2.
Which is 3 · x · x · x written as a term?
A3x
Bx³
C9x
D3x³
Answer D. The number factor 3 is the coefficient. There are three x's, so x³.
Common mistakes: A counts only one x. B drops the 3. C multiplies 3 × 3.
PO1[1]
3.
Which expression is not a polynomial?
Ax² − 7
B5
C4x + 3/x²
D1/2x
Answer C. 3/x² has x in the denominator, so its exponent is −2, not a counting number.
Common mistakes: D: a fraction coefficient is fine. B: a constant is a polynomial of degree 0.
PO2[1]
4.
What is the degree of 6x − 2x³ + x² + 9?
A3
B4
C6
D1
Answer A. The exponents are 1, 3, 2 and 0. The highest is 3.
Common mistakes: B counts the terms. C uses the first coefficient. D uses the first term's exponent.
PO2[1]
5.
Which pair are like terms?
A4x² and 4x
B−3x and 7x
Cx³ and 3x
D5 and 5x
Answer B. Same variable and same power (x¹). The coefficients can differ.
Common mistakes: A and D match the coefficient, not the power. C mixes up x³ and 3x.
PO3[1]
6.
Simplify 5x − 2 − 8x + 6.
A−3x + 4
B3x + 4
C−3x − 8
D13x + 4
Answer A. 5x − 8x = −3x. −2 + 6 = 4.
Common mistakes: B drops the sign of −8x. C does −2 − 6. D adds 5x and 8x.
PO3[1]
7.
(2x² + x) + (x² − 4x) = ?
A3x² + 5x
B3x⁴ − 3x
C3x² − 3x
D2x² − 3x
Answer C. 2x² + x² = 3x². x − 4x = −3x.
Common mistakes: B adds the exponents. A uses +4x. D forgets the x² in the second bracket.

8.
What is the opposite (additive inverse) of 3x² − x + 5?
A3x² + x − 5
B−3x² − x + 5
C−3x² + x + 5
D−3x² + x − 5
Answer D. Change the sign of every term.
Common mistakes: A, B and C change only some of the signs.

13.
Simplify x³ − 4x² + 2x + 3x² − x³ + 5. Write the answer in descending order.
Answer x³ − x³ = 0, so the x³ terms drop out (1 mark).
−4x² + 3x² = −x² (1 mark).
−x² + 2x + 5 (1 mark).
PO3[3]
14.
Nadia says 4x + 3x² + 2 simplifies to 9x³. Test x = 2 in both. Explain her mistake. Write the polynomial in descending order.
Answer x = 2: 4(2) + 3(4) + 2 = 22, but 9(8) = 72. They are not equal (1 mark).
4x, 3x² and 2 are not like terms, so they cannot combine (1 mark).
3x² + 4x + 2 (1 mark).
PO3[3]
15.
Subtract (2x² − 5x + 3) − (−x² + x − 4).
Answer Add the opposite: 2x² − 5x + 3 + x² − x + 4 (1 mark).
x²: 2x² + x² = 3x². x: −5x − x = −6x. Constants: 3 + 4 = 7 (1 mark).
3x² − 6x + 7 (1 mark).

A school in Fort McMurray is planning two rectangular gardens. The side lengths are in metres.

GardenLengthWidth

B2x + 5x

Name the polynomial for the length of Garden A by its number of terms and by its degree.
Answer Binomial (1 mark). Degree 2, quadratic (1 mark).

(b)
Find the perimeter of Garden A. Simplify.
Answer (x² + 2x) + (3x − 1) + (x² + 2x) + (3x − 1) (1 mark).

(c)
Find the perimeter of Garden B. Then find Perimeter A − Perimeter B.
Answer Perimeter B: (2x + 5) + x + (2x + 5) + x = 6x + 10 (1 mark).
(2x² + 10x − 2) − (6x + 10) = 2x² + 4x − 12 (1 mark).

Part D — Explain Your Thinking/3

17.
Theo says (5x² − 2x) − (3x² − 2x) = 2x² − 4x. Is he right? Find the right answer and explain.
Answer Model answer: No. Subtracting means adding the opposite of every term: 5x² − 2x − 3x² + 2x = 2x². Theo did not change −2x to +2x. Check with x = 1: 5 − 2 = 3 and 3 − 2 = 1, so the answer is 2. 2x² gives 2, but 2x² − 4x gives −2.
