Square Roots & Irrational Numbers

Core Practice ★ — Answer Key

Answer key · Teacher copy
1★ Core

Write each as repeated multiplication and as a power. Then find the value.

  1. a) A square Lego plate with 6 studs on each side
  2. b) A square tile with sides of 0.4 m
Answer a) 6 × 6 = 6² = 36 studs. (SR1)
b) 0.4 × 0.4 = 0.4² = 0.16 m².
2★ Core

Perfect square or not? Explain each one.

  1. a) 16/25 b) 3/4 c) 0.49 d) 0.5
Answer a) Yes: 16 = 4² and 25 = 5², so 16/25 = (4/5)². (SR1)
b) No: 3 is not a perfect square. c) Yes: 0.49 = 49/100 = 0.7².
d) No: 0.5 = 1/2, and 2 is not a perfect square.
3★ Core

Use the area model to show that 4/9 is a perfect square.

Answer Shade 2/3 of the rows and 2/3 of the columns. The overlap is 4/9. So 4/9 = (2/3)². (SR1)
4★ Core

Kai says √64 = 32, because it is half of 64. Show he is wrong.

Answer √64 = 8, because 8 × 8 = 64. 32 × 32 = 1024, not 64. The root is the side of the square, not half the number. (SR1)
Targets the "square root is half" mix-up.
5★ Core

Find both square roots of each number.

  1. a) 36 b) 1/9 c) 0.64 d) 0
Answer a) 6 and −6. b) 1/3 and −1/3. (SR2)
c) 0.8 and −0.8. d) Only 0, because 0 × 0 = 0.
6★ Core

Find each value.

  1. a) √121 b) −√121 c) ±√121 d) √−121
Answer a) 11 (the principal root). b) −11. c) ±11, which means 11 and −11. (SR2)
d) No real answer. 11² = 121 and (−11)² = 121. No real number squared gives −121.
Targets "√25 = ±5" (a) and "√−9 = −3" (d).
7★ Core

Mo writes √−16 = −4. Use the mapping to explain his mistake.

Answer (−4) × (−4) = 16, not −16. Both 4 and −4 square to 16. Nothing squares to −16, so √−16 has no real answer. (SR2)
Targets the "√−9 = −3" mix-up.
8★ Core

Solve each equation.

  1. a) x² = 100 b) x² = 25/49 c) x² = 0.09
Answer a) x = ±√100 = ±10. b) x = ±5/7. c) x = ±0.3. (SR2)
9★ Core

Estimate √40 to one decimal place. Then check with a calculator.

Answer Benchmarks: 6² = 36 and 7² = 49. 40 is 4 past 36 and 9 below 49, so closer to 6. (SR3)
Try 6.3: 6.3² = 39.69. Calculator: √40 = 6.324… ≈ 6.3.
10★ Core

Nia says √70 ≈ 8.5 because 70 is between 64 and 81. Is that a good estimate?

Answer Not quite. 8.5² = 72.25, more than 70. 70 is 6 past 64 and 11 below 81, so √70 is closer to 8. (SR3)
√70 = 8.366… ≈ 8.4. Targets the "halfway" mix-up.
11★ Core

A square garden in Medicine Hat has an area of 60 m². Find the side to the nearest tenth. How much fence goes around it?

Answer Side: s = √60. Benchmarks 49 < 60 < 64, so 7 < s < 8, closer to 8. (SR3)
Calculator: √60 = 7.745… ≈ 7.7 m.
Fence: 4 × 7.745… = 30.98… ≈ 31.0 m.
12★ Core

Rational or irrational? Explain each one.

  1. a) √49 b) √48 c) 0.12 d) π e) 22/7
Answer a) Rational: √49 = 7. b) Irrational: 48 is not a perfect square. (SR4)
c) Rational: it repeats. d) Irrational: it never ends or repeats. e) Rational: it is a fraction (close to π, but not π).
