Rational Numbers

Core Practice ★ — Answer Key

Answer key · Teacher copy
1★ Core

Put each number in the smallest box it fits: 8, −5, 2/7, 0, −3.6, 31

Answer Natural: 8 and 31 (counting numbers). Integers: −5 and 0 (whole numbers that are not natural). (RN1)
Rational only: 2/7 and −3.6. All six numbers are rational.
2★ Core

Jay says −4 is not a rational number, because it is not a fraction. Show he is wrong.

Answer −4 = −4/1. A rational number is any number you can write as a/b. Every integer is rational. (RN1)
Targets the "integers aren't rational" mix-up.
3★ Core

Write each number as a/b.

  1. a) 7 = 7/1
  2. b) −0.8 = −4/5
  3. c) 31/2 = 7/2
  4. d) −1.25 = −5/4
Answer a) 7 = 7/1. b) −0.8 = −8/10 = −4/5. (RN1)
c) 31/2 = 6/2 + 1/2 = 7/2. d) −1.25 = −125/100 = −5/4.
4★ Core

Divide to write each fraction as a decimal. Use bar notation if it repeats.

  1. a) 4/11 = 0.36
  2. b) 5/8 = 0.625
  3. c) 7/9 = 0.7
  4. d) −1/6 = −0.16
Answer a) 40 ÷ 11 = 3 R 7, 70 ÷ 11 = 6 R 4. The remainder 4 is back, so 3 and 6 repeat: 0.36. (RN2)
b) 5 ÷ 8 = 0.625 (ends). c) 7 ÷ 9 = 0.777… = 0.7. d) 1 ÷ 6 = 0.1666…, so −1/6 = −0.16. The bar goes over the 6 only.
5★ Core

Mia says 1/3 = 0.3. Use the number line to show she is wrong.

Answer 0.3 = 3/10, and it stops. 1 ÷ 3 = 0.333… never stops. So 1/3 = 0.3 is a little to the right of 0.3. (RN2)
Targets the "0.333… is 0.3" mix-up.
6★ Core

Mark each number on the line with its letter. Then order them from least to greatest.

A = −3/4 · B = 0.4 · C = −2/3 · D = 1/3 · E = −0.7

−3/4, −0.7, −2/3, 1/3, 0.4

Answer Decimals: −0.75, 0.4, −0.6, 0.3, −0.7. (RN2)
Left to right: −3/4, −0.7, −2/3, 1/3, 0.4.
7★ Core

Find two numbers between 0.5 and 0.6.

Answer Any two from 0.51 to 0.59, or more digits like 0.505. Example: 0.52 and 0.57. (RN2)
There are endless numbers between. Targets the "nothing between 0.5 and 0.6" mix-up.
8★ Core

Find each sum or difference.

  1. a) −1/2 + 1/3 = −1/6
  2. b) 1/4 − 3/4 = −1/2
  3. c) −2.5 − (−4.1) = 1.6
  4. d) −1.8 + (−2.7) = −4.5
Answer a) −3/6 + 2/6 = −1/6. Not 0/5: you need a common denominator. Targets the "add tops and bottoms" mix-up. (RN3)
b) −2/4 = −1/2. c) −2.5 + 4.1 = 1.6. d) −4.5.
9★ Core

Find each product or quotient.

  1. a) −2/5 × 3/4 = −3/10
  2. b) (−1.5) × (−6) = 9
  3. c) −3/4 ÷ (−1/8) = 6
  4. d) 7.2 ÷ (−0.9) = −8
Answer a) 6/20 = 3/10; one negative, so −3/10. b) Same signs: 9. (RN3)
c) 3/4 × 8 = 6; same signs, so positive. d) 72 ÷ 9 = 8; different signs: −8.
10★ Core

At 6 a.m. in Red Deer it was −7.5 °C. By 2 p.m. it was 4.3 °C warmer. Then it dropped 5.6 °C by 10 p.m. What was the temperature at 10 p.m.?

Answer −7.5 + 4.3 = −3.2. Then −3.2 − 5.6 = −8.8. It was −8.8 °C at 10 p.m. (RN3)
11★ Core

Evaluate. Estimate first.

  1. a) −4 + 5 × (−0.6)
  2. b) (2/3 − 1) × (−9)
Answer a) Estimate −4 + (−3) = −7. Multiply first: 5 × (−0.6) = −3. Then −4 + (−3) = −7. (RN4)
Not (−4 + 5) × (−0.6) = −0.6. Multiply before you add.
b) Brackets: 2/3 − 1 = −1/3. Then −1/3 × (−9) = 3.
12★ Core

Sam's bank balance is $45.20. He buys 3 games at $18.75 each. What is his balance now? Estimate first.

Answer Estimate: 45 − 3 × 20 = −15. Exact: 45.20 − 3 × 18.75 = 45.20 − 56.25 = −11.05. (RN4)
His balance is −$11.05. He owes $11.05. Close to the estimate, so it is reasonable.
