Probability

Core Practice ★ — Answer Key

Answer key · Teacher copy
1★ Core

Use the spinner. Write each probability as a fraction, a decimal and a percent.

  1. a) P(blue) = 2/5 = 0.4 = 40%
  2. b) P(green) = 1/5 = 0.2 = 20%
  3. c) P(not blue) = 3/5 = 0.6 = 60%
2★ Core

A bag holds 4 red, 6 green and 2 white marbles. You pick one without looking.

  1. a) P(green) = 6/12 = 1/2
  2. b) P(red or white) = 6/12 = 1/2
  3. c) P(purple) = 0
3★ Core

Complete the tree diagram for flipping a coin and spinning a 3-part spinner (A, B, C). List the outcomes.

How many outcomes? 6

4★ Core

Use the table for flipping a coin and rolling a die.

  1. a) P(tails and 3) = 1/12
  2. b) P(heads and an odd number) = 3/12 = 1/4
  3. c) P(a number greater than 4, with either coin side) = 4/12 = 1/3
5★ Core

Use the multiply rule.

  1. a) Roll two dice. P(both even) = 1/2 × 1/2 = 1/4
  2. b) Flip three coins. P(three heads) = 1/2 × 1/2 × 1/2 = 1/8
  3. c) Spin a spinner that is 1/4 red, then roll a die. P(red and a 5) = 1/4 × 1/6 = 1/24
6★ Core

Theo flipped a coin 20 times and got 13 heads. Write the experimental and theoretical P(heads).

Answer Experimental: 13/20 = 65%. Theoretical: 1/2 = 50%.
