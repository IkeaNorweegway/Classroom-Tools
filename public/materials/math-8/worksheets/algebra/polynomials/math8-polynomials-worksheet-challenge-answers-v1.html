1★★ Challenge

Write a polynomial for each description. a) a cubic trinomial in descending order with constant term −5 b) a quadratic monomial with coefficient −1 c) a linear binomial in ascending order

Answer Answers vary. a) x³ + 2x − 5 (degree 3, three terms, ends in −5). (PO2, PO3)
b) −x²
c) 4 + 3x (the constant comes first).
2★★ Challenge

Two garden plots have areas 2x² + 3x and x² + 5x + 2. Find the total area. Then find Plot B − Plot A. Check both with x = 2.

Answer Total: 2x² + 3x + x² + 5x + 2 = 3x² + 8x + 2. (PO4)
B − A: x² + 5x + 2 − 2x² − 3x = −x² + 2x + 2.
Check x = 2: A = 8 + 6 = 14. B = 4 + 10 + 2 = 16. Total 30 and 3(4) + 16 + 2 = 30 ✓. B − A = 2 and −4 + 4 + 2 = 2 ✓.
3★★ Challenge

A triangle has perimeter 4x² + 3x + 6. Two sides are x² + 2x and 2x² + 1. Find the third side.

Answer Third side = perimeter − the two sides. (PO4)
4x² + 3x + 6 − (x² + 2x) − (2x² + 1) = 4x² + 3x + 6 − x² − 2x − 2x² − 1.
= x² + x + 5. Check: (x² + 2x) + (2x² + 1) + (x² + x + 5) = 4x² + 3x + 6 ✓.
4★★ Challenge

What must you subtract from 3x³ − 2x + 1 to get x³ + x² − 2x?

Answer The missing polynomial is (3x³ − 2x + 1) − (x³ + x² − 2x). (PO4)
= 3x³ − 2x + 1 − x³ − x² + 2x = 2x³ − x² + 1.
Check: 3x³ − 2x + 1 − (2x³ − x² + 1) = x³ + x² − 2x ✓.
5★★ Challenge

Kim simplifies (2x² − 4x + 3) − (−x² + x − 5) and gets x² − 5x − 2. Find her mistake. Fix it with the columns.

Answer The opposite of −x² + x − 5 is +x² − x + 5. (PO4)
Kim flipped only the x term. She kept −x² and −5.
Right answer: 2x² + x² − 4x − x + 3 + 5 = 3x² − 5x + 8. Targets the "flip only some signs" mix-up.
6★★ Challenge

Figure x of tile pattern A has x² + 3x + 2 tiles. Figure x of pattern B has 2x² + x tiles. Find B − A. Which pattern has more tiles in Figure 1? In Figure 4?

Answer B − A = 2x² + x − x² − 3x − 2 = x² − 2x − 2. (PO4)
Figure 1: 1 − 2 − 2 = −3. A has 3 more (A = 6, B = 3).
Figure 4: 16 − 8 − 2 = 6. B has 6 more (A = 30, B = 36).
7★★ Challenge

Simplify x³ + 2x − x³ − 2x + 7. Is the answer still a polynomial? Name it by terms and degree.

Answer x³ − x³ = 0 and 2x − 2x = 0. The answer is 7. (PO2, PO3)
Yes. 7 = 7x⁰ is a polynomial: a constant monomial, degree 0.
