Question because

1★ Core

Look at the term −5x³.

  1. a) Name the coefficient, the variable and the exponent.
  2. b) Write −5x³ as a product of factors.
  3. c) Write 7 · x · x as one term.
  4. d) What is the coefficient of −x²?
2★ Core

Ivy solves 2/5x + 1 = 3. She multiplies by 5. She writes 2x + 1 = 15.

  1. a) Which term did Ivy skip?
  2. b) Clear the fraction the right way. Then solve. Check.
  3. c) Solve 0.3x + 1.2 = 2.7. Multiply every term by 10 first.
3★ Core

Sam says 3 is a solution of x < 3. "It's the boundary, so it counts."

  1. a) Is 3 < 3 true or false? Is 3 ≤ 3 true or false?
  2. b) Is Sam right? Use the dot to explain.
  3. c) Strict or non-strict? x < 3, x ≥ −1, 5 > y, n ≤ 7.
  4. d) Write in symbols: "t is at least 4."
4★ Core

The bunny hill at Lake Louise rises 200 m over a run of 500 m.

Ty says the slope is 500/200 = 5/2.

  1. a) Is Ty right? Explain.
  2. b) Find the slope of the hill.
  3. c) Count the rise and the run from A to B. Find the slope of AB.
  1. d) Check your slope with the formula.
5★ Core

Eli says 5 − x³ has degree 2. "It has two terms."

  1. a) Is Eli right? Name 5 − x³ by terms and by degree.
  2. b) Name 2x² + x − 7 two ways.
  3. c) Name −8x two ways.
  4. d) Name 9 two ways.
  5. e) Is 3/x + 1 a polynomial? Explain.
6★ Core

Solve −4(x − 2) = 6.

  1. a) Expand −4(x − 2). Use the arrows.
  2. b) Solve. The answer may be a fraction.
  3. c) Check your answer.
7★ Core

Ben graphs x > −2. He draws the ray to the left.

  1. a) Test 0 and −4 in x > −2. Which one does Ben's ray cover?
  2. b) Draw the right graph of x > −2.
  1. c) Write the inequality for this graph.
8★ Core

Jay says line A has no slope. "It's flat."

  1. a) Find the slope of line A. Use its two points. Is Jay right?
  2. b) Find the slope of line B. Use its two points.
  3. c) Name each slope: positive, negative, zero or undefined.
  1. d) A line has slope 2/3. What slope does a parallel line have? A perpendicular line?

9★★ Extended

Mo writes 3x² + 2x = 5x³.

  1. a) Use the tiles. Explain why Mo is wrong.
  2. b) Sort the like terms. Simplify 2x + 3x² − 6 − x² + 4x + 1.
  1. c) Write your answer in descending order. Then in ascending order.
  2. d) Check with x = 1.
10★★ Extended

Solve 1/3x + 4 = 1/2x + 1.

  1. a) Multiply every term by 6.
  2. b) Solve. Check in the first equation.
  3. c) Solve 1.2x + 1 = 0.4x + 3. Check.
11★★ Extended

Test values in 3x − 4 ≥ 5.

  1. a) Test −1, 2, 3 and 4.5. Which are solutions?
  2. b) Lee says 3 is not a solution. "It's the boundary." Is he right?
  3. c) Draw the dot and the ray.
12★★ Extended

Zara says y = 3x − 2 has slope −2.

  1. a) Find m and b. Is Zara right?
  2. b) Graph y = 3x − 2. Start at b. Use the slope.
  1. c) Write the equation of this line.
13★★ Extended

Erin subtracts (4x² + 3x − 2) − (x² − 5x + 6). She gets 3x² − 2x + 4.

  1. a) Find Erin's mistake.
  2. b) Subtract. Use the columns.
  3. c) Check both answers with x = 1.
  4. d) Add (2x² − x + 3) + (x² + 4x − 7).
14★★ Extended

Two bike shops in Canmore rent by the hour.

  1. a) Let x = the hours. Write the cost at each shop.
  2. b) Write an equation for equal cost. Solve it.
  3. c) Verify your answer.
  4. d) Which shop is cheaper for 10 hours? Answer in words.
15★★ Extended

A small bridge has a load sign. A minivan has 7 seats.

  1. a) Let w = the mass in tonnes. Write an inequality for the bridge.
  2. b) A truck is 4.2 t. It carries 0.9 t of hay. Is it safe? Test it.
  3. c) Let p = the people in the van. Write an inequality. Graph it.
  1. d) Why does the van graph use dots, not a ray?
16★★ Extended

A grain bin holds 40 t of wheat. An auger empties it at a steady rate.

  1. a) Write both intercepts as ordered pairs. What does each one mean?
  2. b) Find the rate of change. Include units.
  3. c) Write the equation of the line.
  4. d) The empty bin sits from hour 8 to hour 10. Write the equation of that part. What is its slope?

17★★ Extended

Tank A has 3 L of water. It fills at 2 L each minute. Tank B has 9 L. It drains at 1 L each minute.

  1. a) Write y = mx + b for each tank. What do m and b mean?
  2. b) Solve an equation. When do the tanks hold the same amount?
  3. c) When does Tank A hold more? Write an inequality in t. Test t = 1 and t = 3.
18★★ Extended

The sides of a triangle are x + 4, 2x − 1 and 1/2x + 3 (cm).

  1. a) Write the perimeter. Simplify it. Name it by terms and degree.
  2. b) The perimeter is 20 cm. Find x. Find each side.
  3. c) The perimeter must be at most 27 cm. Write an inequality. Is x = 6 allowed? Is x = 7?
