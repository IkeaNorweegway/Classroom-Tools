Solving Equations

Core Practice ★ — Answer Key

Answer key · Teacher copy
1★ Core

Solve 1/4x + 2 = 5. Multiply every term by 4 first.

Answer × 4 on every term: x + 8 = 20. (SE1)
Subtract 8: x = 12. Check: 1/4(12) + 2 = 3 + 2 = 5. ✓
2★ Core

Maya solves 1/3x − 2 = 4. She writes x − 2 = 12. Explain her mistake. Then solve.

Answer She multiplied the x-term and the 4 by 3, but not the 2. Every term must be multiplied. (SE1)
x − 6 = 12, so x = 18. Check: 1/3(18) − 2 = 6 − 2 = 4. ✓ Targets the "multiply only the fraction term by the LCD" mix-up.
3★ Core

Solve 0.6x + 1.5 = 4.5.

Answer × 10: 6x + 15 = 45. (SE1)
Subtract 15: 6x = 30. Divide by 6: x = 5. Check: 0.6(5) + 1.5 = 3 + 1.5 = 4.5. ✓
4★ Core

Which equations are equivalent to 1/2x − 1 = 3? Write yes or no. Say what was done.

  1. a) x − 2 = 6
  2. b) x − 1 = 6
  3. c) 2x − 4 = 12
  4. d) 1/2x = 4
Answer a) Yes: × 2 on every term. (SE1)
b) No: the 1 was not multiplied by 2.
c) Yes: × 4 on every term.
d) Yes: + 1 on both sides. All the "yes" equations have x = 8.
5★ Core

Solve 3/4x = 9. Use the bar.

Answer 3 parts are 9, so each part is 3. Four parts: x = 12. (SE1)
Or × 4: 3x = 36, so x = 12. Check: 3/4(12) = 9. ✓
6★ Core

Solve −3(x − 5) = 12.

Answer Distribute: −3x + 15 = 12. Subtract 15: −3x = −3. x = 1. (SE2)
Or ÷ −3 first: x − 5 = −4, so x = 1. Check: −3(1 − 5) = −3(−4) = 12. ✓
7★ Core

Leo writes 1/2(x + 10) = 1/2x + 10. Fix his mistake. Then solve 1/2(x + 10) = 9.

Answer Half of 10 is 5, so 1/2(x + 10) = 1/2x + 5. He gave the factor to the first term only. (SE2)
1/2x + 5 = 9. 1/2x = 4. x = 8. Check: 1/2(18) = 9. ✓ Targets the "distribute to the first term only" mix-up.
8★ Core

Solve 0.5(x + 6) = 4.5.

Answer × 2 on both sides: x + 6 = 9. x = 3. (SE2)
Check: 0.5(3 + 6) = 0.5(9) = 4.5. ✓
9★ Core

Solve 4x + 3 = x + 8. Your answer will be a fraction.

Answer Subtract x: 3x + 3 = 8. Subtract 3: 3x = 5. x = 5/3. (SE3)
Check: 4(5/3) + 3 = 20/3 + 9/3 = 29/3. 5/3 + 8 = 5/3 + 24/3 = 29/3. ✓
10★ Core

Ravi solves 1.2x − 3 = 0.4x + 1. His first step is 0.8x − 3 = 0.4x + 1. Explain his mistake. Then solve.

Answer He took 0.4x off the left side only. The right side still has 0.4x, so it is not equivalent. (SE3)
0.8x − 3 = 1. 0.8x = 4. x = 5. Check: 6 − 3 = 3 and 2 + 1 = 3. ✓ Targets the "do it to one side only" mix-up.
11★ Core

Solve 1/2x + 3 = 1/4x + 5.

Answer × 4 on every term: 2x + 12 = x + 20. (SE3)
Subtract x: x + 12 = 20. x = 8. Check: 4 + 3 = 7 and 2 + 5 = 7. ✓
12★ Core

A taxi costs $3.50 to start plus $1.75 per km. A fare is $21. How far was the ride?

Answer Let x = km. 3.50 + 1.75x = 21. (SE4)
× 100: 350 + 175x = 2100. 175x = 1750. x = 10. Check: 3.50 + 17.50 = 21. ✓ The ride was 10 km.
