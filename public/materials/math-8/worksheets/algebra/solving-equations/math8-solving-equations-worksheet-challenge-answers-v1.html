1★★ Challenge

Solve 2/3x + 1/2 = 1/6x + 2.

Answer × 6: 4x + 3 = x + 12. 3x = 9. x = 3. (SE3)
Check: 2 + 1/2 = 21/2 and 1/2 + 2 = 21/2. ✓
2★★ Challenge

Solve −1/2(4x − 6) = x + 9.

Answer −2x + 3 = x + 9. −6 = 3x. x = −2. (SE2)
Check: −1/2(−8 − 6) = −1/2(−14) = 7 and −2 + 9 = 7. ✓
3★★ Challenge

Solve 0.25(x − 8) = 0.5x + 1.

Answer 0.25x − 2 = 0.5x + 1. Subtract 0.25x: −2 = 0.25x + 1. −3 = 0.25x. x = −12. (SE3)
Check: 0.25(−20) = −5 and 0.5(−12) + 1 = −5. ✓
4★★ Challenge

Solve x − 1/3 = x + 3/5.

Answer × 15 on both sides: 5(x − 1) = 3(x + 3). 5x − 5 = 3x + 9. 2x = 14. x = 7. (SE3)
Check: 6/3 = 2 and 10/5 = 2. ✓
5★★ Challenge

Gym A costs $45 to join plus $19.75 a month. Gym B costs $27.25 a month. When do they cost the same? Which is cheaper for a full year?

Answer 45 = 7.5x. x = 6 months. Both cost $163.50. (SE4)
12 months: A = 45 + 237 = $282. B = $327. Gym A is cheaper for a year.
6★★ Challenge

Use F = 1.8C + 32. At what temperature are °F and °C the same number?

Answer Put F = C: C = 1.8C + 32. Subtract 1.8C: −0.8C = 32. C = −40. (SE4)
Check: 1.8(−40) + 32 = −72 + 32 = −40. ✓ −40 °C is −40 °F.
7★★ Challenge

A rectangle is 2/3x + 1 long and 1/3x wide. Its perimeter is 20 cm. Find the length and width.

Answer 2(2/3x + 1) + 2(1/3x) = 20. 4/3x + 2 + 2/3x = 20. 2x + 2 = 20. x = 9. (SE4)
Length 7 cm, width 3 cm. Check: 2(7 + 3) = 20. ✓
8★★ Challenge

Ana makes 2/3 of a muffin recipe. She uses 1/2 cup of sugar. How much sugar is in the full recipe?

Answer 2/3x = 1/2. × 6: 4x = 3. x = 3/4 cup. (SE4)
Check: 2/3 × 3/4 = 6/12 = 1/2. ✓
