The banquet table pattern: go up by 2 means multiply n by 2. Start at 2 means add 2.

From table to equation

s = n +

"Go up by" → the number in front of n. "Starts at" (figure 0) → the number added.

Watch out — a common mistake

"It goes up by 2, so the equation is s = n + 2."

Why it is wrong: Test it. n = 3 gives 3 + 2 = 5. The table says 8 seats.

What is true: Going up by 2 for every table means 2 × n. s = 2n + 2. Check: 2(3) + 2 = 8 ✓

Watch out — a common mistake

"Always connect the dots with a line."

Why it is wrong: You cannot have 21/2 tables. A line would show seats for 21/2 tables, which does not make sense.

What is true: For things you count (tables, tickets, people), plot dots only. This is called discrete data.
