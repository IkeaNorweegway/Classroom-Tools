Exit Tickets

For the teacher: print and cut. One ticket at the end of each section. Give 3–5 minutes. Read them before the next class and sort into three piles: got it, almost, not yet.

Exit ticket — Section 1 · Strict and non-strict

Name:Date:
Target: I can read and write inequalities in words and in symbols. (IQ1)

1. Write in symbols: a) m is no more than 12. b) t is greater than −4. c) The Highway 2 sign, with s for speed.

2. Write 7 < x with x first.

3. Is 9 a solution of x ≤ 9? Is it a solution of x < 9? Explain how you know.

Exit ticket — Section 3 · Checking solutions

Name:Date:
Target: I can check if a number is a solution by putting it in. (IQ3)

1. Is x = −3 a solution of 4 − x > 6?

2. Is x = 2.5 a solution of 2x + 1 ≤ 5?

Name:Date:
Target: I can write an inequality for a real situation and check it. (IQ4)
