Concept 1: Sequence & Loop

I can: put instructions in order, and use a loop instead of repeating the same block over and over.

A sequence is a set of instructions carried out in   order. Dash does exactly what the blocks say — one after another, with nothing skipped and nothing guessed.

If a pattern repeats (like "turn, drive, turn, drive, turn, drive"), a loop lets you say "do this   times" instead of stacking the same blocks over and over. A loop does the same job with   blocks.

Concept 2: Conditionals — "If This, Then That"

I can: explain what a conditional is doing in a program I wrote.

A conditional tells Dash: "if   is true, then do   — otherwise, do something else." Dash isn't choosing on its own — the programmer decided what counts as true and what Dash should do about it.

Misconception

"Dash knows there's a wall there, so it decides to turn."

Why this fails: Dash has no idea anything exists until a sensor reports a number back to the program, and a conditional block someone wrote decides what to do with that number. Change the conditional, and Dash reacts completely differently to the exact same wall.

Correct understanding: Dash turns because a specific block — written by a person — said "if the distance sensor reads less than ___, then turn." Every single thing Dash does traces back to an instruction someone wrote.

Check Yourself — no peeking
  1. In your own words, what is a conditional doing?
  2. If you wanted Dash to only make a sound when something is very close (not far away), what would you need to change in the conditional?

Concept 3: Sensors — Input and Output

I can: explain how Dash's sensor turns into a program decision, and predict what it will detect.

An input is information coming into the program — a sensor reading (how far away is something?), a button press, a sound. An output is something the program sends out — Dash moving, a light, a sound.

A sensor doesn't make decisions. It just reports a number or a signal. What Dash does with that number is decided entirely by the conditional blocks in the program — same idea as Concept 2, now applied to something Dash can actually detect in the real world.

Connection

Think about a time a machine you use (an automatic door, a motion-light) seemed to "notice" you. What sensor and what conditional do you think are really doing that job?
