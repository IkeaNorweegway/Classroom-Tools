2★ Core

Find each sum.

  1. a) −9 + (−3) = −12
  2. b) 8 + (−11) = −3
  3. c) −14 + 6 = −8
  4. d) −20 + 20 = 0
  5. e) 13 + (−4) = 9
  6. f) −7 + (−8) = −15
Answer a) Same signs: 9 + 3 = 12, keep the − sign. d) Opposites make 0. f) Same signs: 7 + 8 = 15, keep −. (IN1)
b) Different signs: 11 − 8 = 3. −11 is further from 0, so −3. c) 14 − 6 = 8, so −8. e) 13 − 4 = 9, so 9.
3★ Core

Ben says −6 + (−2) = 8, "because two negatives make a positive." Show −6 + (−2) on the number line. What is the right answer?

Answer Start at −6. Jump 2 to the left. You land on −8. So −6 + (−2) = −8. (IN1)
"Two negatives make a positive" is for × and ÷. Adding two negatives goes further left. Targets the "two negatives make a positive" mix-up.
4★ Core

In golf, each hole has a target score called par. A score of 2 under par is written −2. Ava's scores for 3 days were −2, +3 and −4. What is her total?

Answer −2 + 3 + (−4). Start at 0: jump to −2, then 3 right to 1, then 4 left to −3. (IN1)
Her total is −3. That is 3 under par.
5★ Core

Use chips to find 3 − (−2). Draw the zero pairs you add. Cross out the chips you take away.

Answer There are no red chips to take away. Add 2 zero pairs (still worth 3). Take away 2 red chips. (IN2)
5 yellow chips are left. 3 − (−2) = 5.
6★ Core

Write each one as adding the opposite. Then find the answer.

  1. a) 5 − 9 = 5 + (−9) = −4
  2. b) −4 − 6 = −4 + (−6) = −10
  3. c) 7 − (−3) = 7 + 3 = 10
  4. d) −2 − (−9) = −2 + 9 = 7
  5. e) −11 − (−5) = −11 + 5 = −6
  6. f) 0 − 8 = 0 + (−8) = −8
Answer Keep the first number. Change − to +. Use the opposite of the second number. Then add. (IN2)
a) different signs: 9 − 5 = 4, so −4. b) same signs: −10. c) 10. d) 9 − 2 = 7, so 7. e) 11 − 5 = 6, so −6. f) −8.
7★ Core

Sam says, "Subtracting always makes a number smaller." Show 4 − (−3) on the number line. Is Sam right?

Answer 4 − (−3) = 4 + 3 = 7. Start at 4 and jump 3 to the right. You land on 7. (IN2)
Sam is not right. 7 is bigger than 4. Taking away a negative makes it bigger. Targets the "subtracting always makes it smaller" mix-up.
8★ Core

A chinook came to Pincher Creek. At 6 am it was −18 °C. At 2 pm it was 4 °C. How many degrees did it warm up?

Answer Change = end − start = 4 − (−18) = 4 + 18 = 22. (IN2)
Check: −18 up to 0 is 18. 0 up to 4 is 4. 18 + 4 = 22. It warmed up 22 degrees.
9★ Core

Find each product.

  1. a) Write the multiplication for these chips. Find the product.

4 × (−5) = −20

  1. b) 6 × (−7) = −42
  2. c) (−8)(−4) = 32
  3. d) −9 · 3 = −27
  4. e) (−5)(0) = 0
  5. f) (−1)(−2)(−3) = −6
  6. g) (2)(−3)(−5) = 30
Answer a) 4 groups of −5 is 20 red chips: 4 × (−5) = −20. (IN3)
b) different signs: −42. c) same signs: 32. d) different signs: −27. e) anything times 0 is 0.
f) 3 negatives (odd), so negative. 1 × 2 × 3 = 6. Answer −6. g) 2 negatives (even), so positive. 2 × 3 × 5 = 30.
10★ Core

Kai says (−3) × 7 is positive, "because 7 is bigger than 3." Show 7 jumps of −3 on the number line. Is Kai right?

Answer 7 jumps of −3 from 0 land on −21. So (−3) × 7 = −21. (IN3)
Kai is not right. For ×, count the negatives. There is one negative (odd), so the product is negative. Targets the "sign of the bigger number" mix-up.
11★ Core

Find each quotient. Write the related multiplication to check.

  1. a) −36 ÷ 4 = −9
  2. b) 45 ÷ (−9) = −5
  3. c) −64 ÷ (−8) = 8
  4. d) −90 ÷ 6 = −15
  5. e) 0 ÷ (−7) = 0
Answer a) −9, because 4 × (−9) = −36. b) −5, because (−9) × (−5) = 45. c) 8, because 8 × (−8) = −64. (IN4)
d) Estimate: −90 ÷ 6 is between −60 ÷ 6 = −10 and −120 ÷ 6 = −20. 90 ÷ 6 = 15, so −15. Check: 6 × (−15) = −90.
e) 0, because (−7) × 0 = 0.
12★ Core

In Grande Prairie, it was 3 °C at 7 pm. By 11 pm it was −13 °C. It dropped the same amount each hour. What was the change each hour?

Answer Step 1: Change = end − start = −13 − 3 = −16. (IN2, IN4)
Step 2: 7 pm to 11 pm is 4 hours. −16 ÷ 4 = −4.
Step 3: Check: 4 × (−4) = −16. ✓ The change was −4 °C each hour.
