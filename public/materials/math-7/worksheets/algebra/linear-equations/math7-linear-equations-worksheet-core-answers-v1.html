1★ Core

Simplify 4x + 2x and 4x + 2. Noor says 4x + 2x = 6x². Ben says 4x + 2 = 6x. Fix both mistakes.

Answer 4x + 2x = 6x. Add the coefficients only. Six x tiles are 6x, not 6x². (LE1)
4x + 2 stays 4x + 2. An x-term and a number are not like terms. Targets the "2x + 3x = 5x²" and "3x + 2 = 5x" mix-ups.
2★ Core

Simplify.

  1. a) 3(x + 2)
  2. b) −2(x − 4)
  3. c) 2(x − 3) + 5x − 1
Answer a) 3 × x + 3 × 2 = 3x + 6. (LE1)
b) −2 × x = −2x and −2 × (−4) = +8. So −2x + 8.
c) 2x − 6 + 5x − 1. Like terms: 2x + 5x = 7x and −6 − 1 = −7. So 7x − 7.
3★ Core

Leo writes 4(x + 5) = 4x + 5. Look at the groups. Fix his mistake.

Answer Each of the 4 groups has 5 small tiles. That is 20 small tiles, not 5. (LE1)
4(x + 5) = 4x + 20. Multiply BOTH terms. Targets the "2(x + 3) = 2x + 3" mix-up.
4★ Core

Solve 3x + 5 = 17. Use the balance.

Answer Subtract 5 from both sides: 3x = 12. (LE2)
Divide both sides by 3: x = 4. Check: 3(4) + 5 = 17. ✓
5★ Core

Kai solves x + 8 = 3. He takes 8 off the left side only. He writes x = 3. Explain his mistake. Then solve.

Answer He changed one side only, so the balance is not level. The right side must lose 8 too. (LE2)
x = 3 − 8 = −5. Check: −5 + 8 = 3. ✓ Targets the "do it to one side only" mix-up.
6★ Core

Solve.

  1. a) x − 6 = −2
  2. b) −5x = 20
  3. c) 2(x + 3) = 4
Answer a) Add 6 to both sides: x = −2 + 6 = 4. (LE2)
b) Divide both sides by −5: x = 20 ÷ (−5) = −4.
c) 2x + 6 = 4. Subtract 6: 2x = −2. Divide by 2: x = −1.
7★ Core

Which equations are equivalent to 4x + 2 = 10? Write yes or no. Say what was done to both sides.

  1. a) 4x = 8
  2. b) 4x = 12
  3. c) 2x + 1 = 5
  4. d) 5x + 2 = x + 10
Answer a) Yes: − 2 on both sides. (LE2)
b) No: 2 was added to the right side only. (4x = 12 gives x = 3, but 4x + 2 = 10 gives x = 2.)
c) Yes: ÷ 2 on both sides.
d) Yes: + x on both sides.
8★ Core

Solve 5x + 3 = 2x + 15.

Answer Subtract 2x from both sides: 3x + 3 = 15. (LE3)
Subtract 3 from both sides: 3x = 12. Divide by 3: x = 4.
Check: 5(4) + 3 = 23 and 2(4) + 15 = 23. ✓
9★ Core

Zoe solves 5x + 1 = 2x + 13. Her first step is 7x + 1 = 13. Fix her mistake. Then solve.

Answer She moved 2x and kept its sign. Subtract 2x from BOTH sides: 5x − 2x + 1 = 13, so 3x + 1 = 13. (LE3)
3x = 12. x = 4. Check: 5(4) + 1 = 21 and 2(4) + 13 = 21. ✓ Targets the "move a term across and keep its sign" mix-up.
10★ Core

Solve 4x + 9 = x − 3. Verify your answer.

Answer Subtract x from both sides: 3x + 9 = −3. Subtract 9: 3x = −12. Divide by 3: x = −4. (LE3)
Verify: 4(−4) + 9 = −16 + 9 = −7. −4 − 3 = −7. ✓ (LE4)
11★ Core

Omar solves 2(x + 4) = x + 10. His first step is 2x + 4 = x + 10. He gets x = 6. He checks 2(6) + 4 = 16 and 6 + 10 = 16. Is x = 6 right?

Answer No. Check in the ORIGINAL: 2(6 + 4) = 20, but 6 + 10 = 16. Not equal. (LE4)
His first step is wrong: 2(x + 4) = 2x + 8. Then 2x + 8 = x + 10, so x = 2. Check: 2(6) = 12 and 2 + 10 = 12. ✓
Targets the "it works in my last equation, so it is right" mix-up.
12★ Core

Plan A costs $15 a month plus $4 for each GB. Plan B costs $27 a month plus $1 for each GB. When do they cost the same?

Answer Let x = the number of GB. 15 + 4x = 27 + x. (LE4)
Subtract x: 15 + 3x = 27. Subtract 15: 3x = 12. x = 4.
Verify: 15 + 4(4) = 31 and 27 + 4 = 31. Both plans cost $31 for 4 GB.
