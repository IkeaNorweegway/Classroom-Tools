A chord 12 cm from the centre cannot exist in a circle with radius 10 cm — the perpendicular distance to any chord cannot exceed the radius. This configuration is impossible.

7. True or False. If false, correct it.

(a) Any angle inscribed in a circle equals 90°.

Correction if false:

(b) A chord that passes through the centre is a diameter.

(c) The inscribed angle is half the central angle for the same arc.

(d) From any external point, both tangent segments to the circle are equal in length.

Answer
(a) Any angle inscribed in a circle equals 90°: FALSE
Correction: Only inscribed angles that subtend a diameter (a semicircle) equal 90°. In general, inscribed angle = 1/2 × central angle for the same arc.

(b) A chord that passes through the centre is a diameter: TRUE

(c) The inscribed angle is half the central angle for the same arc: TRUE

(d) From any external point, both tangent segments to the circle are equal: TRUE
