Part C — Application (Extended Response)

Show all working. [8 marks]   /8

19. A science class in Red Deer grows bacteria in a dish. The number of bacteria doubles every hour. At 12:00 noon there are 2⁶ bacteria.

[2](a) How many bacteria are there at 3:00 p.m.? Write the answer as a power of 2, then evaluate it.

[2](b) A second dish has 2¹⁰ bacteria at noon. How many times as many bacteria does it have as the first dish? Write the answer as a power of 2, then evaluate it.

[2](c) Six hours before noon, the first dish had 2⁰ bacteria. Kai says that means the dish was empty. Is Kai right? Explain.

[2](d) Using the same pattern, eight hours before noon the first dish would have 2⁻² bacteria. Evaluate 2⁻². Does this number make sense for bacteria? Explain.
