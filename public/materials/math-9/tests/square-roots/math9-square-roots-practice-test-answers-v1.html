Part D — Thinking

20. Model answer: Taylor is only right for numbers greater than 1. √49 = 7, and 7 is smaller than 49. But for numbers between 0 and 1, the square root is bigger: √0.25 = 0.5, and 0.5 is bigger than 0.25. As a fraction, √1/4 = 1/2, which is bigger than 1/4. This happens because multiplying two numbers less than 1 gives a smaller answer (0.5 × 0.5 = 0.25), so the root has to be bigger than the number. For 1 and 0, the root equals the number (√1 = 1, √0 = 0). So Taylor is wrong: a square root makes a number smaller only when the number is greater than 1.
