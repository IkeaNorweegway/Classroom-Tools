From Tables to Equations

One skill: finding the slope and y-intercept from a table and writing y = mx + b · about 15 minutes

Need a reminder? See the class notes: Section 2: Slope as Rate of Change · Section 3: The Equation y = mx + b

NameDate

For the adult: Two questions do most of the work: "How much does y change each time x goes up by 1?" (the slope) and "What is y when x is 0?" (the starting value).

Worked example

Worked example

x: 0, 1, 2, 3 and y: 5, 8, 11, 14. Write the equation.

  1. y goes up by 3 each time x goes up by 1, so the slope is 3.
  2. When x = 0, y = 5, so the y-intercept is 5.
  3. Equation: y = 3x + 5
  4. Check x = 2: 3(2) + 5 = 11. ✓
