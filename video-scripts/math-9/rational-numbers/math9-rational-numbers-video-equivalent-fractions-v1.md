# Equivalent Fractions — Same Amount, Different Name
Math 9 · Rational Numbers (prerequisite review) · Alberta Curriculum

**Learning outcome:** Standalone — no Math 9 course LO code. Prerequisite skill: student can generate an equivalent fraction and explain *why* multiplying (or dividing) the numerator and denominator by the same non-zero number preserves the fraction's value. Supports the Rational Numbers unit's fraction operations, which assume this is already secure.
**Script type:** Concept Explainer
**Target runtime:** ≈5–6 min

---

## Color & Object Legend

| Object / Quantity | Color | Notes |
|---|---|---|
| The whole (bar outline) | Light gray | The boundary — never changes |
| The fraction's value (shaded region) | Blue | Stays blue in every beat — the point is that this amount never changes |
| Partitioning action (new cut lines, scale factor *n*) | Amber | Signals "this is the operation happening," distinct from the value itself |

---

## Cold Open — The Visual Puzzle

| | |
|---|---|
| **NARRATE** | "Here are two fractions. One bar is cut into 2 pieces, one piece shaded. The other is cut into 4 pieces, two shaded. Different numbers... but look closely at the shaded part." |
| **ANIMATE** | Two identical rectangles (light gray outline) side by side. Left: split into 2 equal pieces, left piece shaded blue. Right: split into 4 equal pieces, two left-most pieces shaded blue. Both shaded regions are drawn to occupy the exact same physical area of the bar. |
| **ON-SCREEN TEXT** | `1/2` under the left bar, `2/4` under the right bar |
| **HOLD** | 3s — hold on both bars side by side, unresolved, before the next beat answers the puzzle |

---

## Beat 1: The Cut Doesn't Touch the Amount

| | |
|---|---|
| **NARRATE** | "Watch the left bar. I'm going to add one more cut — right through the middle of each existing piece. Nothing shaded changes. I'm only adding lines." |
| **ANIMATE** | Left bar (still 1/2, blue shaded left half): an amber vertical line draws itself through the middle of *both* the shaded and unshaded piece, splitting each in two. The blue shaded region does not move, resize, or recolor — it simply now has an amber line running through the middle of it. |
| **ON-SCREEN TEXT** | none |
| **HOLD** | 2s — hold with the amber cut line visible, before the pieces separate visually into 4 |

---

## Beat 2: Recount — Same Picture, New Fraction Name

| | |
|---|---|
| **NARRATE** | "Now count the pieces. Four total. How many are shaded blue? Two. The bar looks almost identical to the one on the right a moment ago — because it's the exact same amount." |
| **ANIMATE** | The now-4-piece left bar morphs/aligns to sit directly on top of the right bar from the cold open. The two bars visually merge into one — same blue shaded area, same amber partition lines. |
| **ON-SCREEN TEXT** | `1/2 = 2/4` |
| **HOLD** | 3s — hold on the merged bar with the equation visible |

---

## Beat 3: Do It Again — The Pattern Appears

| | |
|---|---|
| **NARRATE** | "Let's add cuts one more time — split every piece into three instead of two. The blue area still hasn't moved." |
| **ANIMATE** | The same bar: amber lines draw in, splitting each of the 4 existing pieces into 3 (12 pieces total), with the originally-shaded region now covered by 6 small amber-outlined pieces, still shaded entirely blue. |
| **ON-SCREEN TEXT** | `1/2 = 2/4 = 6/12` |
| **HOLD** | 3s — hold on the fully-cut bar with all three fraction names stacked on screen |

---

## Generalize

| | |
|---|---|
| **NARRATE** | "Every time, the move was the same: cut each piece into *n* smaller pieces. That multiplies the number of shaded pieces by *n*, and it multiplies the total number of pieces by *n* — the same *n*, every time. That's why the value never changes." |
| **ANIMATE** | The fraction equation `1/2 = 2/4 = 6/12` morphs into the general form `a/b = (a × n)/(b × n)`, with amber multiplication arrows drawn from `a` to `a × n` and from `b` to `b × n` simultaneously, in the same amber used for every cut line in the video. |
| **ON-SCREEN TEXT** | `a/b = (a × n)/(b × n)` |
| **HOLD** | 3s — hold on the general equation before the recap |

---

## Recap — Closing Beat

| | |
|---|---|
| **NARRATE** | "Same bar, same blue amount, three different names. Multiply top and bottom by the same number, and you haven't changed the fraction — you've only changed how many pieces it's cut into." |
| **ANIMATE** | Final frame: the one fully-partitioned bar (12 pieces, 6 shaded blue) with all three equivalent fraction names stacked beside it, held static. |
| **ON-SCREEN TEXT** | `1/2 = 2/4 = 6/12` |
| **HOLD** | 4s — final hold before cut |

## Production Notes

**Color legend (repeated for reference):** Whole/outline → light gray · Fraction's value (shaded region) → blue, constant throughout · Partitioning action (cut lines, scale factor *n*) → amber

**Pacing reminders:**
- [x] No beat has two simultaneous transforms
- [x] Every beat has a stated HOLD
- [x] ON-SCREEN TEXT never repeats NARRATE word-for-word
- [x] Cold-open object/color (the blue shaded region) carries through unchanged to the generalization
- [x] Concept explainer — no prediction-pause beat required (that's a worked-example-walkthrough device)

**Voice/tone notes:** Conversational, slightly slower pace through Beats 1–2 (the core visual insight); pick up pace slightly through Beat 3 (repetition of an established idea); slow down again on the Generalize beat — that's the payoff line.
