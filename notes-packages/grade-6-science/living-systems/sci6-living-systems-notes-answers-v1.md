| Blank / Prompt | Answer |
|---|---|

| Biotic means ___ | living |
| Abiotic means ___ | non-living |

## Unit Synthesis Blanks

| Cluster / Prompt | Answer |
|---|---|
| 3 biotic components | Any three: producers / consumers / decomposers / plants / animals / fungi / bacteria |
| 3 abiotic components | Any three: sunlight / water / temperature / soil |
| 3 roles organisms play | Producers · Consumers · Decomposers |
| Why decomposers matter (one sentence) | They break down dead matter and return nutrients to the soil so producers can grow |
| Photosynthesis equation in words | Carbon dioxide + water + light energy → glucose + oxygen |
| CO₂ comes from | The air |
| Water comes from | The soil / roots |
| Glucose stored as | Starch |
| Oxygen goes to | The atmosphere / air / released as a byproduct |
| Soil misconception (one sentence) | Plants make their own food from CO₂ and water using light energy — soil provides minerals, not food |
| Animals depend on plants for (3 beyond food) | Any three: oxygen · habitat · soil stability · clothing · medicine · climate regulation |
| Plants depend on animals for (2) | Any two: pollination · seed dispersal · CO₂ supply · nutrient return via decomposition |
| Sacred plant + ecological role | Any one: sage (nitrogen-fixing) · sweetgrass (wetland soil stabiliser) · cedar (carbon sink/habitat) · tobacco (pollinator attractor) |
| Trophic cascade definition | A change at one level of a food web that ripples through the whole ecosystem system |
