## Section 1: Opposites and absolute value
Learning target: I can find the opposite and the absolute value of a number.

### Vocabulary
- positive number :: a number bigger than 0. It is to the right of 0. :: 5, 2.5, {3/4}
- negative number :: a number less than 0. It is to the left of 0. :: −5, −2.5, −{3/4}
- opposite :: the number the same distance from 0, on the other side :: 4 and −4
- absolute value :: the distance from a number to 0. We write it with bars: |−6| :: |−6| = 6

A number line is like a road.
Numbers get **bigger** as you go right.
They get **smaller** as you go left.
@viz numberline min=-6 max=6 ends="smaller,bigger" caption="Left is smaller. Right is bigger."

A **negative number** is less than 0. A **positive number** is more than 0.
A thermometer is a number line standing up. Up is warmer. Down is colder.
@viz thermo min=-30 max=20 step=10 values="-20,15" labels="night: −20°;day: 15°" caption="A cold night and a warm day in Edmonton."

#### Opposites
**Opposites** are the same distance from 0. They are on different sides.
@viz numberline min=-6 max=6 points="-4:;4:" jumps="-4>0>4" jumplabels="4 steps,4 steps" caption="4 and −4 are opposites. Each is 4 steps from 0."

Opposites show up in real life.
- A gain of $5 and a loss of $5.
- 10 m above sea level and 10 m below sea level.
@viz vline min=-12 max=12 step=2 every=4 unit=" m" zero="sea level" water=1 height=190 width=300 points="10:bird: 10 m;-10:diver: −10 m" caption="The bird and the diver are opposites."

The opposite of −7 is 7. The opposite of 7 is −7.
The opposite of 0 is 0.

#### Absolute value
The **absolute value** of a number is its distance from 0.
We write it with two straight bars: |−5|.
Say it: "the absolute value of negative five."
@viz numberline min=-6 max=6 points="-5:" jumps="0>-5" jumplabels="5 steps" caption="−5 is 5 steps from 0. So |−5| = 5."

::: key Absolute value is a distance
A distance is never negative.
So |−5| = 5 and |5| = 5.
Opposites have the **same** absolute value.
:::
::: example Worked Example 1 — A cold Calgary morning
It is −12 °C in Calgary. How far is that from 0 °C?
@viz thermo min=-20 max=10 step=5 values="-12" labels="−12 °C"
Count the degrees from −12 up to 0.
So |−12| = [[12]]. It is 12 degrees below 0.
:::
::: example Worked Example 2 — A decimal
Find |−2.5| and |2.5|.
@viz numberline min=-3 max=3 step=0.5 every=1 points="-2.5:;2.5:" jumps="-2.5>0>2.5" jumplabels="2.5 steps,2.5 steps"
−2.5 is 2.5 steps from 0. So |−2.5| = 2.5.
2.5 is also 2.5 steps from 0. So |2.5| = [[2.5]].
:::
::: example Worked Example 3 — Money you owe
Leo's bank account shows −$15.50. That means he owes the bank $15.50.
@viz vline min=-20 max=20 step=5 prefix="$" zero="" height=200 width=300 points="-15.5:Leo: −$15.50" above="has money" below="owes money"
How much does he owe? |−15.50| = [[15.50]]. He owes $15.50.
:::
::: explain
Why is the absolute value of a number never negative?
(lines 2)
=> Absolute value is a distance from 0. You can't walk a negative number of steps.
:::
::: misconception
WRONG: "Absolute value makes a number negative. |−5| = −5."
WHY: Absolute value is a distance. A distance is never less than 0.
@viz numberline min=-6 max=6 points="-5:;5:" jumps="-5>0>5" jumplabels="5 steps,5 steps"
RIGHT: |−5| = 5 and |5| = 5. Both are 5 steps from 0.
:::
::: try
a) The opposite of 8 is [[−8]].
b) The opposite of −2.5 is [[2.5]].
c) |−9| = [[9]]
d) |6.4| = [[6.4]]
e) |−{3/5}| = [[{3/5}]]
f) Mark the two numbers that are 3 steps from 0. They are [[3]] and [[−3]].
@viz numberline min=-5 max=5 keypoints="-3:−3;3:3"
:::
::: retrieval
1. Which is colder: −15 °C or −5 °C?
=> −15 °C. It is further below 0.
2. What is the opposite of −0.8?
=> 0.8
3. Find |−14| and |14|.
=> 14 and 14. They are opposites, so they are the same distance from 0.
4. Mia says |−3| = −3. Fix her mistake.
=> |−3| = 3. Absolute value is a distance, and distance is never negative.
5. ★ Stretch: Find two numbers that are 2.5 steps from 1.
=> 3.5 and −1.5. Count 2.5 right of 1, then 2.5 left of 1.
:::

## Section 2: Fractions and decimals on the number line
Learning target: I can put negative fractions and decimals on a number line.

### Vocabulary
- negative fraction :: a fraction less than 0 :: −{1/2}, −{3/4}
- negative decimal :: a decimal less than 0 :: −0.5, −1.25
- mixed number :: a whole number and a fraction :: −1{1/4} means −1 and −{1/4} more

Fractions and decimals live between the whole numbers.
The left side of 0 is a mirror of the right side.
@viz numberline min=-1 max=1 step=0.25 ticklabels="-1:−1;-0.75:−3/4;-0.5:−1/2;-0.25:−1/4;0:0;0.25:1/4;0.5:1/2;0.75:3/4;1:1" caption="Quarters on both sides of 0."

Tenths work the same way.
@viz numberline min=-1 max=1 step=0.1 every=0.5 points="-0.3:−0.3;0.3:0.3" caption="−0.3 and 0.3 are opposites. Each is 3 tenths from 0."

::: example Worked Example 1 — Where is −1.5?
Step 1: −1.5 is past −1. It is between [[−2]] and [[−1]].
Step 2: The .5 means half way.
@viz numberline min=-3 max=1 step=0.5 every=1 points="-1.5:−1.5" highlight="-2,-1"
So −1.5 is half way from −1 to −2.
:::
::: misconception
WRONG: "−1.5 is between −1 and 0."
WHY: −1.5 is more than 1 step from 0. So it must be past −1.
@viz numberline min=-2 max=1 step=0.5 every=0.5 points="-1.5:✓ −1.5;-0.5:✗ not here"
RIGHT: −1.5 is half way from −1 to −2. The point between −1 and 0 is −0.5.
:::
::: example Worked Example 2 — Fractions: −{3/4} and −1{1/4}
Step 1: Cut each whole into 4 equal parts (quarters).
Step 2: −{3/4} is 3 quarters left of 0.
Step 3: −1{1/4} is 1 whole and [[1]] more quarter left of 0.
@viz numberline min=-2 max=1 step=0.25 every=1 points="-0.75:−3/4;-1.25:−1 1/4"
:::
::: example Worked Example 3 — Stock changes
A stock changes price each day. Down is negative. Up is positive.
Monday: down $0.40. Tuesday: up $0.30.
@viz numberline min=-1 max=1 step=0.1 every=0.5 points="-0.4:Mon;0.3:Tue" ends="down,up"
Monday's change is −0.40. Tuesday's change is [[+0.30]].
:::
::: explain
In Worked Example 3, why is Monday's point left of 0?
(lines 2)
=> The price went down, so the change is negative. Negative numbers are left of 0.
:::

#### One sign, three places
A negative sign can sit in front, on top, or on the bottom.
It is still the **same number**.

::: key −{a/b} = {a/−b} = −({a/b})
−{3/4} = {3/−4} = −({3/4})
All three mean "three quarters, on the negative side."
:::
@viz numberline min=-1 max=1 step=0.25 ticklabels="-1:−1;-0.5:−1/2;0:0;0.5:1/2;1:1" points="-0.75:−3/4 = 3/(−4) = −(3/4)" caption="One point, three ways to write it."

::: misconception
WRONG: "−{3/4}, {3/−4} and −({3/4}) are three different numbers."
WHY: Each one has just one negative sign. One negative sign puts the number left of 0.
@viz numberline min=-1 max=0 step=0.25 ticklabels="-1:−1;-0.75:−3/4;-0.5:−1/2;-0.25:−1/4;0:0" points="-0.75:all three are here" width=420
RIGHT: All three are the same number. They sit at the same point.
:::
::: try
1. Mark each number on the line. Write its letter above it.
**a** = −0.5 · **b** = −1.25 · **c** = −{7/4}
**d** = 1.5 · **e** = −2{1/2}
@viz numberline min=-3 max=2 step=0.25 every=1 keypoints="-0.5:a;-1.25:b;-1.75:c;1.5:d;-2.5:e"
2. What number is at each point?
@viz numberline min=-2 max=0 step=0.1 every=0.5 points="-1.4:A;-0.6:B"
A = [[−1.4]]  B = [[−0.6]]
3. Write −{2/5} two other ways. [[{2/−5}]] and [[−({2/5})]]
:::
::: retrieval
1. Between which two whole numbers is −2.5?
=> −3 and −2. It is half way.
2. Find |−1.75|.
=> 1.75
3. What is the opposite of −1{1/2}?
=> 1{1/2}
4. Is {5/−8} positive or negative? How do you know?
=> Negative. It has one negative sign, so it is left of 0.
5. ★ Stretch: Ben says −0.9 is closer to −1 than to 0. Is he right? Use a number line.
@viz numberline min=-1 max=0 step=0.1 every=0.5
=> Yes. −0.9 is 0.1 from −1 but 0.9 from 0.
:::

## Section 3: Fractions to decimals and back
Learning target: I can change fractions to decimals and decimals to fractions.

### Vocabulary
- tenths, hundredths, thousandths :: decimal places: 1 out of 10, 1 out of 100, 1 out of 1000 :: 0.3 = 3 tenths
- equivalent fractions :: fractions that show the same amount :: {1/2} = {5/10} = {50/100}
- simplest form :: a fraction where the top and bottom can't be divided by the same number :: {35/100} = {7/20}

A fraction and a decimal can name the **same** number.
@viz hundred shaded=75 labels="75 out of 100 = 3/4 = 0.75" caption="Shade 3 quarters of the grid. That is 75 hundredths."

#### Way 1: Make 10, 100 or 1000 on the bottom
Multiply the top and bottom by the same number.
Then read it as a decimal.
@viz bars bars="2/5;4/10" labels="2/5;4/10" caption="2 fifths and 4 tenths cover the same amount."

::: example Worked Example 1 — {3/4} as a decimal
Step 1: What times 4 makes 100? 4 × 25 = 100.
Step 2: Multiply the top and the bottom by 25. 3 × 25 = [[75]]
So {3/4} = {75/100}.
Step 3: Write 75 hundredths as a decimal: [[0.75]]
@viz dnl top="0,1/4,2/4,3/4,1" bottom="0,0.25,0.5,[[0.75]],1" toplabel="fraction" bottomlabel="decimal"
:::
::: explain
Why can we multiply the top and the bottom by 25?
(lines 2)
=> {25/25} = 1. Multiplying by 1 does not change the amount.
:::

#### Way 2: Divide the top by the bottom
The fraction bar means divide. {3/8} means 3 ÷ 8.
Use a calculator: 3 ÷ 8 = 0.375.

::: example Worked Example 2 — A negative fraction
Long ago, stock prices changed in eighths of a dollar.
A stock changed by −{3/8} of a dollar. Write it as a decimal.
Step 1: Do the positive part. 3 ÷ 8 = [[0.375]]
Step 2: Put the sign back. −{3/8} = [[−0.375]]
@viz dnl top="−1/2,−3/8,−1/4,−1/8,0" bottom="−0.5,[[−0.375]],−0.25,−0.125,0" toplabel="fraction" bottomlabel="decimal"
:::
::: misconception
WRONG: "{1/4} = 1.4"
WHY: The fraction bar is not a decimal point. {1/4} means 1 ÷ 4. And 1.4 is more than 1!
@viz numberline min=0 max=2 step=0.25 every=0.5 points="0.25:1/4;1.4:1.4"
RIGHT: {1/4} = 1 ÷ 4 = 0.25.
:::
Some decimals keep going. {1/3} = 1 ÷ 3 = 0.333…
The dots mean the 3s never stop.

#### Decimals to fractions: read the place value
| Decimal | Say it | Fraction | Simplest form |
|---|---|---|---|
| 0.6 | 6 tenths | {6/10} | {3/5} |
| 0.25 | 25 hundredths | {25/100} | [[{1/4}]] |
| 0.125 | 125 thousandths | [[{125/1000}]] | [[{1/8}]] |

::: example Worked Example 3 — A lake level
The water in a lake went down 0.35 m. The change is −0.35 m.
Write −0.35 as a fraction.
@viz hundred shaded=35 labels="35 hundredths"
Step 1: 0.35 is 35 hundredths. Write it as a fraction: [[{35/100}]]
Step 2: Divide the top and bottom by 5: [[{7/20}]]
Step 3: Put the sign back. −0.35 = [[−{7/20}]]
:::
::: explain
In Worked Example 3, why did we divide by 5?
(lines 2)
=> 5 goes into both 35 and 100. Dividing gives simplest form.
:::
::: key Fractions to know by heart
| Fraction | {1/2} | {1/4} | {3/4} | {1/5} | {1/10} | {1/8} |
|---|---|---|---|---|---|---|
| Decimal | 0.5 | [[0.25]] | [[0.75]] | [[0.2]] | [[0.1]] | [[0.125]] |
A negative fraction gives a negative decimal: −{1/4} = −0.25.
:::
::: try
a) {1/2} = [[0.5]]
b) −{3/5} = [[−0.6]]
c) {7/4} = [[1.75]]
d) −{9/10} = [[−0.9]]
e) −0.8 = [[−{4/5}]]
f) 0.125 = [[{1/8}]]
g) −2.5 = [[−{5/2}, or −2{1/2}]]
:::
::: retrieval
1. Write {3/4} as a decimal.
=> 0.75
2. Write −0.4 as a fraction in simplest form.
=> −{4/10} = −{2/5}
3. Find |−0.75|.
=> 0.75
4. Put −1.25 on the number line.
@viz numberline min=-2 max=1 step=0.25 every=1 keypoints="-1.25:−1.25"
=> One whole and one quarter left of 0.
5. ★ Stretch: Which fraction with 8 on the bottom equals −0.625?
=> −{5/8}, because 5 ÷ 8 = 0.625.
:::

## Section 4: Comparing and ordering
Learning target: I can compare and order positive and negative fractions and decimals.

### Vocabulary
- greater than (>) :: further right on the number line :: 2 > −5
- less than (<) :: further left on the number line :: −8 < −3
- least to greatest :: smallest first, biggest last :: −2, 0, 3

The number line decides. **Further left is smaller.**
@viz numberline min=-10 max=2 points="-8:−8;-3:−3" ends="smaller,bigger" caption="−8 is further left. So −8 < −3."

::: misconception
WRONG: "−8 is bigger than −3, because 8 is bigger than 3."
WHY: −8 is further from 0, but on the left side. Further left is smaller.
@viz thermo min=-10 max=5 step=5 values="-8,-3" labels="−8 °C;−3 °C" caption="−8 °C is colder than −3 °C. Colder means less."
RIGHT: −8 < −3. Think: −8 °C is colder than −3 °C.
:::
::: misconception
WRONG: "0.125 is bigger than 0.5, because it has more digits."
WHY: Compare the place values, not the number of digits.
| Number | Tenths | Hundredths | Thousandths |
|---|---|---|---|
| 0.500 | 5 | 0 | 0 |
| 0.125 | 1 | 2 | 5 |
@viz numberline min=0 max=1 step=0.125 every=0.25 points="0.125:0.125;0.5:0.5"
RIGHT: 0.500 > 0.125. Five tenths beats one tenth.
:::
::: example Worked Example 1 — Compare −{3/4} and −{5/8}
Step 1: Change to decimals. −{3/4} = [[−0.75]] and −{5/8} = [[−0.625]]
Step 2: Put both on the number line.
@viz numberline min=-1 max=0 step=0.125 every=0.25 points="-0.75:−3/4;-0.625:−5/8"
Step 3: −{3/4} is further left. So −{3/4} [[<]] −{5/8}.
:::
::: explain
In Worked Example 1, 0.75 > 0.625. So why is −0.75 < −0.625?
(lines 2)
=> −0.75 is further from 0 on the left side. Further left is smaller.
:::
::: example Worked Example 2 — Order a mixed list
Order from least to greatest: −0.6, {1/2}, −{3/4}, 0.2, −1
Step 1: Change to decimals: −0.6, [[0.5]], [[−0.75]], 0.2, −1
Step 2: Put them on the number line.
@viz numberline min=-1 max=1 step=0.25 width=600 keypoints="-1:−1;-0.75:−3/4;-0.6:−0.6;0.2:0.2;0.5:1/2"
Step 3: Read from left to right: [[−1, −{3/4}, −0.6, 0.2, {1/2}]]
:::
::: example Worked Example 3 — A cold morning in Alberta
Here are the temperatures one January morning.
| Town | Edmonton | Calgary | Jasper | Banff | Red Deer |
|---|---|---|---|---|---|
| Temperature (°C) | −18.4 | −7.5 | −21.6 | −15.9 | −12.3 |
@viz thermo min=-25 max=5 step=5 values="-18.4,-7.5,-21.6,-15.9,-12.3" labels="Edmonton;Calgary;Jasper;Banff;Red Deer"
Order from coldest to warmest: [[Jasper, Edmonton, Banff, Red Deer, Calgary]]
:::
::: key How to compare and order
@viz flow steps="Change to decimals|Line up the place values|Put them on a number line|Further left is smaller"
:::
::: try
1. Write < or >.
a) −6 [[<]] −2
b) −0.7 [[<]] −0.07
c) −{1/2} [[>]] −0.6
d) 0.125 [[<]] 0.5
e) −{3/4} [[<]] −{5/8}
f) |−3| [[>]] |2|
2. Order from least to greatest: −0.3, −{1/4}, −1, 0.2, −1.5
@viz numberline min=-2 max=1 step=0.25 every=0.5 width=600 keypoints="-1.5:−1.5;-1:−1;-0.3:−0.3;-0.25:−1/4;0.2:0.2"
[[−1.5, −1, −0.3, −{1/4}, 0.2]]
:::
::: retrieval
1. Which is greater: −2.5 or −2.05? Explain.
=> −2.05. It is closer to 0, so it is further right.
2. Write −{2/5} as a decimal.
=> −0.4
3. Find |−{7/8}|.
=> {7/8}
4. Noor owes $4.75. Raj owes $12.50. Write each balance as a number. Who has less money?
=> Noor −4.75, Raj −12.50. Raj has less: −12.50 < −4.75.
5. ★ Stretch: Find a number between −{1/2} and −{1/4}. Write it as a fraction and as a decimal.
=> One answer: −{3/8} = −0.375. Any number between −0.5 and −0.25 works.
:::

## Concept Reference
::: key Opposites and absolute value
Opposites are the same distance from 0, on different sides: 4 and −4.
Absolute value is the distance from 0. It is never negative. |−5| = 5, |5| = 5.
:::
@viz numberline min=-6 max=6 points="-5:;5:" jumps="-5>0>5" jumplabels="5 steps,5 steps"

::: key Negative fractions and decimals
−1.5 is half way from −1 to −2. The left side of 0 is a mirror of the right side.
One negative sign, anywhere, gives the same number: −{3/4} = {3/−4} = −({3/4}) = −0.75.
:::
@viz numberline min=-2 max=1 step=0.25 every=1 points="-1.5:−1.5;-0.75:−3/4"

::: key Fractions and decimals
Fraction to decimal: make 10, 100 or 1000 on the bottom. Or divide top ÷ bottom. {3/4} = {75/100} = 0.75.
Decimal to fraction: read the place value, then simplify. 0.35 = {35/100} = {7/20}.
| {1/2} | {1/4} | {3/4} | {1/5} | {1/10} | {1/8} |
|---|---|---|---|---|---|
| 0.5 | 0.25 | 0.75 | 0.2 | 0.1 | 0.125 |
:::
::: key Comparing and ordering
Change to decimals. Line up the place values. Further left is smaller.
−8 < −3 · 0.5 > 0.125 · −{3/4} < −{5/8}
:::
@viz flow steps="Change to decimals|Line up the place values|Put them on a number line|Further left is smaller"
