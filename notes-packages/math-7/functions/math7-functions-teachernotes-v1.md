## Overview
::: overview
**Big idea:** a relation pairs inputs with outputs; a function is a relation in which each input has exactly one output (two inputs may share an output). The same function can be shown as a rule (a function machine), ordered pairs, a table, a mapping diagram, a graph and a real situation. Graphing from a table forces a decision students rarely make on their own: is the input a count (discrete, dots only) or a measure that can take any value (continuous, a connected line)? Domain and range are then the full set of possible inputs and outputs, described in words, and the real situation sets their limits: no negative time or people, a trough that holds 120 L, a bus that seats 40, a 20-visit pool pass. The vertical line test is the graphical form of the one-output rule.
**Sequence:** function machine, input and output, ordered pairs, table, mapping diagram and graph of one function; the one-output rule; independent and dependent variables (FN1) → the four-step graphing routine, dots or a line, discrete bowling vs. continuous trough, a decreasing graph (gas on the drive to Banff) (FN2) → domain and range from a mapping diagram, ordered pairs, a graph, a table and a curved temperature graph; "whole numbers from 0 to 5" vs. "any number from 0 to 4" on a number line (FN3) → limits from the situation (bus, trough, pool pass) and the vertical line test on a circle, a sideways U, a hill and a dot graph (FN4).
**Materials:** grid paper or the printed grids, a ruler, a sheet of paper or a pencil to slide across a graph as the vertical line, mini whiteboards, a cardboard "function machine" box (optional: students feed in input cards and the teacher passes out output cards).
**Depth ceiling:** 7F1 asks students to distinguish discrete and continuous functions, describe domain and range in words, describe real-world restrictions, graph from a table of values, and decide whether a relation is a function (including the vertical line test). Graphs stay in the first quadrant here; all four quadrants are allowed if a context needs negatives. No f(x) notation, no set-builder or interval notation (write "any number from 0 to 4", not 0 ≤ x ≤ 4 or [0, 4]) and no slope or rate-of-change language beyond "adds 20 L each minute" (slope is Grade 8). Functions are all linear here except the temperature curve, which is read, not graphed from a rule.
**Reading level:** student pages are written at about Grade 3–4. The math words (input, output, ordered pair, relation, function, independent variable, dependent variable, mapping diagram, table of values, discrete, continuous, domain, range, limit, vertical line, vertical line test) are the learning; teach each with a picture on the board. Note that "range" also means biggest − smallest in statistics (topic 11 and Grade 6 data); the notes flag the two meanings.
:::

| Watch for | What to do |
|---|---|
| "Every relation is a function" | Draw the mapping diagram and point at each input in turn: "How many arrows leave this one?" One input with two arrows breaks it. |
| "Two inputs can't share an output" | Birthday months: Ava and Sam both have May. Each person still has one month. Two arrows may land on the same output. |
| Flipping input and output when writing pairs | The input is always first: (games, cost). Say the pair aloud as "2 games cost 12 dollars." |
| "Always connect the dots" | Ask "can the input be 2.5?" Half a rider or half a ticket makes no sense, so dots only. Time, litres and GB can be any amount, so a line. |
| Deciding discrete/continuous from the output | Money is the output in both bowling (discrete) and the data plan (continuous). It is the input that decides. |
| Swapping domain and range | Domain = inputs = across (x); range = outputs = up (y). "D before R, like input before output, like x before y." |
| Listing a continuous domain ("0, 1, 2, 3, 4, 5") | The trough has water at 2.5 minutes too. Use "any number from 0 to 5" for continuous, and a thick part on the number line. |
| Negative time or people in the domain | Ask "what does −2 minutes mean here?" Most situations start at 0. |
| Using a horizontal line for the test | A flat line finds two inputs with the same output, which is allowed. Only a vertical line checks one input at a time. |

## Lessons
### Lesson 1 — Relations and functions (60 min)
DO: Pre-knowledge check (5 min). Q1 and Q6 preview substitution into a rule, Q2 and Q4 patterns and rules, Q3 plotting (input across), Q5 values between whole numbers (preview of continuous).
SHOW: The function machine: 2 games go in, × 6, $12 comes out. Then three inputs at once.
SAY: "An input goes in. The machine follows the rule. One output comes out. The output depends on the input, so it is the dependent variable."
DO: Four ways to show the bowling relation: table, ordered pairs (input first), mapping diagram, graph. Students say each pair aloud: "3 games cost 18 dollars."
WATCH: "Every relation is a function." Misconception box: the input 2 has two arrows.
WATCH: "Two inputs can't share an output." Misconception box: two arrows into 5 is fine.
CUE: Worked Example 1 (pairs to mapping diagram), Worked Example 2 (birthday months, then flip it: month → name is not a function), Worked Example 3 (bus rides at $3: independent and dependent variables).
DO: Your turn, retrieval, exit ticket Section 1.

### Lesson 2 — Graphing a function from a table (60 min)
DO: Warm-up interleaved: is (1, 4), (2, 4) a function; −3 + (−7); solve 2x − 5 = 11; 25% of 80.
SHOW: The four-step routine: table, pairs, plot (input across, output up), dots or a line.
SAY: "Ask one question: can the input be a part, like 2.5? If not, leave the dots apart. If it can, join them."
DO: Worked Example 1 (bowling, discrete): students finish the table and plot (4, 24) and (5, 30). Worked Example 2 (water trough, continuous): 1.5 minutes gives 30 L, so join the dots.
WATCH: "Always connect the dots." Misconception box: a line through the bus-rider graph claims 2.5 riders paid $7.50.
CUE: Worked Example 3 (gas on the drive to Banff): a graph can go down and still be a function.
DO: Your turn, retrieval, exit ticket Section 2. Quiz next class (FN1–FN2).

### Lesson 3 — Domain and range (60 min)
DO: Mid-unit quiz (25 min) first. Then the lesson.
SHOW: The bowling mapping diagram with the ovals labelled domain and range.
SAY: "The domain is every input that can happen. The range is every output that can happen. We say them in words."
DO: Two number lines: dots for "whole numbers from 0 to 5," a thick segment for "any number from 0 to 4."
WATCH: Swapping domain and range. Misconception box: in (2, 12), 2 is the input.
DO: Worked Example 1 (pairs), Worked Example 2 (trough graph: 0 to 5 minutes, 0 to 100 L), Worked Example 3 (Calgary spring day: read the lowest and highest points, 2 °C to 15 °C), Worked Example 4 (data plan up to 4 GB: $20 to $40).
CUE: Remind students that "range" in data means biggest − smallest. Here it is the set of outputs.
DO: Your turn, retrieval, exit ticket Section 3.

### Lesson 4 — Real-world limits and the vertical line test (60 min)
DO: Warm-up interleaved: domain and range of (2, 5), (4, 5), (6, 9); dots or a line for tickets sold; solve 4x = 2x + 10; 15% of 60.
SHOW: Four limits: no negative time or people, a 120 L trough, a 40-seat bus, a 20-visit pool pass.
SAY: "The situation tells you where the domain starts and stops. Then the range follows from the rule."
DO: Worked Example 1 (bus seats 40, $3 a rider: whole numbers 0 to 40, fares 0, 3, 6, … $120), Worked Example 2 (trough full after 6 minutes), Worked Example 3 (pool pass: visits used vs. visits left, both whole numbers 0 to 20).
SHOW: The vertical line test: slide a ruler or pencil across the circle, then across the temperature graph.
DO: Worked Example 4 (graphs A, B, C). Students slide a pencil and say "once" or "twice" for each.
WATCH: A horizontal line used for the test. Misconception box: on the hill, 2 and 6 share the output 4, which is allowed.
DO: Core worksheet; Challenge for early finishers. Exit ticket Section 4.

## Assessment
::: box Mid-unit quiz (22 marks)
FN1 (Q1–5), FN2 (Q6–9). Given at the start of Lesson 3, after relations, functions and graphing from a table, before domain and range (FN3) and limits (FN4). Q9 is the explain-your-thinking item: full marks need "dots" and a reason tied to the input (you can't sell part of a ticket / tickets are counted). On Q3 accept "not a function" only with the input named (5). On Q4 give the mark for "yes" only if the student says two inputs may share an output. On Q7 accept points within half a grid square.
:::
::: box Worksheets and exits
Core (★) covers FN1–FN4 with a mapping diagram, function machine, grid, number line or curve on most questions: function or not from pairs, mapping diagrams and a real situation, independent and dependent variables, completing a table and graphing it, dots or a line, domain and range from pairs, a table and a graph, a 40-seat bus limit, and the vertical line test. Challenge (★★) adds a rule found from a table, a relation that is a function one way but not the other, a graph read for domain and range with a limit, two limits in one situation (a tank and a trip), a temperature graph that dips below 0, and building a function to fit a given domain and range. Each misconception has at least one targeted question; the key names it. Exit tickets: one per section, each ending with an "explain how you know" item.
:::

## Data and contexts used
- Bowling at $6 a game is a made-up round price. Real Alberta alleys charge about $5–$8 a game, often plus shoe rental.
- The Edmonton bus fare of $3 a ride is rounded for easy arithmetic. Check current ETS and Calgary Transit fares if students ask; real fares are a little higher and passes change the picture.
- The 40-seat bus, 8-seat van, 120 L trough filling at 20 L a minute and 20-visit pool pass are made-up but plausible.
- The drive from Edmonton to Banff is about 4 hours (roughly 400 km). A car using 10 L of gas an hour with a 50 L tank is plausible for a mid-size car at highway speed.
- The Calgary spring-day temperatures (2 °C at 6 a.m. rising to 15 °C at 2 p.m., 9 °C at 6 p.m.) are made up. The Challenge winter day that dips to −6 °C is made up too.
- The phone plan ($20 a month plus $5 a GB, up to 4 GB) matches the made-up plan in Linear Equations. Real Alberta plans are sold as bundles.

## Connections
- **Linear Equations (topic 6):** each side of a word-problem equation is a function (cost vs. GB); the solution is the input where two tables match.
- **Ratios & Percents (topic 5):** "$6 a game" is a unit rate; the bowling table is a ratio table starting at 0.
- **Samples & Statistics (topic 11):** discrete vs. continuous data uses the same test (counted or measured), and "range" there means biggest − smallest.
- **Grade 8:** slope as the steepness of a line (the "per game" or "per minute" amount), linear relations and their equations, and inequalities that describe a domain.
