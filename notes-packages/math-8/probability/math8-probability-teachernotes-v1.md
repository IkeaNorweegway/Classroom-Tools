## Overview
::: overview
**Big idea:** for independent events, the chance that both happen is P(A) × P(B). Trees and tables come first so the multiply rule is a shortcut students can check, not a trick.
**Sequence:** one event (PB1) → two events with trees and tables (PB2) → the multiply rule (PB3) → experiments vs theory (PB4).
**Materials:** coins, dice, paper-clip spinners, a class tally chart for Lesson 4.
**Depth ceiling:** two (or three) independent events. No dependent events, permutations or combinations (Grade 9 and later).
:::

| Watch for | What to do |
|---|---|
| "Tails is due" (gambler's fallacy) | Ask: "How does the coin know what happened last time?" |
| Adding for "and" | Check with the table: count the cells. Point out the answer must get smaller. |
| Expecting exact results | Pool class data: show 12, 60 and 240 trials. |
| Unequal spinner parts treated as equal | Only count parts when they are equal in size. |

## Lessons
### Lesson 1 — Outcomes and probability (60 min)
DO: Pre-knowledge check. Quick vote: "Is a 6 harder to roll than a 1?"
SHOW: The probability line (0 to 1). Die and spinner examples.
SAY: "Probability = favourable outcomes over all outcomes."
DO: Exit ticket Section 1.

### Lesson 2 — Trees and tables (60 min)
DO: Warm-up: P(even) on a die, P(blue) on a spinner.
SHOW: The coin-and-die tree, then the table. "Same 12 outcomes, two pictures."
WATCH: Gambler's fallacy. Use the misconception box; flip a coin 5 times live.
DO: Exit ticket Section 2.

### Lesson 3 — The multiply rule (60 min)
DO: Warm-up: count cells in the coin-and-die table for three events.
SHOW: 1/2 × 1/6 = 1/12 next to the table and the area model.
SAY: "For 'and' with independent events, multiply. Then check with the table."
DO: Weather-and-hockey example (percents). Exit ticket Section 3.

### Lesson 4 — Experiments (60 min)
DO: Each pair does 12 trials of "heads and a 6." Pool the class data on the board.
SHOW: How the class result moves toward 1/12 as trials add up.
DO: Core worksheet; exit ticket Section 4. Quiz next class.

## Connections
- **Fractions:** the multiply rule is fraction multiplication.
- **Percents:** probabilities as percents (forecasts).
- **Grade 9:** dependent events (drawing without replacement) and probability in society.
