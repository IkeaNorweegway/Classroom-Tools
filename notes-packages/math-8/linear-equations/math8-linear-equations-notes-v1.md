## Section 1: One-step equations
Learning target: I can solve equations like 3x = 12 and x/4 = 5 with a balance and with inverse operations.

### Vocabulary
- equation :: a math sentence where both sides are equal :: 3x = 12
- variable :: a letter for an unknown number :: x
- inverse operation :: the operation that undoes another :: ÷ undoes ×
- solution :: the value that makes the equation true :: x = 4 solves 3x = 12
- verify :: put the solution back in to check :: 3(4) = 12 ✓

An equation is like a **balance**. Both sides weigh the same. Whatever you do to one side, you must do to the [[other side]].

@viz balance left="3x" right="+12" caption="Three x-bags balance 12 blocks."

::: example Worked Example 1 — Solve 3x = 12
3x means 3 × x. The inverse of × 3 is [[÷ 3]].
Divide both sides by 3: {3x/3} = {12/3}
x = [[4]]
Verify: 3 × 4 = 12 ✓
@viz balance left="x" right="+4" text="x = [[4]]" caption="Split both sides into 3 equal groups: one bag balances 4 blocks."
:::

::: misconception
WRONG: "3x = 12. Subtract 3 from both sides, so x = 9."
WHY: 3x means 3 TIMES x, not 3 plus x. Check: 3 × 9 = 27, not 12.
RIGHT: Undo × with ÷. x = 12 ÷ 3 = 4.
:::

::: explain
How do you know which inverse operation to use?
(lines 2)
=> Look at what is being done to x. If x is multiplied, divide. If x is divided, multiply.
:::

::: example Worked Example 2 — Solve {x/4} = −5
{x/4} means x ÷ 4. The inverse of ÷ 4 is [[× 4]].
Multiply both sides by 4: x = −5 × 4 = [[−20]]
Verify: (−20) ÷ 4 = −5 ✓
:::

::: example Worked Example 3 — Negative numbers: −2x = 14
Divide both sides by −2: x = 14 ÷ (−2) = [[−7]]
Verify: −2 × (−7) = 14 ✓
:::

::: explain
Why do we divide by −2, not by 2?
(lines 2)
=> x is multiplied by −2, so we undo it by dividing by −2. Dividing by 2 would leave −x.
:::

::: try
a) 5x = 35, x = [[7]]
b) {x/3} = 6, x = [[18]]
c) −4x = 20, x = [[−5]]
d) {x/−2} = 8, x = [[−16]]
e) Verify your answer to c): [[−4 × (−5) = 20 ✓]]
:::

::: retrieval
1. Solve 6x = 42.
=> x = 7
2. Solve {x/5} = −3.
=> x = −15
3. Jo solved 4x = 20 by subtracting 4 and got x = 16. What went wrong?
=> 4x means 4 times x. She should divide by 4: x = 5. Check: 4 × 16 = 64, not 20.
4. What does "verify" mean? Verify x = −3 for −6x = 18.
=> Put the answer back in. −6 × (−3) = 18 ✓
5. ★ Stretch: Write a one-step equation whose solution is x = −8. Use division.
=> Example: x/2 = −4.
:::

## Section 2: Two-step equations
Learning target: I can solve equations like 2x + 3 = 11 and x/3 − 4 = 2 by undoing steps in reverse order.

### Vocabulary
- constant :: a number on its own, with no variable :: in 2x + 3, the constant is 3
- coefficient :: the number multiplied by the variable :: in 2x + 3, the coefficient is 2
- reverse order :: undo the last step first :: like taking off shoes before socks

2x + 3 = 11 was built in two steps: start with x, **× 2**, then **+ 3**. To solve, undo in **reverse order**.

@viz flow steps="x|× 2|+ 3|= 11"

::: example Worked Example 4 — Solve 2x + 3 = 11
@viz balance left="2x;+3" right="+11"
Step 1: Undo + 3. Subtract 3 from both sides. 2x = [[8]]
@viz balance left="2x" right="+8"
Step 2: Undo × 2. Divide both sides by 2. x = [[4]]
Verify: 2(4) + 3 = 11 ✓
:::

::: misconception
WRONG: "2x + 3 = 11. Divide by 2 first: x + 3 = 5.5."
WHY: Dividing only the 2x by 2 is not allowed. You would have to divide the 3 too. It is easier to undo the + 3 first.
RIGHT: Undo the last step first. Subtract 3, then divide by 2. x = 4.
:::

::: explain
Why do we subtract 3 before we divide by 2?
(lines 2)
=> The + 3 was the last thing done to x, so it is the first thing we undo (reverse order).
:::

::: example Worked Example 5 — Solve {x/3} − 4 = 2
Built: x, ÷ 3, then − 4. Undo in reverse.
Step 1: Add 4 to both sides. {x/3} = [[6]]
Step 2: Multiply both sides by 3. x = [[18]]
Verify: 18 ÷ 3 − 4 = 6 − 4 = 2 ✓
:::

::: example Worked Example 6 — With negatives: −3x + 5 = −10
Step 1: Subtract 5. −3x = [[−15]]
Step 2: Divide by −3. x = [[5]]
Verify: −3(5) + 5 = −15 + 5 = −10 ✓
:::

::: try
a) 3x + 4 = 19, x = [[5]]
b) 5x − 2 = 23, x = [[5]]
c) {x/2} + 7 = 3, x = [[−8]]
d) −2x − 6 = 8, x = [[−7]]
:::

::: retrieval
1. Solve 4x + 1 = 25.
=> x = 6
2. Solve {x/5} + 2 = 6.
=> x = 20
3. Sam solved 3x − 6 = 12 like this: 3x = 6, x = 2. Find his mistake.
=> He subtracted 6 instead of adding 6. 3x = 18, so x = 6.
4. Verify that x = −2 solves 7x + 10 = −4.
=> 7(−2) + 10 = −14 + 10 = −4 ✓
5. ★ Stretch: Write a two-step equation that has the solution x = 3. Swap with a partner and solve.
=> Example: 4x − 5 = 7.
:::

## Section 3: Equations with brackets
Learning target: I can solve equations like 3(x + 2) = 18 in two ways.

### Vocabulary
- distributive property :: multiply the number outside the bracket by every term inside :: 3(x + 2) = 3x + 6
- expand :: use the distributive property to remove brackets :: 2(x − 4) → 2x − 8

3(x + 2) means 3 groups of (x + 2).

@viz balance left="x;+2;x;+2;x;+2" right="+18" text="3(x + 2) = 18" caption="3 groups of (x + 2): 3 bags and 6 blocks balance 18 blocks."

::: misconception
WRONG: "3(x + 2) = 3x + 2."
WHY: The picture shows 3 groups of (x + 2). That is 3 bags AND 3 × 2 = 6 blocks.
RIGHT: Multiply both terms: 3(x + 2) = 3x + 6.
:::

::: example Worked Example 7 — Way 1: Divide first. 3(x + 2) = 18
Divide both sides by 3: x + 2 = [[6]]
Subtract 2: x = [[4]]
Verify: 3(4 + 2) = 3(6) = 18 ✓
:::

::: example Worked Example 8 — Way 2: Expand first. 3(x + 2) = 18
Expand: 3x + [[6]] = 18
Subtract 6: 3x = [[12]]
Divide by 3: x = [[4]]
:::

::: explain
Both ways gave x = 4. When is "divide first" easier? When is "expand first" easier?
(lines 2)
=> Divide first is easier when the right side divides evenly (18 ÷ 3). Expand first always works, even when it doesn't divide evenly, like 3(x + 2) = 10.
:::

::: example Worked Example 9 — A fraction answer: 2(x − 3) = 5
Expand: 2x − 6 = 5
Add 6: 2x = 11
Divide by 2: x = [[{11/2}]] = 5.5
Verify: 2(5.5 − 3) = 2(2.5) = 5 ✓
:::

::: try
a) 4(x + 1) = 20, x = [[4]]
b) 2(x − 5) = 6, x = [[8]]
c) −3(x + 2) = 12, x = [[−6]]
d) 2(x + 4) = 9, x = [[{1/2} or 0.5]]
:::

::: retrieval
1. Expand 5(x − 2).
=> 5x − 10
2. Solve 6(x + 1) = 30 two ways.
(work 3)
=> Divide: x + 1 = 5, x = 4. Expand: 6x + 6 = 30, 6x = 24, x = 4.
3. Lily wrote 4(x + 3) = 4x + 3. Draw or explain why that is wrong.
=> 4 groups of (x + 3) have 4 × 3 = 12 blocks, not 3. 4(x + 3) = 4x + 12.
4. Solve −2(x − 1) = 10.
=> x − 1 = −5, so x = −4.
5. ★ Stretch: Solve 3(x + 2) = 2. Which way is easier here? Why?
=> Expand: 3x + 6 = 2, 3x = −4, x = −4/3. Expanding is easier because 2 ÷ 3 is not a whole number.
:::

## Section 4: Writing and checking equations
Learning target: I can write an equation for a problem, solve it, and check that the answer makes sense.

### Vocabulary
- let statement :: says what the variable stands for :: Let r = the number of rides
- reasonable :: makes sense in the problem :: you can't buy −2 tickets

@viz flow steps="Let x = …|Write the equation|Solve|Verify and answer in words"

::: example Worked Example 10 — Stampede rides
At the Calgary Stampede, Dev pays $18 to get in, plus $4 for each ride. He spends $50. How many rides?
Let r = the number of [[rides]].
Equation: 4r + 18 = [[50]]
Solve: 4r = 32, so r = [[8]]
Verify: 4(8) + 18 = 32 + 18 = 50 ✓
Answer in words: Dev went on [[8 rides]].
@viz balance left="4x;+18" right="+50" text="4r + 18 = 50"
:::

::: explain
Why is it important to answer in words at the end?
(lines 2)
=> The question asked how many rides, not "what is r." The words show you answered the real question, and help you see if it makes sense.
:::

::: example Worked Example 11 — Sharing a cost
Five friends rent a canoe at Lake Louise. They split the rental cost equally. Each friend also pays $3 for a life jacket. Each friend pays $17 in all. What does the canoe rental cost?
Let c = the canoe rental cost.
Each friend's share is {c/5}. Equation: {c/5} + 3 = [[17]]
Subtract 3: {c/5} = [[14]]
Multiply by 5: c = [[$70]]
Verify: 70 ÷ 5 + 3 = 14 + 3 = 17 ✓
:::

#### Find the error
::: example Worked Example 12 — Spot the mistake
Ari solved 2(x + 4) = 18:
Line 1: 2x + 4 = 18
Line 2: 2x = 14
Line 3: x = 7
The mistake is in Line [[1]]. It should be 2x + [[8]] = 18. Then 2x = 10 and x = [[5]].
:::

::: try
a) A gym charges $25 to join and $15 a month. Mia paid $100. Write and solve an equation for the number of months.
(work 3)
=> 15m + 25 = 100. 15m = 75. m = 5 months.
b) Three equal bags of chips and a $2 drink cost $11. Write and solve an equation for the cost of one bag.
(work 3)
=> 3b + 2 = 11. 3b = 9. b = $3.
:::

::: retrieval
1. Write an equation: "A number times 6, plus 4, is 40." Solve it.
=> 6n + 4 = 40, n = 6
2. Movie tickets cost $12 each. A family paid $60. Write and solve an equation.
=> 12t = 60, t = 5 tickets
3. Find the error: 3x − 7 = 8 → 3x = 1 → x = 1/3.
=> Line 2 should be 3x = 15 (add 7). x = 5.
4. A solution says a class has x = −3 students. What does that tell you?
=> The answer is not reasonable. Check the equation and the steps for a mistake.
5. ★ Stretch: A taxi costs $4 plus $2 per km. Write an equation for a $30 ride, solve it, and explain your answer in words.
=> 2k + 4 = 30, 2k = 26, k = 13. The ride was 13 km long.
:::

## Unit Synthesis
1. Solve 3x − 5 = 16 and explain each step with the balance idea.
=> Add 5 to both sides (keeps it balanced): 3x = 21. Divide both sides by 3: x = 7.
2. Explain why we undo steps in reverse order.
=> The last thing done to x is on the outside, so it comes off first, like taking off shoes before socks.
3. Make up a story problem for 2(x + 5) = 30. Solve it.
=> Example: 2 friends each buy a $5 snack and a ticket; together they pay $30. x + 5 = 15, x = $10.

## Concept Reference
::: key The balance rule
Do the same thing to both sides. Use inverse operations: + ↔ −, × ↔ ÷.
:::
@viz balance left="2x;+3" right="+11"

::: key One step
3x = 12 → ÷ 3 → x = 4 · {x/4} = −5 → × 4 → x = −20
:::

::: key Two steps: undo in reverse order
2x + 3 = 11 → − 3 → 2x = 8 → ÷ 2 → x = 4
{x/3} − 4 = 2 → + 4 → {x/3} = 6 → × 3 → x = 18
:::

::: key Brackets
3(x + 2) = 18. Divide first: x + 2 = 6, x = 4. Or expand: 3x + 6 = 18, 3x = 12, x = 4.
:::

::: key Word problems
Let x = … → write the equation → solve → verify → answer in words.
:::

| Mistake | Fix |
|---|---|
| 3x = 12 → subtract 3 | 3x is 3 × x. Divide by 3. |
| 2x + 3 = 11 → divide by 2 first | Undo + 3 first, then ÷ 2. |
| 3(x + 2) = 3x + 2 | 3(x + 2) = 3x + 6 |
| Skipping the check | Always put the answer back into the original equation. |
