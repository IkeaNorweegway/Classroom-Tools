## Overview
::: overview
**Big idea:** one relation, many faces. Every relation in this topic is shown as a picture, a table, an equation and a graph, with the words "starts at" and "goes up by" tying them together.
**Sequence:** pattern → table (LR1) → equation and ordered pairs (LR2) → graph (LR3) → reading a relation (LR4).
**Materials:** square tiles or linking cubes, grid paper, the banquet-table picture.
**Depth ceiling:** Grade 8 language only: "starts at" and "goes up by". No slope formula or y = mx + b vocabulary (Grade 9). Graphs of discrete data are the focus.
:::

| Watch for | What to do |
|---|---|
| y = x + 2 for "goes up by 2" | Test the equation with a row of the table, every time. |
| Starting value read as the Figure 1 value | Extend the table backwards to Figure 0. |
| Connecting dots for counted things | Ask "Can you have 2½ tables?" |
| Mixing up x and y in ordered pairs | Say the pair as "(tables, seats)" until it sticks. |

## Lessons
### Lesson 1 — Patterns to tables (60 min)
DO: Pre-knowledge check. Build the banquet tables with tiles: 1, 2, 3 tables.
SHOW: The picture and the table. "What stays the same? What grows?"
SAY: "It starts at ___ and goes up by ___." Students say this sentence for every pattern.
DO: Exit ticket Section 1.

### Lesson 2 — Equations (60 min)
DO: Warm-up: describe two patterns in words.
SHOW: "Goes up by 2" → 2n; "starts at 2" → + 2.
WATCH: y = n + 2. Use the misconception box: test with n = 3.
DO: The taxi equation, with both kinds of missing value. Exit ticket Section 2.

### Lesson 3 — Graphing (60 min)
DO: Warm-up: make a table for y = 2x + 3.
SHOW: Plot the banquet table. "Why are there no points between the dots?"
SAY: "Things you count get dots. Things that flow, like time, can get a line."
DO: Graph y = 3x − 1, including a negative y-value. Exit ticket Section 3.

### Lesson 4 — Reading a relation (60 min)
DO: Warm-up interleaved: one table, one equation, one ordered pair.
SHOW: The candle graph (decreasing). Then the two phone plans: where do they cross?
CUE: "Which plan would you pick if you use 2 GB? 6 GB?"
DO: Core worksheet. Exit ticket Section 4. Quiz next class.

## Connections
- **Linear Equations:** finding the missing x in an ordered pair (Worked Example 3) is solving an equation. That is the next topic.
- **Ratios & Rates:** a unit rate is the "goes up by" of a relation that starts at 0.
- **Grade 9:** slope, y = mx + b, and graphs of continuous relations.
