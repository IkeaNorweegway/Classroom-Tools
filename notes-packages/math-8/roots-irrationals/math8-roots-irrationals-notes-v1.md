## Section 1: Perfect and non-perfect squares
Learning target: I can tell if a fraction or decimal is a perfect square.

### Vocabulary
- perfect square :: a number you get by squaring a rational number :: 49 = 7², {9/16} = ({3/4})², 0.25 = 0.5²
- non-perfect square :: a number that is not the square of any rational number :: 20, {2/3}, 0.4
- squared :: times itself :: 0.5 squared = 0.5 × 0.5 = 0.25
- power :: a short way to write a repeated multiplication :: ({3/4})² means {3/4} × {3/4}

#### What you know from Grade 7
A perfect square is a number of tiles that makes a square.
@viz squares shapes="2x2;3x3;4x4;5x5" labels="2² = 4;3² = 9;4² = 16;5² = 25" caption="Each side is a whole number. The tiles make a square."
12 tiles make rectangles, but never a square. So 12 is a **non-perfect square**.
@viz squares shapes="2x6;3x4" labels="2 × 6 = 12;3 × 4 = 12" caption="The sides are never equal."

#### Now fractions and decimals can be perfect squares too
Cut a square into 4 by 4 small parts. Shade {3/4} of the rows and {3/4} of the columns.
The overlap is a square. It is {9/16} of the whole.
@viz area a=3/4 b=3/4 result="3/4 × 3/4 = 9/16"
So {9/16} = ({3/4})². It is a **perfect square**.

::: key Perfect square test
Write the fraction in simplest form.
If the top **and** the bottom are both perfect squares, it is a perfect square.
{9/16} = ({3/4})², because 9 = 3² and 16 = 4².
For a decimal, write a fraction first. 0.25 = {25/100} = ({5/10})² = 0.5².
:::

::: example Worked Example 1 — Is {49/64} a perfect square?
Step 1: Is the fraction in simplest form? Yes.
Step 2: Top: 49 = 7². Bottom: 64 = 8².
Step 3: So {49/64} = ({7/8})² = {7/8} × {7/8}.
@viz area a=7/8 b=7/8 result="7/8 × 7/8 = 49/64"
Yes, {49/64} is a perfect square.
:::

::: example Worked Example 2 — Decimals
a) Is 0.25 a perfect square? 0.5 × 0.5 = 0.25. Yes: 0.25 = 0.5².
@viz area a=1/2 b=1/2 result="0.5 × 0.5 = 0.25"
b) Is 0.09 a perfect square? 0.09 = {9/100}. 9 = 3² and 100 = 10². Yes: 0.09 = 0.3².
c) Is 0.9 a perfect square? 0.9 = {9/10}. 10 is not a perfect square. So no.
@viz squares shapes="3x3;10x1" labels="9 = 3² ✓;10 is not a square ✗" cell=13
:::
::: explain
0.09 is a perfect square, but 0.9 is not. Why?
(lines 2)
=> 0.09 = {9/100}, and 9 and 100 are both perfect squares. 0.9 = {9/10}, and 10 is not a perfect square.
:::

::: example Worked Example 3 — A Lego plate
A square Lego plate has 8 studs along each side.
@viz sqside n=8 side="8 studs" fill=sun cell=16 labels="8 × 8 = 8²;= 64 studs"
Repeated multiplication: 8 × 8. Power: 8². Value: 64 studs.
:::

WHY: The square root is the side of a square. Half is something else.
@viz squares shapes="4x4;8x2" labels="4 × 4 = 16 ✓ a square;8 × 2 = 16 ✗ not a square" cell=14

## Section 2: Two square roots (±)
Learning target: I can find both square roots of a number.

### Vocabulary
- square root :: a number that, times itself, gives the number :: 5 and −5 are square roots of 25
- principal square root :: the positive square root. The √ sign means this one. :: √25 = 5
- negative square root :: the negative one. Write −√. :: −√25 = −5
- ± :: "plus or minus": both roots at once :: ±√25 = ±5 means 5 and −5

#### Two numbers square to 25
5 × 5 = 25. Also (−5) × (−5) = 25. Same signs give a positive.
@viz mapping in="−5,5" out="25" arrows="−5>25;5>25" inlabel="number" outlabel="squared"
So 25 has **two square roots**: 5 and −5.
@viz numberline min=-6 max=6 points="-5:−5;5:5" caption="Both roots are 5 steps from 0, on opposite sides."

::: key Square roots of a number
A positive number has two square roots, one positive and one negative.
√25 = 5 is the **principal square root**. −√25 = −5 is the **negative square root**.
0 has only one square root: 0 × 0 = 0.
A negative number has **no real square roots**.
:::

#### Why does a negative have no square root?
Square any number. Look at the sign of the answer.
| Number | 3 | −3 | 0.5 | −0.5 | 0 |
|---|---|---|---|---|---|
| Squared | 9 | 9 | 0.25 | 0.25 | 0 |
Every answer is positive or 0. None is negative.
@viz mapping in="−3,0,3" out="9,0,−9" arrows="−3>9;3>9;0>0" inlabel="number" outlabel="squared"

::: misconception
WRONG: "√−9 = −3."
WHY: Check it. (−3) × (−3) = 9, not −9. Two negatives make a positive.
@viz counters groups=-3 each=-3 result="(−3) × (−3) = +9"
RIGHT: No real number times itself is −9. So √−9 has no real answer.
:::

#### The equation x² = a
x² = 25 asks: "Which numbers squared give 25?"
There are two: x = 5 or x = −5. Write x = ±√25 = ±5.
@viz numberline min=-6 max=6 points="-5:x = −5;5:x = 5" caption="x² = 25 has two answers."

::: misconception
WRONG: "√25 = ±5. The root sign gives both answers."
WHY: √ means the principal (positive) root only. The equation x² = 25 is what has two answers.
@viz sqside n=5 side="5" cell=18 labels="Area = 25;Side = √25 = 5" caption="A side can't be −5. √ gives the positive one."
RIGHT: √25 = 5. −√25 = −5. x² = 25 gives x = ±5.
:::

::: example Worked Example 1 — Solve x² = 49
Step 1: Which numbers squared give 49? 7² = 49 and (−7)² = 49.
Step 2: x = ±√49 = [[±7]]
@viz numberline min=-8 max=8 every=2 keypoints="-7:−7;7:7"
Step 3: Check: (−7)² = 49 ✓ and 7² = 49 ✓
:::

::: example Worked Example 2 — Fractions and decimals

b) x² = 0.36. x = ±[[0.6]]
@viz numberline min=-1 max=1 step=0.1 every=0.5 keypoints="-0.6:−0.6;0.6:0.6"

:::

::: example Worked Example 3 — A square ice rink
A backyard rink in Edmonton is a square. Its area is 144 m². How long is each side?
@viz sqside n=12 side="s" cell=12 fill=soft labels="Area = 144 m²;s² = 144"

(lines 2)

## Section 3: Estimating square roots
Learning target: I can estimate a square root, then check it.

### Vocabulary
- benchmark :: a perfect square near the number, to compare with :: 49 and 64 are benchmarks for 50
- estimate :: a close guess that you can explain :: √50 is about 7.1
- ≈ :: "is about equal to" :: √50 ≈ 7.07

#### Use the perfect squares on each side
50 is not a perfect square. It sits between 49 and 64.
So √50 sits between √49 = 7 and √64 = 8.
@viz srbench lo=7 hi=8 n=50 est="√50 ≈ 7.1" caption="50 is very close to 49. So √50 is very close to 7."

::: key Estimate a square root
1. Find the perfect squares just below and just above the number.
2. Their roots are your benchmarks. The answer is between them.
3. Decide which benchmark is closer. Estimate to one decimal place.
4. Check by squaring your estimate. Then use the √ key on a calculator.
:::

::: misconception
WRONG: "√50 ≈ 25. Half of 50 is 25."
WHY: 25 × 25 = 625. That is far bigger than 50.
@viz squares shapes="7x7" labels="7 × 7 = 49, almost 50" cell=12
RIGHT: 7² = 49, so √50 is just over 7. √50 ≈ 7.07.
:::
::: misconception
WRONG: "50 is between 49 and 64, so √50 ≈ 7.5. It's halfway."
WHY: 50 is not halfway from 49 to 64. It is only 1 past 49.
@viz srbench lo=7 hi=8 n=50 mid=1 est="√50 ≈ 7.07, not 7.5"
RIGHT: 7.5² = 56.25. √50 is close to 7: √50 ≈ 7.07.
:::

::: example Worked Example 1 — Estimate √30
Step 1: Benchmarks: 25 < 30 < 36. So 5 < √30 < 6.
@viz srbench lo=5 hi=6 n=30 est="√30 ≈ [[5.5]]"
Step 2: 30 is 5 past 25 and 6 below 36. It is near the middle, a bit closer to 25.
Step 3: Try 5.5. Check: 5.5² = 5.5 × 5.5 = [[30.25]]. Very close to 30!
Step 4: Calculator: √30 = 5.477… ≈ [[5.5]]
:::

::: example Worked Example 2 — A square garden

@viz sqside n=7.07 grid=0 side="√50 m" fill=plant cell=20 labels="Area = 50 m²;Side = √50 m"
Step 1: Side = √50. Benchmarks: 7² = 49 and 8² = 64.
Step 2: Estimate: just over 7.
Step 3: Calculator: √50 = 7.071… ≈ [[7.1]] m.
How much fence goes around it? 4 × 7.07 ≈ [[28.3]] m.
:::

::: example Worked Example 3 — Estimate √110

@viz srbench lo=10 hi=11 n=110 keydot=1 est="√110 ≈ [[10.5]]"

@viz flow steps="Side|Square it: Area|Square root: Side|× 4: Perimeter"

From the area: side = √area.
From the perimeter: side = perimeter ÷ 4.

## Section 4: Irrational numbers and the real number line
Learning target: I can sort and order rational and irrational numbers.

### Vocabulary
- irrational number :: a number you can't write as a fraction. Its decimal never ends and never repeats. :: √2, √50, π
- real numbers :: all the rational and all the irrational numbers together :: −4, {1/3}, √2, π
- exact value :: the number itself, with nothing rounded :: √2, π
- approximate value :: a rounded decimal that is close :: √2 ≈ 1.41, π ≈ 3.14

#### √2 never ends
Find √2 on a calculator: 1.414213562… The digits keep going. No group repeats.
@viz sqside n=1.41 grid=0 side="√2" cell=80 fill=soft labels="Area = 2;Side = √2 ≈ 1.414…"
Zoom in. Each zoom gives one more digit, forever.
@viz numberline min=1 max=2 step=0.1 every=0.5 points="1.4142:√2" caption="1.4² = 1.96 and 1.5² = 2.25. So √2 is between 1.4 and 1.5."
@viz numberline min=1.4 max=1.5 step=0.01 every=0.05 points="1.4142:√2" caption="1.41² = 1.9881 and 1.42² = 2.0164. So √2 is between 1.41 and 1.42."

::: key Rational or irrational?
**Rational**: you can write it as {a/b}. The decimal ends (0.25) or repeats (0.{bar:3}).
**Irrational**: you can't. The decimal never ends and never repeats (1.414213…).
The square root of a perfect square is rational: √49 = 7, √{9/16} = {3/4}.
The square root of a non-perfect square is irrational: √2, √50, √120.
:::

#### π is irrational too
Roll a wheel with a diameter of 1 m one full turn. It goes π m: 3 diameters and a bit.
@viz wheel dlabel="1 m" clabel="one turn = π m" seglabel="1 m" bitlabel="0.14159…"
π = 3.14159265… It never ends and never repeats.

::: misconception
WRONG: "π = 3.14 exactly." / "1.41 is √2."
WHY: Square 1.41: 1.41 × 1.41 = 1.9881. That is not 2. 1.41 is only close to √2.
@viz numberline min=1.4 max=1.42 step=0.001 every=0.005 points="1.41:1.41;1.4142:√2" caption="Zoom in. 1.41 and √2 are two different points."
RIGHT: √2 and π are **exact**. 1.41 and 3.14 are **approximate**: √2 ≈ 1.41 and π ≈ 3.14.
:::

#### The real numbers
Every rational and every irrational number is a **real number**.
Each one has its own point on the number line.
@viz srreal nat="1;9 = √81" int="0;−4" rat="½;0.{bar:3};−2.5" irr="√2;√50;π;−√3" caption="The rational numbers and the irrational numbers together make the real numbers."

::: key Real numbers
Rational: ends or repeats. Irrational: never ends, never repeats (√2, π).
√2 and π are exact. 1.41 and 3.14 are approximate.
:::
@viz srreal nat="1;2;9" int="0;−3" rat="½;0.{bar:3}" irr="√2;π"

| Mistake | Fix |
|---|---|
| √16 = 8 (half) | √16 = 4, because 4 × 4 = 16. |
| √25 = ±5 | √25 = 5. x² = 25 has two answers: x = ±5. |
| √−9 = −3 | (−3)² = 9. No real number squares to a negative. |
| √50 ≈ 25 or ≈ 7.5 | 7² = 49, so √50 is just over 7 (≈ 7.07). |
| π = 3.14, √2 = 1.41 | π ≈ 3.14 and √2 ≈ 1.41. They never end or repeat. |
