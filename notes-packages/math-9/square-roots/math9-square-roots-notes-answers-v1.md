## Section 1 — Perfect Squares and Principal Square Roots

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Square | The result of multiplying a number by itself | 7² = 49 |
| Perfect square | Any number that is the square of a positive integer | 49, 100, 144 |
| Square root | A number that, when squared, gives the radicand | √49 = 7 (since 7² = 49) |
| Principal square root | The positive square root (the radical symbol always means this) | √25 = 5 (not ±5) |
| Radical symbol (√) | The symbol indicating principal (positive) square root | √36 = 6 |
| Radicand | The number under the radical symbol | In √36, radicand = 36 |

### Guided Notes

| Blank / Prompt | Answer |
|---|---|
| If 5² = 25, then √25 = ___ | **5** |
| If 9² = 81, then √81 = ___ | **9** |
| A perfect square is the square of a ___ integer | **positive** (or whole) |

**Perfect square table:**

| Integer | Squared | Perfect square |
|---|---|---|
| 1 | 1² | 1 |
| 2 | 2² | 4 |
| 3 | 3² | **9** |
| 4 | 4² | **16** |
| 5 | 5² | **25** |
| 6 | 6² | **36** |
| 7 | 7² | **49** |
| 8 | 8² | **64** |
| 9 | 9² | **81** |
| 10 | 10² | **100** |
| 11 | 11² | **121** |
| 12 | 12² | **144** |

| Blank / Prompt | Answer |
|---|---|
| √25 = ___ only (principal means ___) | 5 only; **positive** root |
| Expression that gives −3 | **−√9** |
| Radicand of √36 | **36** |
| Principal square root of 36 | **6** |

**Evaluate:**

| Expression | Value | Note |
|---|---|---|
| √144 | **12** | 12² = 144 |
| −√25 | **−5** | Negative is in front; principal root is 5, then negated |
| √(−16) | **undefined (no real solution)** | No real number squared gives a negative |
| √(49/64) | **7/8** | √49/√64 = 7/8 |

| Blank | Answer |
|---|---|
| Can you take √ of a negative? | **No** |
| Because no real number squared gives a ___ result | **negative** |

**Square roots of fractions:**

| Expression | Answer |
|---|---|
| √(9/25) = √9/√25 = ___/___ | **3/5** |
| √(4/49) | **2/7** |
| √(16/81) | **4/9** |

### Retrieval Check — Section 1

| Question | Answer |
|---|---|
| 1. √64 | **8** |
| 2. −√36 and √(−36) — same? | −√36 = **−6** (negate the root). √(−36) = **undefined** (negative radicand). NOT the same. |
| 3. √(25/144) | **5/12** |
| 4. "√100 = ±10" — correct? | **No.** The principal square root is the positive root by definition. √100 = 10. Writing ±√100 gives ±10, but √100 alone = 10. |
| 5. (Stretch) √50 between which integers? | 7² = 49 < 50 < 64 = 8², so **7 < √50 < 8**. Since 50 is only 1 above 49, √50 ≈ 7.1. |

## Section 2 — Non-Perfect Squares and Irrational Numbers

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Irrational number | A real number that cannot be written as a/b; decimal never terminates or repeats | √2 = 1.41421..., π |
| Non-perfect square | A positive integer that is not the square of any integer | 2, 3, 5, 7, 50 |
| Estimate | An approximate value (not exact) | √47 ≈ 6.9 |
| Real number | Any number on the number line — rational or irrational | −3, 1/2, √5, π |

### Guided Notes

| Blank / Prompt | Answer |
|---|---|
| √3, √7, √10 are ___ numbers | **irrational** |
| Connection prompt: square root = power of ___ | **1/2** — √x = x^(1/2) |

**Estimating √47:**

| Blank | Answer |
|---|---|
| ___ < 47 < ___ so √___ < √47 < √___ | **36 < 47 < 49** so **6 < √47 < 7** |
| Is 47 closer to 36 or 49? | **49** (distance 2 vs. 11) |
| Better estimate | √47 ≈ **6.9** |

**Estimate table:**

| Expression | Between | Estimate |
|---|---|---|
| √20 | 4 and 5 (16 < 20 < 25) | ≈ **4.5** |
| √55 | 7 and 8 (49 < 55 < 64) | ≈ **7.4** |
| √80 | 8 and 9 (64 < 80 < 81) | ≈ **8.9** |
| √120 | 10 and 11 (100 < 120 < 121) | ≈ **11.0** |

**Number line — √5, √10, √15, √20:** ≈ 2.2, 3.2, 3.9, 4.5

**Real number system:**

| Blank | Answer |
|---|---|
| Where does √9 go? | **Integer** (√9 = 3, which is an integer → also rational, real) |
| Where does √10 go? | **Irrational** (real, but not rational or integer) |

### Retrieval Check — Section 2

| Question | Answer |
|---|---|
| 1. √49 rational or irrational? √50? | √49 = 7 → **rational** (integer). √50 is irrational (50 not a perfect square; decimal never terminates/repeats). |
| 2. Estimate √30 | 5² = 25 < 30 < 36 = 6². Distance: 30−25=5 vs 36−30=6. Closer to 25. √30 ≈ **5.5** |
| 3. Place √7 on number line | 2² = 4 < 7 < 9 = 3², so 2 < √7 < 3. Closer to 3 (distance 2) than 4 (distance 3). Plot √7 ≈ **2.6** |
| 4. Can a number be both rational and irrational? | **No** — they are mutually exclusive categories by definition. |
| 5. (Stretch) Square, area 50 cm² | s = **√50 = 5√2 cm** (exact). Approx: **≈ 7.1 cm**. **Irrational** — 50 is not a perfect square. |

## Section 3 — The Pythagorean Theorem

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Right triangle | Triangle with exactly one 90° angle | 3-4-5 triangle |
| Hypotenuse | Side opposite the right angle; always the longest side | c in a² + b² = c² |
| Leg | Either of the two shorter sides forming the right angle | a and b in a² + b² = c² |
| Pythagorean theorem | In a right triangle: a² + b² = c² | 3² + 4² = 5² ✓ |
| Pythagorean triple | Three positive integers satisfying a² + b² = c² | (3,4,5), (5,12,13) |

### Guided Notes

| Blank / Prompt | Answer |
|---|---|
| Square of the ___ (c) = sum of squares of the two ___ (a, b) | **hypotenuse; legs** |
| Hypotenuse: side ___ the right angle; always the ___ side | **opposite; longest** |

**Worked Example 1 — legs 6 and 8:**

| Blank | Answer |
|---|---|
| 6² + 8² = ___ + ___ | 36 + 64 |
| c² = ___ | 100 |
| c = √___ = ___ | √100 = **10** |

Explain: we take the square root to undo c² and find c. Principal root because a side length must be positive.

**Worked Example 2 — hyp 10, leg 4:**

| Blank | Answer |
|---|---|
| ___ + b² = ___ | 16 + b² = 100 |
| b² = ___ | 84 |
| b = √___ ≈ ___ m | √84 ≈ **9.2 m** |

Explain: c² gives the total; we subtract the known leg-squared first to isolate b² before square-rooting.

**Misconception test — sides 3, 4, 6:**

| Blank | Answer |
|---|---|
| 3² + 4² = ___ | 25 |
| 6² = ___ | 36 |
| Does it work? Is this a right triangle? | 25 ≠ 36. **No right angle.** |

| Blank | Answer |
|---|---|
| 6-8-10 is a ___ × (3,4,5) triple | **2×** |

**Alberta context — pipeline:**

| Blank | Answer |
|---|---|
| √(9² + 40²) = √(___ + ___) | √(81 + 1600) = √1681 |
| = ___ km | **41 km** *(note: 41² = 1681 — a Pythagorean triple)* |

### Retrieval Check — Section 3

| Question | Answer |
|---|---|
| 1. Legs 5 and 12 — hypotenuse | 5² + 12² = 25+144 = 169 = 13². **Hypotenuse = 13** |
| 2. Hyp 15, leg 9 — other leg | 9² + b² = 15². 81 + b² = 225. b² = 144. **b = 12** |
| 3. Sides 7, 24, 25 — right angle? | 7² + 24² = 49 + 576 = 625. 25² = 625. **Yes, right angle ✓** |
| 4. Student error — no right angle | Assumed a 90° angle; theorem requires exactly one right angle to hold. |
| 5. (Stretch) Square, diagonal 10 cm | Diagonal² = s² + s² = 2s². 2s² = 100. s² = 50. **s = √50 = 5√2 cm** |

## Section 4 — Square Roots of Rational Numbers

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Square root of a fraction | √(a/b) = √a/√b (when a ≥ 0, b > 0) | √(9/16) = 3/4 |
| Square root of a decimal | Convert to fraction or recognize decimal pattern | √0.49 = 0.7 |

### Guided Notes

| Blank / Prompt | Answer |
|---|---|
| √(9/16) = √9/√16 = ___/___ | **3/4** |
| √0.49 = √(49/100) = ___/___ = ___ | 7/10 = **0.7** |
| Method 2: ___ × ___ = 0.49 | 0.7 × 0.7 |

**Practice table:**

| Expression | Answer |
|---|---|
| √0.25 | **0.5** (= √(1/4) = 1/2) |
| √(4/9) | **2/3** |
| √1.44 | **1.2** (= √(144/100) = 12/10) |
| √(0.01) | **0.1** (= √(1/100) = 1/10) |

**Connecting to exponents:**

| Blank | Answer |
|---|---|
| x^(1/2) = ___ | **√x** |
| 9^(1/2) = ___ and √9 = ___ | **3** and **3** — they match |

**Distribution table:**

| Expression | Distributes? | Example answer |
|---|---|---|
| √(a × b) | **Yes** | √(4×9) = √36 = **6** = √4×√9 ✓ |
| √(a ÷ b) | **Yes** | √(36/4) = √9 = **3** = √36/√4 ✓ |
| √(a + b) | **No** | √(9+16) = 5 ≠ 3+4 = 7 |
| √(a − b) | **No** | √(25−9) = 4 ≠ 5−3 = 2 |

**Misconception verify (a=16, b=9):** Left = √25 = 5. Right = 4+3 = 7. **Not equal.**

### Retrieval Check — Section 4

| Question | Answer |
|---|---|
| 1. √(64/25) | **8/5** |
| 2. √1.21 | √(121/100) = 11/10 = **1.1** |
| 3. √(16+9) = √16+√9 → disprove | √25 = 5; √16+√9 = 4+3 = 7. **5 ≠ 7**. Correct answer: **5**. |
| 4. 16^(1/2) | **4** (= √16) |
| 5. (Stretch) √(0.25)³ | (0.25)³ = (1/4)³ = 1/64. √(1/64) = 1/8 = **0.125**. **Rational.** |

## Unit Synthesis

### Part A — Key ideas

| Question | Model answer |
|---|---|
| 1. Perfect vs. non-perfect square | Perfect: result of squaring an integer (e.g., 49 = 7²). Non-perfect: positive integer not the square of any integer (e.g., 50). |
| 2. Why is √2 irrational? | Its decimal expansion never terminates and never repeats — it has been mathematically proven impossible to write √2 as any fraction a/b, no matter how precise. |
| 3. Pythagorean theorem | a² + b² = c², where a, b are the **legs** and c is the **hypotenuse** (side opposite the right angle). |
| 4. x^(1/2) equals? Why? | **√x**. Because x^(1/2) × x^(1/2) = x^1, and √x × √x = x — they perform the same operation. |

### Part B — Ladder problem (13 m, 5 m from wall)

| Step | Work |
|---|---|
| a = 5, c = 13, b = ? | a² + b² = c² |
| 5² + b² = 13² | 25 + b² = 169 |
| b² = 144 | b = √144 = **12 m** |
| Rational or irrational? | **Rational** — (5, 12, 13) is a Pythagorean triple; √144 = 12 exactly |
