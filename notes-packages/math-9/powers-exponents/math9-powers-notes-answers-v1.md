## Section 1 — What Is a Power?

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Power | Shorthand for repeated multiplication of the same factor | 3⁴ = 3×3×3×3 |
| Base | The factor being repeatedly multiplied | In 3⁴, base = 3 |
| Exponent | Tells how many times to use the base as a factor | In 3⁴, exponent = 4 |
| Evaluate | Find the numerical value | Evaluate 3⁴ = 81 |
| Integral base | A base that is an integer (positive, negative) | (−3)⁴; base is the integer −3 |

### Guided Notes

**Four representations:**

| Verbal | Symbolic | Expanded | Value |
|---|---|---|---|
| "3 multiplied by itself 4 times" | 3⁴ | 3×3×3×3 | **81** |
| "5 multiplied by itself 2 times" | **5²** | 5×5 | **25** |
| **"2 multiplied by itself 6 times"** | 2⁶ | 2×2×2×2×2×2 | **64** |
| **"4 multiplied by itself 3 times"** | **4³** | 4×4×4 | **64** |

| Blank | Answer |
|---|---|
| The exponent is… | the count of how many times the base appears as a factor |

**Base and exponent table:**

| Power | Base | Exponent |
|---|---|---|
| 7³ | 7 | 3 |
| (−2)⁵ | **−2** | **5** |
| 10² | 10 | 2 |
| (−1)⁸ | **−1** | **8** |

**Worked Example 1 — 2⁵:**

> 2⁵ = 2×2×2×2×2 = **32**

Explain: five 2s because the exponent (5) counts the base (2), not the other way. Five twos, not two fives.

**Worked Example 2 — (−3)⁴:**

| Step | Work | Sign |
|---|---|---|
| (−3) × (−3) | = 9 | neg × neg = **positive** |
| 9 × (−3) | = −27 | pos × neg = **negative** |
| −27 × (−3) | = **81** | neg × neg = **positive** |

(−3)⁴ = **81**

Predict (−3)⁵: **negative** — 5 is odd; an odd count of negative factors gives a negative product.

**Misconception:**

| Expression | Value | Same? |
|---|---|---|
| −2³ | **−8** (base is 2; exponent applies first: 2³=8; then negate) | Different! |
| (−2)³ | **−8** (base is −2; (−2)×(−2)×(−2) = −8) | Different interpretation, same value here |

*Note: The distinction matters more with even exponents: −2⁴ = −16 but (−2)⁴ = +16.*

**Sign pattern — (−2)ⁿ:**

| Power | Expanded | Value | Sign |
|---|---|---|---|
| (−2)¹ | −2 | −2 | Negative |
| (−2)² | (−2)(−2) | **4** | **Positive** |
| (−2)³ | (−2)(−2)(−2) | **−8** | **Negative** |
| (−2)⁴ | … | **16** | **Positive** |
| (−2)⁵ | … | **−32** | **Negative** |
| (−2)⁶ | … | **64** | **Positive** |

Rule: **even exponent → positive; odd exponent → negative** (for a negative base)

### Retrieval Check — Section 1

| Question | Answer |
|---|---|
| 1. What does the exponent tell you? | How many times to use the base as a factor — the count of multiplications |
| 2. (−4)³ | (−4)×(−4)×(−4) = 16×(−4) = **−64** |
| 3. "−5² = 25" — correct? | **No.** −5² means −(5²) = −25. The base is 5, not −5. Brackets are needed for the base to include the negative: (−5)² = 25. |
| 4. (−1)¹⁰⁰ | **1** — exponent 100 is even; even power of a negative base is always positive |
| 5. (Stretch) Power with negative base, even exponent, value < 10 | e.g., **(−3)² = 9** or **(−2)² = 4** — even exponent ensures positive; small base keeps value below 10 |

## Section 2 — The Zero Exponent

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Zero exponent | An exponent of zero; result is 1 for any nonzero base | 7⁰ = 1, (−5)⁰ = 1 |

### Guided Notes

**Pattern table — base 3:**

| Power | Expanded | Value |
|---|---|---|
| 3⁵ | 3×3×3×3×3 | 243 |
| 3⁴ | 3×3×3×3 | 81 |
| 3³ | 3×3×3 | **27** |
| 3² | 3×3 | **9** |
| 3¹ | 3 | **3** |
| 3⁰ | — | **1** |

3¹ ÷ 3 = 1, so **3⁰ = 1**

**Pattern table — base 5:**

| Power | Value |
|---|---|
| 5³ | 125 |
| 5² | **25** |
| 5¹ | **5** |
| 5⁰ | **1** |

5⁰ = **1**. **a⁰ = 1** for any a ≠ 0.

**Misconception verify:**

| Expression | Value |
|---|---|
| 10² ÷ 10 | **10** (= 10¹) |
| 10¹ ÷ 10 | **1** (= 10⁰) |
| So 10⁰ = | **1** |

### Retrieval Check — Section 2

| Question | Answer |
|---|---|
| 1. 7⁰ | **1** |
| 2. (−15)⁰ | **1** |
| 3. Correct "3⁰ = 0" | The pattern shows: every time the exponent drops by 1, divide by the base. 3¹ = 3. 3¹ ÷ 3 = 1. So 3⁰ = 1, not 0. An exponent does not mean "multiply by zero" — it counts factors. |
| 4. (Stretch) (3⁰ + 4⁰)² vs. 4 | 3⁰ = 1, 4⁰ = 1. Sum = 2. 2² = 4. **Equal to 4.** |

## Section 3 — Product of Powers

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Product of powers rule | When multiplying powers with the same base, add the exponents: aᵐ × aⁿ = aᵐ⁺ⁿ | 2³ × 2⁴ = 2⁷ |
| Like bases | Powers sharing the same base | 3², 3⁵ have like bases |

### Guided Notes

**Discovery table:**

| Expression | Total factors | Simplified power |
|---|---|---|
| 2³ × 2⁴ | 7 twos | 2⁷ |
| 3² × 3⁵ | **7** threes | **3⁷** |
| 5⁴ × 5¹ | **5** fives | **5⁵** |
| a³ × a⁶ | **9** a's | **a⁹** |

Rule: add the exponents. **aᵐ × aⁿ = aᵐ⁺ⁿ**

**Worked Example — (−4)³ × (−4)⁵:**

| Blank | Answer |
|---|---|
| Same base? | Yes — both (−4) |
| Apply rule: (−4)^(___+___) | (−4)^(3+5) = **(−4)⁸** |
| Positive or negative? | **Positive** — exponent 8 is even |

Explain: adding exponents counts the total number of (−4) factors (3 + 5 = 8). Multiplying the exponents would miscount them.

| Blank | Answer |
|---|---|
| x⁴ × x² × x³ = x^(_+_+_) | x^(4+2+3) = **x⁹** |

**Misconception verify:** 2³ × 3⁴ = 8 × 81 = 648. 6⁷ = 279,936. **Not equal.**

**When does the rule apply?**

| Expression | ✓/✗ | Reason |
|---|---|---|
| 5⁴ × 5³ | ✓ | Same base (5) |
| 3² × 4² | **✗** | Different bases — cannot combine |
| m⁵ × m | **✓** | m = m¹; same base → m⁶ |
| 2x³ × 3x² | **✓** (for x) | Coefficients multiply: 6x⁵ |
| a⁴b² × a³b | **✓** | Apply separately: a⁷b³ |

### Retrieval Check — Section 3

| Question | Answer |
|---|---|
| 1. Product of powers rule | When multiplying powers with the same base, add the exponents |
| 2. a⁵ × a⁴ | **a⁹** |
| 3. (−2)³ × (−2)⁶ | **(−2)⁹** — negative (odd exponent) |
| 4. "4³ × 4⁵ = 4¹⁵" — error? | Multiplied exponents instead of adding. Correct: **4⁸** |
| 5. (Stretch) 3² × 3⁰ × 3³ | 3^(2+0+3) = 3⁵ = **243**. The 3⁰ = 1 term does not change the product — multiplying by 1 is an identity operation. |

## Section 4 — Quotient of Powers

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Quotient of powers rule | When dividing powers with the same base, subtract the exponents: aᵐ ÷ aⁿ = aᵐ⁻ⁿ | 3⁵ ÷ 3² = 3³ |

### Guided Notes

**Discovery table:**

| Expression | Result |
|---|---|
| 4⁶ ÷ 4² | **4⁴** |
| a⁷ ÷ a³ | **a⁴** |
| (−2)⁸ ÷ (−2)⁵ | **(−2)³** |

Rule: subtract exponents. **aᵐ ÷ aⁿ = aᵐ⁻ⁿ**

| Blank | Answer |
|---|---|
| x⁹ ÷ x⁴ = x^(___−___) | x^(9−4) = **x⁵** (9 factors, cancel 4, 5 remain) |

**Connection to zero exponent:**

| Blank | Answer |
|---|---|
| a⁵ ÷ a⁵ = a^(___−___) = a^___ | a^(5−5) = a⁰ |
| Any number ÷ itself = ___ | 1 |
| Therefore a⁰ = ___ | **1** |

**Negative exponent preview:**

| Blank | Answer |
|---|---|
| 3² ÷ 3⁵ = 3^___ | 3^(2−5) = 3**⁻³** |
| Expanded: 1/3³, so 3⁻³ = ___ | **1/27** |
| Negative exponent moves to the ___ of a fraction | **denominator** |

### Retrieval Check — Section 4

| Question | Answer |
|---|---|
| 1. Quotient of powers rule | When dividing powers with the same base, subtract the bottom exponent from the top |
| 2. m⁸ ÷ m³ | **m⁵** |
| 3. (−5)⁶ ÷ (−5)² | **(−5)⁴** — positive (even exponent) |
| 4. a⁴ ÷ a² = a² or a⁸? | a² is **correct**. The wrong student multiplied (used product rule). Quotients: subtract. |
| 5. (Stretch) Why a⁰ = 1 via quotient rule | aⁿ ÷ aⁿ = a^(n−n) = a⁰ by the quotient rule. But aⁿ ÷ aⁿ = 1 because any nonzero number divided by itself equals 1. Therefore a⁰ = 1. |

## Section 5 — Power of a Power

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Power of a power rule | When raising a power to another power, multiply the exponents: (aᵐ)ⁿ = aᵐⁿ | (2³)⁴ = 2¹² |

### Guided Notes

**Discovery table:**

| Expression | Simplified |
|---|---|
| (3²)⁴ | **3⁸** (2×4=8) |
| (a⁴)³ | **a¹²** (4×3=12) |
| (5²)⁵ | **5¹⁰** (2×5=10) |

Rule: **(aᵐ)ⁿ = aᵐⁿ** (multiply the exponents)

**Worked Example — ((−2)³)⁴:**

| Blank | Answer |
|---|---|
| (−2)^(___×___) | (−2)^(3×4) = **(−2)¹²** |
| Positive or negative? | **Positive** — exponent 12 is even |

Explain: the power of a power multiplies because we have n copies of aᵐ — each copy contributes m to the exponent, so total = m×n. In Section 3 we added because we had two separate groups of factors being joined.

**Misconception table:**

| Expression | Rule | Simplified |
|---|---|---|
| (x²)³ | Power of a power | **x⁶** |
| x² × x³ | Product of powers | **x⁵** |
| (y⁵)² | Power of a power | **y¹⁰** |
| y⁵ × y² | Product of powers | **y⁷** |

### Retrieval Check — Section 5

| Question | Answer |
|---|---|
| 1. Power of a power rule | (aᵐ)ⁿ = aᵐⁿ |
| 2. (a³)⁵ | **a¹⁵** |
| 3. ((−3)²)³ | (−3)^(2×3) = (−3)⁶ = **729** (positive: even exponent) |
| 4. (2³)⁴ vs. (2⁴)³ | Both = 2^12 = **4,096**. Multiplication is commutative: 3×4 = 4×3. |
| 5. (Stretch) (x³)⁴ × (x²)⁵ | x¹² × x¹⁰ = **x²²** |

## Section 6 — Power of a Product and Quotient

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Power of a product rule | Exponent distributes to each factor in a product: (ab)ⁿ = aⁿbⁿ | (2x)³ = 8x³ |
| Power of a quotient rule | Exponent distributes to numerator and denominator: (a/b)ⁿ = aⁿ/bⁿ | (x/3)² = x²/9 |

### Guided Notes

**Power of product table:**

| Expression | Result |
|---|---|
| (2×3)² = 4×9 | **36** |
| (ab)³ | a³**b³** |
| (2x)⁴ | **16x⁴** |
| (3mn)² | **9m²n²** |

Rule: **(ab)ⁿ = aⁿbⁿ**

| Blank | Answer |
|---|---|
| (a/b)³ = a³/b³ → rule: (a/b)ⁿ = ___ | **aⁿ/bⁿ** |

**Worked Example — (3x²)⁴:**

| Step | Work |
|---|---|
| Distribute exponent | 3⁴ × (x²)⁴ |
| 3⁴ = ___ | **81** |
| (x²)⁴ = x^___ | **x⁸** |
| Result | **81x⁸** |

Explain: the factor 3 is inside the bracket with the x², so the exponent applies to everything inside — both the coefficient and the variable. Forgetting the coefficient gives 5x⁸ instead of 81x⁸ (an error by a factor of 81).

**Misconception — (a+b)² ≠ a²+b²:**

| Blank | Answer |
|---|---|
| (3+4)² = 7² | **49** |
| 3² + 4² = 9+16 | **25** |
| Equal? | **No — 49 ≠ 25** |

### Retrieval Check — Section 6

| Question | Answer |
|---|---|
| 1. (2a)³ | **8a³** |
| 2. (x/3)² | **x²/9** |

## Unit Synthesis

**Reconstructed laws:**

| Rule | Symbol form |
|---|---|
| Product of powers | aᵐ × aⁿ = **aᵐ⁺ⁿ** |
| Quotient of powers | aᵐ ÷ aⁿ = **aᵐ⁻ⁿ** |
| Power of a power | (aᵐ)ⁿ = **aᵐⁿ** |
| Power of a product | (ab)ⁿ = **aⁿbⁿ** |
| Zero exponent | a⁰ = **1** |
| Negative exponent | a⁻ⁿ = **1/aⁿ** |

**Model explanations (any two):**

- *Product rule:* Expanding shows 3 twos × 4 twos = 7 twos total. Adding exponents counts the combined factors correctly.
- *Zero exponent:* Each step down divides by the base. Starting at a¹ = a, dividing by a gives a/a = 1. The pattern must give 1, not 0.
- *Negative exponent:* Quotient rule applied to a smaller top: a² ÷ a⁵ = a⁻³. Expanding gives 1/a³. So a⁻ⁿ = 1/aⁿ — an instruction to invert, not to negate.
- *Power of product vs. sum:* Multiplication lets us regroup factors freely; (ab)² = a²b² by regrouping. Addition cannot be regrouped the same way — (a+b)² must be expanded as (a+b)(a+b), producing the cross-term 2ab.
