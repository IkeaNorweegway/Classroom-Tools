### Guided Notes

A **linear relation** is a relationship between two variables where equal changes in one variable produce _______________ changes in the other.

**The Rule of Four — four ways to represent the same relationship:**

| Form | Description | What it shows |
|---|---|---|
| **Verbal** | A sentence describing the rule | The meaning — what's happening in context |
| **Table** | Pairs of (x, y) values | Specific values and the pattern |
| **Equation** | An algebraic rule (e.g., y = 3x + 2) | The general rule for any value |
| **Graph** | Points/line on coordinate axes | The visual shape and direction |

## Section 2 — Slope as Rate of Change

**Learning target:** I can calculate slope using the rise/run formula, interpret slope as a rate of change, and distinguish between positive, negative, zero, and undefined slopes.

### Vocabulary

| Term | Definition in your own words | One example |
|---|---|---|
| Slope | | |
| Rise | | |
| Run | | |
| Rate of change | | |
| Positive slope | | |
| Negative slope | | |
| Zero slope | | |
| Undefined slope | | |

### Guided Notes

**Slope** measures how _______________ a line is and in what _______________.

slope = rise/run = ___change in y___ / ___change in x___

Using two points (x₁, y₁) and (x₂, y₂):

m = (y₂ − y₁) / (x₂ − x₁)

---

**Worked Example 1 — From a graph:**

A line passes through (1, 2) and (4, 8).

> Rise = y₂ − y₁ = 8 − 2 = ___
>
> Run = x₂ − x₁ = 4 − 1 = ___
>
> Slope = ___/___  = ___

**Explain:** The slope of 2 means "for every 1 unit right, the line goes ___ units up." How would you see this on the graph?

_______________________________________________

---

**Worked Example 2 — Negative slope:**

A line passes through (0, 6) and (3, 0).

> m = (0 − 6)/(3 − 0) = ___/___  = ___

**Explain:** A negative slope means the line is going _______________. What does −2 mean in a context like "the temperature drops 2°C per hour"?

_______________________________________________

---

> **MISCONCEPTION: Slope depends on which two points you pick**
>
> Wrong idea: "If I use different points on the line, I'll get a different slope."
>
> Why it fails: For a straight line, slope is constant — every pair of points on the same line gives the same rise/run ratio. This is the defining property of a *line*. If the slope changes depending on which points you pick, the relationship is NOT linear.
>
> Check: A line passes through (0, 1), (2, 5), and (4, 9). Find the slope using (0,1) and (2,5): ___. Now find the slope using (2,5) and (4,9): ___. Same? ___

---

**The four slope types:**

| Slope type | What the line does | Value |
|---|---|---|
| Positive | | m > 0 |
| Negative | | m < 0 |
| Zero | | m = ___ |
| Undefined | | m = ___ |

Match to a context:
- "Temperature stays at 0°C all day" → slope = ___
- "A wall is perfectly vertical" → slope = ___
- "A ski hill drops 3 m per 10 m across" → slope = ___

---

**Slope as rate of change:**

When slope is applied to a real-world relation, the units matter.

> A car travels 300 km in 3 hours.
> m = 300 km / 3 h = ___ km/h

The slope tells you: for each hour (run), you travel ___ km (rise).

**Alberta context:**

### Guided Notes

**Slope-intercept form:** y = mx + b

| Part | Symbol | What it is | On the graph |
|---|---|---|---|
| Slope | m | Rate of change | Steepness and direction |
| y-intercept | b | Starting value | Where line crosses y-axis |

**Reading the equation directly:**

y = 3x − 4

> Slope m = ___ &nbsp;&nbsp; y-intercept b = ___
> Starting point (0, b) = (0, ___)
> For each x that increases by 1, y changes by ___

---

**Worked Example — Write the equation from context:**

A Banff hotel charges $90 per night plus a one-time parking fee of $25.

> What is the starting value (when nights = 0)? ___
> What is the rate of change (cost per night)? ___
> Equation: C = ___ n + ___

**Graph this equation:**

Plot the y-intercept at (0, 25) and use the slope of 90 to find a second point.

Second point: (1, ___) &nbsp;&nbsp; Draw the line.

```
│250
│
│175
│
│100
│
│25
└──────────────
  0  1  2  3
```

---

> **MISCONCEPTION: The y-intercept is where the line crosses the x-axis**
>
> Wrong idea: "The intercept is where the line hits zero — that's the x-axis."
>
> Why it fails: "Intercept" means "crosses." The y-intercept crosses the y-axis (where x = 0). The x-intercept crosses the x-axis (where y = 0). In y = 3x − 4, the y-intercept is −4 (at the point (0, −4)), and the x-intercept is found by setting y = 0: 0 = 3x − 4, x = 4/3.
>
> Find both intercepts of y = 2x − 6:
> y-intercept (set x = 0): y = ___  → point: (___, ___)
> x-intercept (set y = 0): x = ___ → point: (___, ___)

---

**Finding b when given slope and a point:**

Slope m = 2, passes through (3, 7). Find b.

> y = mx + b
>
> 7 = 2(3) + b
>
> 7 = 6 + b
>
> b = ___
>
> Equation: y = ___

## Section 4 — Direct and Partial Variation

**Learning target:** I can distinguish between direct and partial variation, recognize each from a table, graph, or equation, and connect them to real-world contexts.

### Vocabulary

| Term | Definition in your own words | One example |
|---|---|---|
| Direct variation | | |
| Partial variation | | |
| Constant of variation | | |
| Initial value | | |

### Guided Notes

**Direct variation:** y varies directly with x.

- The equation has the form y = ___ (no constant added)
- The graph passes through the _______________
- The ratio y/x is _______________ for all values

**Partial variation:** y varies partially with x.

- The equation has the form y = mx + b where b ≠ ___
- The graph crosses the y-axis at b (NOT the origin)
- The ratio y/x is NOT constant — but the *differences* in y are

---

**Side-by-side comparison:**

| Feature | Direct variation | Partial variation |
|---|---|---|
| Equation | y = kx | y = kx + b, b ≠ 0 |
| Graph passes through | ___ | ___ |
| Example context | Cost = price × quantity | Cost = monthly fee + price × quantity |

---

**Identify from a table:**

Table A:

| x | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| y | 0 | 5 | 10 | 15 |

Type: _______________ Equation: ___

Table B:

| x | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| y | 8 | 12 | 16 | 20 |

Type: _______________ Equation: ___

**How to tell:** Look at the y-value when x = 0. If y = 0: _______________. If y ≠ 0: _______________.

---

**Alberta context — Two phone plans:**

Plan A: $0.15 per text, no monthly fee.
Plan B: $10/month + $0.05 per text.

Plan A equation: C = ___
Plan B equation: C = ___

For 50 texts: Plan A costs ___ Plan B costs ___
For 200 texts: Plan A costs ___ Plan B costs ___

At what number of texts do the plans cost the same? (Set the two equations equal and solve):

_______________________________________________

---

> **MISCONCEPTION: Direct variation just means "the numbers go up together"**
>
> Wrong idea: "If both x and y increase, the relation is direct variation."
>
> Why it fails: Partial variation also has both variables increasing. Direct variation specifically requires the graph to pass through the origin (0, 0) — meaning when x = 0, y = 0. The phone plan with a monthly fee is NOT direct variation, even though cost rises with usage.
>
> Check: Table A above — when x = 0, y = ___. Does it pass through the origin? ___
