## Section 1 — Patterns and the Four Representations

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Linear relation | A relationship where equal changes in x produce equal changes in y; graphs as a straight line | y = 3x + 2 |
| Table of values | A chart listing specific (x, y) pairs | x: 0,1,2 and y: 2,5,8 |
| Independent variable | The variable you choose/control; the input; usually x | Time, number of items |
| Dependent variable | The variable that depends on the input; the output; usually y | Cost, distance |
| Equation | An algebraic rule that gives y for any value of x | y = −2x + 5 |
| Rule of Four | Four equivalent ways to represent the same relation: verbal, table, equation, graph | All four show the same relationship |

### Guided Notes

| Blank | Answer |
|---|---|
| Equal changes in one variable produce ___ changes in the other | **equal** |

**Independent/dependent table:**

| Situation | Independent | Dependent |
|---|---|---|
| Cost depends on number of items | **Number of items** | **Cost** |
| Distance depends on travel time | **Travel time** | **Distance** |
| Temperature depends on time of day | **Time of day** | **Temperature** |

**Tree example (4 cm/year, started at 10 cm):**

| Year (x) | Height (y) |
|---|---|
| 0 | 10 |
| 1 | **14** |
| 2 | **18** |
| 3 | **22** |
| 4 | **26** |

Equation: y = **4**x + **10**

**Translation task — y = −2x + 5:**

| x | y |
|---|---|
| 0 | **5** |
| 1 | **3** |
| 2 | **1** |
| 3 | **−1** |

Pattern: y decreases by **2** each time x increases by 1.

| Blank | Answer |
|---|---|
| Independent variable is what you ___ | **choose / control** |
| Dependent variable ___ on it | **depends** |

## Section 2 — Slope as Rate of Change

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Slope | Measure of steepness and direction of a line; ratio of rise to run | m = 3 means 3 units up per 1 unit right |
| Rise | Vertical change; change in y (y₂ − y₁) | If y goes from 2 to 8, rise = 6 |
| Run | Horizontal change; change in x (x₂ − x₁) | If x goes from 1 to 4, run = 3 |
| Rate of change | Slope applied to a real-world context; how much y changes per unit of x | 100 km/h means 100 km per hour |
| Positive slope | Line rises from left to right | m = 2 |
| Negative slope | Line falls from left to right | m = −3 |
| Zero slope | Horizontal line; y doesn't change | y = 5 |
| Undefined slope | Vertical line; x doesn't change (division by zero) | x = 3 |

### Guided Notes

| Blank | Answer |
|---|---|
| Slope measures how ___ a line is and in what ___ | **steep; direction** |

**Worked Example 1 — (1,2) and (4,8):**

| Blank | Answer |
|---|---|
| Rise = 8 − 2 | **6** |
| Run = 4 − 1 | **3** |
| Slope = ___/___ | **6/3 = 2** |

"For every 1 unit right, line goes **2** units up" — on the graph, each step right leads to 2 steps up.

**Worked Example 2 — (0,6) and (3,0):**

| Blank | Answer |
|---|---|
| m = (0−6)/(3−0) = ___/___ | **−6/3 = −2** |
| Negative slope means line is going ___ | **downward (from left to right)** |

In context (−2°C per hour): temperature drops 2 degrees for each hour that passes.

**Misconception check:** (0,1)→(2,5): m=4/2=2. (2,5)→(4,9): m=4/2=2. **Same — yes.** Slope is constant along a line.

**Four slope types:**

| Slope type | What the line does | Value |
|---|---|---|
| Positive | Rises from left to right | m > 0 |
| Negative | Falls from left to right | m < 0 |
| Zero | Horizontal | m = **0** |
| Undefined | Vertical | m = **undefined** |

**Match contexts:**
- Constant temperature all day → slope = **0**
- Vertical wall → slope = **undefined**
- Ski hill drops → slope = **negative**

**Car:** 300 km / 3 h = **100 km/h**. For each hour, travel **100 km**.

**Alberta highway:** m = −120/800 = **−3/20 (= −0.15)**. The slope means: for every 800 m horizontal, the road drops 120 m — it descends at a rate of 15 cm per metre.

### Retrieval Check — Section 2

| Question | Answer |
|---|---|
| 1. Slope through (−2,3) and (4,−9) | m = (−9−3)/(4−(−2)) = −12/6 = **−2** |
| 2. Slope from table (x:0–3, y:4,7,10,13) | Constant difference = 3. **m = 3** |
| 3. Zero slope — what does it look like? | Horizontal line (y doesn't change). Context: constant temperature, flat road. |
| 4. 3/−2 vs. −3/2 — who is right? | **Both are right** — they are equal. Slope sign is in the result, not the numerator alone. |
| 5. (Stretch) Line through (a,0) and (0,b) | m = (b−0)/(0−a) = **−b/a** |

## Section 3 — The Equation y = mx + b

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Slope-intercept form | y = mx + b; slope and y-intercept visible directly | y = 3x − 4; m=3, b=−4 |
| y-intercept | Where the line crosses the y-axis; the value of y when x = 0 | In y=3x−4, y-int = −4 |
| x-intercept | Where the line crosses the x-axis; the value of x when y = 0 | In y=3x−4, x-int = 4/3 |
| Initial value | The y-intercept interpreted in context; starting value when x = 0 | $25 parking fee before any nights |

### Guided Notes

**y = 3x − 4:**

| Blank | Answer |
|---|---|
| Slope m = ___ | **3** |
| y-intercept b = ___ | **−4** |
| Starting point (0, ___) | (0, **−4**) |
| Each x+1 → y changes by ___ | **+3** |

**Hotel example:**

| Blank | Answer |
|---|---|
| Starting value (parking fee) | **$25** |
| Rate of change (per night) | **$90** |
| Equation: C = ___ n + ___ | C = **90**n + **25** |
| Second point: (1, ___) | (1, **115**) |

**Misconception — y = 2x − 6:**

| Blank | Answer |
|---|---|
| y-intercept (x=0): y = ___ → point | **y = −6 → (0, −6)** |
| x-intercept (y=0): x = ___ → point | **x = 3 → (3, 0)** |

**Finding b — m=2, through (3,7):**

| Blank | Answer |
|---|---|
| 7 = 2(3) + b → b = ___ | **1** |
| Equation: y = ___ | **y = 2x + 1** |

Why substitute (3,7): the point is ON the line, so its coordinates satisfy the equation — we use this to solve for the unknown b.

**y = −2x + 6 — Rule of Four:**

| Blank | Answer |
|---|---|
| Verbal: "Starting at ___, decreases by ___ per unit" | **6; 2** |

Table:

| x | y |
|---|---|
| 0 | **6** |
| 1 | **4** |
| 2 | **2** |
| 3 | **0** |

### Retrieval Check — Section 3

| Question | Answer |
|---|---|
| 1. y = −3x + 7 — slope and y-int | **m = −3, b = 7** |
| 2. Slope 4, y-int −2 | **y = 4x − 2** |
| 3. Through (0,5) and (2,11) | m = (11−5)/(2−0) = 3. **y = 3x + 5** |
| 4. y-intercept in hotel context | The y-intercept ($25) is the one-time parking fee — the cost before any nights are stayed. |
| 5. (Stretch) y=3x+2 and y=3x−5 | Same slope → **parallel** (never intersect). Different y-intercepts → different starting heights. Two lines with the same slope are always parallel. |

## Section 4 — Direct and Partial Variation

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Direct variation | y = kx; y is proportional to x; graph through origin | Fuel cost: C = 1.50d |
| Partial variation | y = kx + b where b ≠ 0; graph does NOT pass through origin | Taxi: C = 2.50 + 1.80d |
| Constant of variation | The slope k in y = kx | k = 1.50 in C = 1.50d |
| Initial value | The y-intercept b in partial variation | $2.50 base fare |

### Guided Notes

| Blank | Answer |
|---|---|
| Direct variation equation: y = ___ | **kx** (no constant added) |
| Graph passes through the ___ | **origin (0, 0)** |
| Ratio y/x is ___ for all values | **constant** |
| Partial: b ≠ ___ | **0** |

**Side-by-side:**

| Feature | Direct | Partial |
|---|---|---|
| Graph passes through | **origin** | **(0, b) — not origin** |

**Table identification:**

| Blank | Answer |
|---|---|
| Table A (y=0 when x=0) | **Direct variation.** Equation: **y = 5x** |
| Table B (y=8 when x=0) | **Partial variation.** b=8; slope=(12-8)/1=4. Equation: **y = 4x + 8** |
| How to tell | If y=0 when x=0: **direct**. If y≠0 when x=0: **partial** |

**Alberta phone plans:**

| Blank | Answer |
|---|---|
| Plan A: C = ___ | **0.15t** (direct variation) |
| Plan B: C = ___ | **0.05t + 10** (partial variation) |
| 50 texts: A = ___ B = ___ | A = **$7.50** | B = **$12.50** |
| 200 texts: A = ___ B = ___ | A = **$30** | B = **$20** |
| Break-even: 0.15t = 0.05t + 10 | 0.10t = 10 → **t = 100 texts** |

**Misconception check:** Table A x=0, y=**0**. Does pass through origin: **Yes → direct variation.**

### Retrieval Check — Section 4

| Question | Answer |
|---|---|
| 1. y=4x: direct or partial? y=4x+3? | y=4x: **direct**. y=4x+3: **partial** (b=3≠0) |
| 2. Taxi: $2.50 + $1.80/km | Equation: **C = 1.8d + 2.5**. **Partial variation** (base fare b≠0) |
| 3. Table (x:0,2,4,6; y:6,10,14,18) | y=6 at x=0 → b=6. Slope=2. **y=2x+6. Partial variation.** |
| 4. Why does direct always pass through origin? | y=kx: when x=0, y=k×0=0 always. The origin is always on the graph by definition. |
| 5. (Stretch) Same slope, one direct one partial | Same steepness (slope = same). Different y-intercepts → one passes through origin, other doesn't. **Parallel lines** at different heights. |

## Unit Synthesis

### Part A — Key ideas

| Question | Answer |
|---|---|
| 1. Four representations | Verbal (meaning in words), Table (specific values), Equation (general algebraic rule), Graph (visual shape and direction) |
| 2. Slope formula | m = (y₂ − y₁) / (x₂ − x₁) |
| 3. m and b in y=mx+b | m = slope (steepness and direction); b = y-intercept (starting value where line crosses y-axis) |
| 4. Direct vs. partial | Direct: y=kx, passes through origin, y/x constant. Partial: y=kx+b (b≠0), doesn't pass through origin. From table: x=0 gives y=0 → direct; y≠0 → partial. |

### Part B — Car rental ($50/day + $0.20/km)

Equation: **C = 0.20d + 50**

| km | 0 | 100 | 200 | 300 |
|---|---|---|---|---|
| Cost ($) | **50** | **70** | **90** | **110** |

- Slope = **0.20** — each km driven adds $0.20 to the bill
- y-intercept = **$50** — the daily charge before driving any km
- **Partial variation** — there's a fixed daily fee (b=50≠0)
