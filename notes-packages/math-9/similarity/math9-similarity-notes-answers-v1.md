## Section 1 — Ratio, Rate, and Proportion Review

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Ratio | Comparison of two quantities with the same units | 3:4 or 3/4 |
| Rate | Comparison of two quantities with different units | 100 km/h or $5/kg |
| Proportion | Statement that two ratios are equal | 3/4 = 6/8 |
| Cross-multiply | Multiply across the equals sign to eliminate fractions | a/b=c/d → ad=bc |
| Scale factor | Ratio comparing scaled (image) length to original length | SF = image/original |

### Guided Notes

| Blank | Answer |
|---|---|
| Ratio: same units | **same** |
| Rate: ___ units | **different** |
| Proportion: two ___ are equal | **ratios** |
| a×___ = b×___ | **d; c** |

**WE — x/6 = 4/9:**

> 9x = 24 → x = **8/3** (≈ 2.67)

Cross-multiply works by multiplying both sides by the LCD (6×9=54), then simplifying — it's a shortcut for that multi-step process.

**Scale factor:**

| Blank | Answer |
|---|---|
| SF = ___ / ___ length | **image / original** |
| SF > 1 → ___ | **enlargement (larger)** |
| SF < 1 → ___ | **reduction (smaller)** |
| SF = 1 → ___ | **congruent (same size)** |

**WE — Scale factor check:**

> 10/4 = **2.5** ✓ and 15/6 = **2.5** ✓
> Both ratios must agree to confirm the shape is uniformly scaled.

| Blank | Answer |
|---|---|
| Recipe: 3/24=x/60 → x | **7.5 cups** |
| Map Banff (1:50000): 6.4 cm → | 6.4×50000=320,000 cm = **3.2 km** |

### Retrieval Check — Section 1

| Question | Answer |
|---|---|
| 1. x/5=12/15 | 15x=60 → **x=4** |
| 2. (x+2)/7=6/3 | (x+2)/7=2 → x+2=14 → **x=12** |

## Section 2 — Similar Polygons

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Similar polygons | Same shape, possibly different size; equal angles AND proportional sides | Rectangles 2×4 and 4×8 |
| Corresponding sides | Sides that occupy the same position in two similar polygons | AB↔DE in △ABC~△DEF |
| Corresponding angles | Angles in the same position in two similar polygons | Angle A↔Angle D |
| Congruent | Identical in shape AND size (scale factor = 1) | Two squares both with side 5 cm |

### Guided Notes

| Blank | Answer |
|---|---|
| Similar: angles are ___ | **equal** |
| Similar: sides are ___ (in proportion) | **proportional** |
| Two rectangles 2×4 and 4×8: similar? Congruent? | **Similar** (ratio 2). **Not congruent** (different sizes). |

**Similarity statement correspondence:**
- A↔E → angle A = angle **E**
- AB↔EF → AB/EF = **BC/FG** etc.

**WE — △ABC~△DEF, AB=6, BC=9, DE=4:**

| Blank | Answer |
|---|---|
| Scale factor = DE/AB | = **4/6 = 2/3** |
| EF = BC × (2/3) | = 9 × 2/3 = **6** |

Scale factor is DE/AB (image over original) because DEF is the result of applying the factor to ABC.

**Checking PQRS~WXYZ:**

| Blank | Answer |
|---|---|
| Angles: P=W? Q=X? R=Y? S=Z? | **Yes, Yes, Yes, Yes** (all given equal) |
| WX/PQ=8/4 | **2** |
| XY/QR=12/6 | **2** |
| YZ/RS=10/5 | **2** |
| ZW/SP=6/3 | **2** |
| All ratios equal? Similar? | **Yes. Yes — similar ✓** |

| Blank | Answer |
|---|---|
| Perimeter ratio = scale factor | **k** |
| PQRS perimeter | **18** |
| WXYZ perimeter | **36** |
| Ratio | **36/18 = 2 = scale factor ✓** |

### Retrieval Check — Section 2

| Question | Answer |
|---|---|
| 1. Equal angles → similar? Congruent? | **Similar: yes** (AA). **Congruent: not necessarily** — same angles doesn't guarantee same size. |
| 2. Rectangles 3×8 and 9×24 | 9/3=3, 24/8=3. Equal → **similar**. Scale factor = **3**. |
| 3. △ABC~△DEF, AB=5, DE=10 | SF=10/5=2. EF=8×2=**16**. DF=6×2=**12**. |
| 4. Two conditions for similarity | (1) All corresponding **angles are equal**, AND (2) all corresponding **sides are proportional**. |
| 5. (Stretch) Area scale factor | Areas scale by **k²**. Rectangles 3×8=24 and 9×24=216. 216/24=9=3²=k². ✓ |

## Section 3 — Criteria for Similar Triangles

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| AA | Two angles of one triangle equal two angles of another → similar | Angle P=Angle X and Angle Q=Angle Y |
| SSS | All three pairs of corresponding sides proportional → similar | a/d=b/e=c/f |
| SAS | Two sides proportional AND the included angle equal → similar | AB/DE=BC/EF and angle B=angle E |
| Included angle | Angle between two given sides | Angle B is between AB and BC |

### Guided Notes

| Blank | Answer |
|---|---|
| Third angle = 180° − ___ − ___ | **first angle − second angle** |
| If A=D and B=E, then angle ___ = angle ___ automatically | **C = F** |
| △ABC ~ triangle ___ | **DEF** |

**WE (AA) — △PQR (P=55°, Q=75°) and △XYZ (X=55°, Z=50°):**

| Blank | Answer |
|---|---|
| Angle R = 180−55−75 | **50°** |
| Angle Y = 180−55−50 | **75°** |
| Angle P=X=55° ✓ Angle R=Z=50° ✓ | **AA criterion met** |
| △PQR ~ △ ___ | **XYZ** |

**WE (SSS) — △ABC (6,9,12) and △DEF (4,6,8):**

| Blank | Answer |
|---|---|
| d/a=4/6 | **2/3** |
| e/b=6/9 | **2/3** |
| f/c=8/12 | **2/3** |
| All equal? Similar by ___ | **Yes. SSS** |

**Parallel lines → similar triangles:** △ADE ~ **△ABC** (by AA — shared angle A + equal corresponding angles from DE∥BC)

**Criterion table:**

| Given | Criterion |
|---|---|
| Two angles equal | **AA** |
| All three sides proportional | **SSS** |
| Two sides proportional, angle NOT between them | **Neither (SSA is insufficient)** |
| One side proportional, two angles equal | **AA** (sides confirm scale, angles confirm similarity) |

### Retrieval Check — Section 3

| Question | Answer |
|---|---|
| 1. AA criterion | If two angles of one triangle equal two angles of another, the triangles are similar — the third angle is automatically determined (sum = 180°). |
| 2. AB=4,BC=6,angle B=50°; DE=8,EF=12,angle E=50° | DE/AB=8/4=2, EF/BC=12/6=2. Included angle B=E=50°. **SAS similarity. △ABC~△DEF.** |
| 3. One pair of angles — sufficient? | **No** — one pair leaves two unknown angles; the triangles might have different shapes. Need at least AA (two pairs). |
| 4. △PQR~△STU, P=47°, Q=83° | S=47°, T=83°, U=180-47-83=**50°**. Angles U=R=50°. |
| 5. (Stretch) DE∥BC, AD=3, DB=5, DE=4 | AD/AB=3/(3+5)=3/8. DE/BC=3/8 → 4/BC=3/8 → **BC = 32/3 ≈ 10.67** |

## Section 4 — Scale Diagrams and Indirect Measurement

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Scale diagram | Drawing representing a real object at a reduced or enlarged size | Map, blueprint |
| Scale | Ratio of diagram measurement to real measurement | 1:50 000 |
| Indirect measurement | Finding a measurement that cannot be directly measured by using similar triangles | Shadow method for tree height |
| Shadow method | Using shadows and a measuring stick to find height via similar triangles | h/shadow₁ = stick/shadow₂ |

### Guided Notes

| Blank | Answer |
|---|---|
| Scale 1:5000 → 1 cm = ___ cm = ___ m in real life | **5000 cm = 50 m** |

**Map WE (1:25,000), road 3.2 cm:**

> Real = 3.2 × 25,000 = 80,000 cm = **0.8 km**

**Pool 50×25 m, scale 1:500:**

| Blank | Answer |
|---|---|
| Length: 50/500 = ___ m = ___ cm | **0.1 m = 10 cm** |
| Width: 25/500 = ___ m = ___ cm | **0.05 m = 5 cm** |

**Shadow WE — h/7.2 = 1.5/0.9:**

> h = 7.2 × (1.5/0.9) = 7.2 × **5/3** = **12 m**

Must measure both shadows at same time: sun angle changes throughout the day → different proportions → triangles no longer similar.

**Mirror method — h/60 = 1.6/10:**

> h = 60 × 0.16 = **9.6 m**

### Retrieval Check — Section 4

| Question | Answer |
|---|---|
| 1. Scale 1:200, diagram wall 40 cm | 40 × 200 = 8000 cm = **80 m** |
| 2. Model car 1:20, real = 4.6 m | 4.6 m = 460 cm. Model = 460/20 = **23 cm** |
| 3. Tree shadow 12 m, pole 2 m casts 1.5 m shadow | h/12=2/1.5=4/3 → **h = 16 m** |
| 4. Why similar? Which criterion? | Same sun angle at same time of day → same angle in both right triangles → **AA** similarity. |
| 5. (Stretch) 15.6 km on 1:50,000 map | 15.6 km = 1,560,000 cm. Map = 1,560,000/50,000 = **31.2 cm** |

## Unit Synthesis

### Part A

| Question | Answer |
|---|---|
| 1. Two conditions for similar polygons | Equal corresponding **angles** AND proportional corresponding **sides** |
| 2. Three criteria for similar triangles | **AA** (two angles equal), **SSS** (all sides proportional), **SAS** (two sides proportional + included angle equal). AA requires least information. |
| 3. Scale factor 3 — perimeter ratio? Area ratio? | Perimeter ratio = **3**. Area ratio = **9 (= 3²)**. |
| 4. Map 1:100,000, 4 cm → ? km | 4 × 100,000 = 400,000 cm = **4 km** |

### Part B — △ABC~△DEF, AB=10, BC=15, DE=6

Scale factor = DE/AB = 6/10 = **3/5**

| Find | Work |
|---|---|
| EF | 15 × 3/5 = **9** |
| Angle B | 180−40−65 = **75°** |
| Angle E (=B) | **75°** |
| Angle F (=C) | **65°** |
| Angle D (=A) | **40°** |

### Part C — Pre-Knowledge Check

- Similar ≠ congruent. Similar = same shape, possibly different size. Congruent = same shape AND same size.
- Equal in similar triangles: **all three angles** (corresponding angles). Proportional: **all three sides** (same scale factor).
