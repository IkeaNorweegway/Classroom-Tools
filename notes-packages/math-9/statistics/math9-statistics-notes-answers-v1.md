## Section 1 — Types of Data and Graphs

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Univariate data | Data on one variable per subject | Heights of all students in a class |
| Bivariate data | Two variables measured on the same subject | Height AND weight of each student |
| Scatter plot | Graph showing bivariate data as individual points on an x-y plane | Temperature vs. visitors |
| Variable | A measurable characteristic that can change | Temperature, test score |
| Data point | One subject's measurements on both variables; a single dot on the scatter plot | (25°C, 130 visitors) |

### Guided Notes

| Blank | Answer |
|---|---|
| Univariate: data about ___ variable | **one** |
| Line graph: ___ over time | **trends** |
| Bivariate: data about ___ variables | **two** |
| Best graph for bivariate | **scatter plot** |
| Scatter plot shows if there is a ___ between two variables | **relationship/correlation** |
| Does knowing one variable help ___ the other? | **predict** |
| Each dot = ___ data point | **one** |
| Independent variable on ___ axis | **x** |
| Dependent variable on ___ axis | **y** |

**Splash pad pattern (temperature vs. visitors):** As temperature increases, visitors increase — positive trend.

### Retrieval Check — Section 1

| Question | Answer |
|---|---|
| 1. Univariate vs. bivariate | Univariate: one trait per subject (e.g., test scores). Bivariate: two traits on same subject (e.g., study time AND test score). |
| 2. When to use scatter plot | When you want to see if/how two variables are related — whether knowing one helps predict the other. |
| 3. Each dot represents | One subject's simultaneous measurements on both variables. |
| 4. Why independent on x-axis | The independent variable is the input — it "drives" the dependent. Convention places the input horizontally. |
| 5. (Stretch) Absences vs. marks | Absences on **x-axis** (independent — controlled by student). Final mark on **y-axis** (depends on absences). |

## Section 2 — Correlation and Scatter Plots

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Correlation | A relationship between two variables — how they tend to change together | Temperature and ice cream sales |
| Positive correlation | Both variables increase together | Height and weight |
| Negative correlation | One increases as the other decreases | TV hours and test scores |
| No correlation | No pattern — variables are unrelated | Shoe size and spelling scores |
| Strong correlation | Points cluster tightly near a line | Clear, consistent trend |
| Weak correlation | Points loosely suggest a direction | Difficult to predict one from other |

### Guided Notes

| Blank | Answer |
|---|---|
| Correlation: whether two variables change ___ | **together** |

**Outlier:** falls **far** away from the general pattern. An outlier can pull the trend line toward it, making the correlation appear weaker or change its direction slightly. Always note outliers — do not automatically remove them.

**Misconception:** Correlation ≠ causation. A third variable (confounder) can drive both observed variables. Strong correlation is necessary but NOT sufficient for causation.

**Splash pad:** **Strong positive** correlation between temperature and visitors.

### Retrieval Check — Section 2

| Question | Answer |
|---|---|
| 1. Positive vs. negative correlation | Positive: both variables increase together. Negative: one increases as the other decreases — inverse relationship. |
| 2. More sleep → less reaction time | **Negative correlation** |
| 3. Strong vs. weak appearance | Strong: points cluster tightly along a clear line. Weak: points spread widely, trend is hard to see. |
| 4. Correlation ≠ causation | A third variable (confounder) may drive both. E.g., hot weather → both ice cream sales AND outdoor activity/drowning — not ice cream causing drowning. |
| 5. (Stretch) Fire stations and fires | Both driven by **city size**: larger cities have both more fire stations AND more fires. Stations don't cause fires. |

## Section 3 — Line of Best Fit

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Line of best fit | Straight line best representing the trend in a scatter plot | y = 10t − 115 for splash pad data |
| By inspection | Drawing based on visual judgment — equal points above and below | Human placement of trend line |
| Trend line | Another name for line of best fit | The same line |
| Equation of line of best fit | y = mx + b derived from two points ON the line | v = 10t − 115 |

### Guided Notes

| Blank | Answer |
|---|---|
| Line best represents the ___ of points | **trend/overall pattern** |
| Used for ___ or ___ correlation | **positive; negative** |
| Rules: passes ___ the middle | **through** |
| Equal numbers above and ___ | **below** |
| Follows general ___ | **direction/trend** |
| Does NOT need to pass through the ___ | **origin** |

**Why choose points ON the line (not data points):** Data points have measurement error. The line is a smoothed model of the trend — points on the line give the "theoretical" relationship, not noise-affected observations.

**Verbal description:** "For each 1°C increase in temperature, approximately **10** more visitors are expected."

### Retrieval Check — Section 3

| Question | Answer |
|---|---|
| 1. Four rules for line of best fit | (1) Through the middle. (2) Equal points above and below. (3) Follows general direction. (4) No requirement to pass through origin or any data point. |
| 2. Student A vs. B (origin vs. balanced) | **Student B** is more likely correct. Requiring the line to pass through the origin is an unwarranted constraint not justified by the data. |
| 3. Predict at 29°C | Using v≈10t−115: v=10(29)−115=**175 visitors** *(varies by student's line)* |
| 4. Slope meaning | For each 1°C increase in temperature, approximately 10 more visitors are expected — it is the rate of change. |
| 5. (Stretch) y=−3x+95 | **Negative correlation** (slope is negative). Slope means: for each unit increase in x, y decreases by 3. |

## Section 4 — Interpolation and Extrapolation

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Interpolation | Predicting y for an x-value WITHIN the observed data range | Predicting at 26°C when data spans 20–34°C |
| Extrapolation | Predicting y for an x-value OUTSIDE the observed data range | Predicting at 40°C when data only goes to 34°C |
| Reliability | How trustworthy/accurate a prediction is likely to be | Interpolation is more reliable than extrapolation |
| Domain of the data | The range of x-values actually observed | 20°C to 34°C |

### Guided Notes

| Blank | Answer |
|---|---|
| Interpolation: x is ___ the range | **inside/within** |
| Extrapolation: x is ___ the range | **outside** |

**Prediction table (data range 20–34°C):**

| x-value | Inside/Outside | Type | Reliability |
|---|---|---|---|
| 26°C | Inside | **Interpolation** | **Reliable** |
| 22°C | Inside | **Interpolation** | **Reliable** |
| 40°C | Outside | **Extrapolation** | **Less reliable** |
| 18°C | Outside | **Extrapolation** | **Less reliable** |

**Alberta canola context (range 0–200 kg/ha):**

| Question | Answer |
|---|---|
| 150 kg/ha: 0.015(150)+1.2 | **3.45 t/ha** — **interpolation** (inside range) |
| 400 kg/ha: 0.015(400)+1.2 | **7.2 t/ha** — **extrapolation** (outside range) |
| Why unreliable? | Too much fertilizer can damage soil, cause runoff, or reduce yield — the linear trend breaks down at excessive amounts. |

### Retrieval Check — Section 4

| Question | Answer |
|---|---|
| 1. Define each | Interpolation: predicting within observed x-range. Extrapolation: predicting outside observed x-range. |
| 2. Data range 5–30 | Interpolation: 5≤x≤30. Extrapolation: x<5 or x>30. |
| 3. y=4x-10 at x=20 | y=70. **Interpolation** (20 is within 5–30). |
| 4. Why extrapolation unreliable | The relationship may change outside the observed range — additional factors that weren't observed may come into play. |
| 5. (Stretch) Species in 2100 | 95 years beyond 2005 — the model predicts negative species before 2100 (impossible). Linear decline hits 0 before then. The model breaks down because populations can't go below 0 and other dynamics occur. |

### Part B — Study time vs. score

> (a) Strong positive correlation expected.
> (b) Graph: points rise clearly from (1,52) to (6,90).
> (c) Approximate: m≈(90−52)/(6−1)=7.6. b≈44. Equation: **y ≈ 7.6x + 44**
> (d) x=4.5: y=7.6(4.5)+44≈**78%** — **interpolation** (inside 1–6 range).
> (e) x=10: y=7.6(10)+44=**120%** — **extrapolation**, not reliable. Score cannot exceed 100%; the linear model breaks down beyond 100%.
