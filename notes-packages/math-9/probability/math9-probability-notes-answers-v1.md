## Section 1 — Probability Fundamentals

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Outcome | A single possible result of an experiment | Rolling a 4 on a die |
| Sample space | The set of all possible outcomes | {1,2,3,4,5,6} for a die |
| Event | One or more outcomes you're interested in | Rolling an even number |
| Theoretical probability | Probability calculated from the structure; assumes equally likely outcomes | P(even) = 3/6 |
| Experimental probability | Probability calculated from actual trial results | 14 reds in 40 spins → 14/40 |
| Complementary events | Two events where one is "not the other"; together they cover all outcomes | Rain and no rain |
| Favourable outcomes | Outcomes that satisfy the event | For "even number on a die": {2,4,6} |

### Guided Notes

| Blank | Answer |
|---|---|
| Probability between ___ and ___ | **0 and 1** |
| 0 = ___ | **impossible** |
| 1 = ___ | **certain** |
| Theoretical: ___ outcomes / ___ outcomes | **favourable / total** |
| Experimental: times event ___ / total ___ | **occurred / trials** |

**Die worked example:**

| Expression | Answer |
|---|---|
| Sample space size | **6** |
| P(rolling a 4) | **1/6** |
| P(rolling even) — favourables | **3/6 = 1/2** {2,4,6} |
| P(rolling a 7) | **0/6 = 0** (impossible) |
| P(rolling less than 7) | **6/6 = 1** (certain) |

**Spinner experiment:** P(red)=14/40=**7/20**. P(blue)=16/40=**2/5**. Fair theoretical=1/3 each. Experimental results are close to 1/3 but not exact — random variation causes fluctuation in small samples.

| Blank | Answer |

| P(4,5,6) = 1−1/2 | **1/2** |
| 3/8 as decimal/percent | **0.375 / 37.5%** |

**Conversion table:**

| Question | Answer |

## Section 3 — Independent Events

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Independent events | Events where one outcome does not affect the probability of the other | Two coin flips; die + spinner |
| Multiplication rule (independent) | P(A and B) = P(A) × P(B) | P(H and 3) = 1/2 × 1/6 = 1/12 |
| P(A and B) | Probability that both A and B occur | P(both red) = 5/8 × 5/8 |

### Guided Notes

| Blank | Answer |
|---|---|
| Independent: outcome of one does NOT affect ___ of other | **probability** |
| P(H and 3) = (1/2)×(1/6) | = **1/12** |
| From sample space: 1 out of 12. Same? | **Yes ✓** |
| P(red and red) with replacement | = (5/8)×(5/8) = **25/64** |

Why draw 2 = draw 1: the marble was replaced, restoring the bag to its original composition. The condition that makes this true is **replacement** (or "with replacement").

**Gambler's Fallacy:** P(heads after 4 heads) = **1/2** (always). Each flip is independent.

**Independence table:**

| Scenario | Answer |
|---|---|
| Two separate coin flips | **Independent** |
| Draw card, keep it, draw again | **Dependent** |
| Draw card, replace it, draw again | **Independent** |
| Two students without replacement | **Dependent** |
| Rolling two dice | **Independent** |

### Retrieval Check — Section 3

| Question | Answer |
|---|---|
| 1. Die + spinner — independent? | **Yes** — rolling a die cannot affect spinning a spinner; they're physically separate events. |
| 2. P(A)=0.4, P(B)=0.3 — P(A and B) | 0.4 × 0.3 = **0.12** |
| 3. Bag 4G, 6Y. P(green both, with replacement) | (4/10) × (4/10) = **16/100 = 4/25** |
| 4. Gambler's Fallacy | Believing past independent outcomes affect future probability. Example: "I've lost 6 lottery draws, so I'm due to win." |
| 5. (Stretch) Three events P=1/3 each | P(all three) = (1/3)³ = **1/27**. P(at least one doesn't occur) = 1−1/27 = **26/27** |

## Section 4 — Dependent Events

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Dependent events | Events where the first outcome changes the probability of the second | Drawing cards without replacement |
| Conditional probability | Probability of B given A has occurred: P(B\|A) | P(Ace\|first was Ace) = 3/51 |
| Without replacement | Selected items not returned; pool shrinks | Drawing cards from a deck |
| P(B\|A) | Read "P of B given A" — probability of B assuming A occurred | P(blue 2nd \| red 1st) |

### Guided Notes

| Blank | Answer |
|---|---|
| Sample space for second event is ___ because one removed | **smaller** |
| Rule: P(A then B) = P(A) × ___ | **P(B\|A)** |

**WE1 — Two aces from 52-card deck:**

| Blank | Answer |
|---|---|
| P(Ace draw 1) = 4/52 | = **1/13** |
| After drawing ace: aces remain | **3** | cards remain | **51** |
| P(Ace draw 2 \| draw 1 ace) | **3/51** |
| P(both aces) = (4/52)×(3/51) | = **12/2652 = 1/221 ≈ 0.0045** |

Why 3/51: one ace was removed — only 3 of the remaining 51 cards are aces.

**WE2 — 5R, 3B, no replacement:**

| Blank | Answer |
|---|---|
| P(red first) | **5/8** |
| After 1 red: ___ red, ___ total | **4 red, 7 total** |
| P(blue \| red first) | **3/7** |
| P(red then blue) | (5/8)(3/7) = **15/56 ≈ 0.268** |

**Comparison table (same bag):**

| Scenario | P(red then blue) |
|---|---|
| WITH replacement | (5/8)(3/8) = **15/64** |
| WITHOUT replacement | (5/8)(3/7) = **15/56** |

Different because without replacement changes the **sample space** (denominator decreases).

**Misconception:** Yes, 4/7≈0.571 vs 5/8=0.625 — **difference is meaningful** for small populations.

**Three marbles (4R, 6B, 10 total) — P(R,R,B):**

| Step | Work |
|---|---|
| P(R₁) | **4/10** |
| After R₁: ___ red, ___ blue, ___ total | **3, 6, 9** |
| P(R₂\|R₁) | **3/9** |
| After R₂: ___ red, ___ blue, ___ total | **2, 6, 8** |
| P(B₃\|R₁R₂) | **6/8** |
| P(R,R,B) = (4/10)(3/9)(6/8) | = **72/720 = 1/10** |

### Retrieval Check — Section 4

| Question | Answer |
|---|---|
| 1. Class 12G, 8B — P(both girls, no replacement) | (12/20)×(11/19) = 132/380 = **33/95** |
| 2. Bag 6R, 4G — P(red then green, no replacement) | (6/10)×(4/9) = 24/90 = **4/15** |
| 3. Why "without replacement" creates dependence | Removing one item reduces the pool. The fraction of remaining items changes, so the probability for the second draw is different from the first. |
| 4. P(ace, ace) with vs. without replacement | With: (4/52)²=16/2704=**1/169**. Without: (4/52)(3/51)=12/2652=**1/221**. Without replacement gives lower probability. |
| 5. (Stretch) 3Y,4B,5G — P(Y,B,G) | (3/12)×(4/11)×(5/10)=60/1320=**1/22** |

## Unit Synthesis

### Part A

| Question | Answer |
|---|---|
| 1. Theoretical probability formula | P(event) = **number of favourable outcomes / total outcomes** |
| 2. Multiplication rules | Independent: **P(A and B) = P(A)×P(B)**. Dependent: **P(A then B) = P(A)×P(B\|A)** |
| 3. Gambler's Fallacy | Believing past independent events affect future probability. Example: "I've been dealt bad cards — I must be due for a good hand." |
| 4. Dependent vs. independent | Key question: does the first outcome change what's available for the second? Without replacement → dependent. With replacement or separate events → independent. |

### Part B — Bag 4R, 3B, 2G (9 total)

| Part | Work | Answer |
|---|---|---|
| (a) P(not red) | (3+2)/9 | **5/9** |
| (b) With replacement — P(R then B) | (4/9)×(3/9) | **12/81 = 4/27** |
| (c) Without replacement — P(R then B) | (4/9)×(3/8) | **12/72 = 1/6** |

(b) is independent — replacement restores composition. (c) is dependent — removal changes denominator.

### Part C — Pre-Knowledge Check

1. P(heads) = **1/2** — always, regardless of past flips. The Gambler's Fallacy.
2. Theoretical: from structure (equally likely). Experimental: from trials. They converge with large numbers of trials.
3. Yes, probability changes for the next draw — dependent events (without replacement). Concept: **conditional probability**.
