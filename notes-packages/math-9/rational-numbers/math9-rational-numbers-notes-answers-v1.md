## Section 1 — What Is a Rational Number?

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Rational number | Any number written as a/b where a, b are integers and b ≠ 0 | −3/4, 5, 0.25, 0.333... |
| Numerator | Top number; tells how many parts you have | In 3/4, the numerator is 3 |
| Denominator | Bottom number; tells the size/type of parts | In 3/4, the denominator is 4 |
| Equivalent fractions | Fractions that represent the same value | 1/2 = 2/4 = 3/6 |
| Opposite | Same distance from zero, opposite side of the number line | Opposite of 3/4 is −3/4 |
| Absolute value | Distance from zero; always non-negative | |−3/4| = 3/4 |

### Guided Notes

| Blank / Prompt | Answer |
|---|---|
| Written as ___/___; a, b are integers, b ___ 0 | a/b; b ≠ 0 |
| 5 = ___/1 | 5/1 |
| −3 = ___/1 | −3/1 |
| 0.75 = ___/100 | 75/100 |
| 0.333... = ___/3 | 1/3 |

**Comparing table:**

| Statement | True or False? | Reason |
|---|---|---|
| −1/2 > −3/4 | TRUE | −1/2 is closer to 0; on the number line, it sits to the right of −3/4 |
| −5/6 < −7/8 | FALSE | LCD = 24: −5/6 = −20/24, −7/8 = −21/24; −20/24 > −21/24, so −5/6 > −7/8 |
| 2/3 > 3/4 | FALSE | LCD = 12: 2/3 = 8/12, 3/4 = 9/12; 8 < 9, so 2/3 < 3/4 |

**Method — comparing −5/6 and −7/8:**

| Blank | Answer |
|---|---|
| Common denominator | 24 |
| −5/6 = −___/24 | −20/24 |
| −7/8 = −___/24 | −21/24 |
| Compare: −20/24 ___ −21/24 | > (−20 is closer to 0) |
| So −5/6 ___ −7/8 | > |
| Key insight: bigger in absolute value is actually ___ in value | smaller (more negative) |

**Ordering: 1/2, −3/4, −1/3, 0, 5/6, −1**

Least → greatest: **−1, −3/4, −1/3, 0, 1/2, 5/6**

### Retrieval Check — Section 1

| Question | Answer |
|---|---|
| 1. Is −8 rational? Explain. | Yes — it can be written as −8/1 (integer over non-zero integer satisfies the definition) |
| 2. Write −5/3 in two equivalent sign forms. | 5/(−3) and −(5/3) |
| 3. Which is greater: −2/3 or −3/4? | −2/3. LCD = 12: −2/3 = −8/12, −3/4 = −9/12. Since −8 > −9, −2/3 > −3/4. |
| 4. Order least to greatest: 0.5, −3/4, −1/2, 1/4 | −3/4, −1/2, 1/4, 0.5 |
| 5. (Stretch) Every integer rational? Every rational an integer? | Every integer IS rational (write n as n/1). NOT every rational is an integer (e.g., 1/2 has no integer form). |

## Section 2 — Adding and Subtracting Rational Numbers

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Common denominator | A shared denominator for two or more fractions | 6 is a common denominator for 1/2 and 1/3 |
| Least common denominator (LCD) | The smallest shared denominator | LCD of 1/4 and 1/6 is 12 |
| Mixed number | Whole part + fraction part | 2¾ |
| Improper fraction | Numerator ≥ denominator | 11/4 |

### Guided Notes

| Blank / Prompt | Answer |
|---|---|
| Must have the ___ denominator to add/subtract | same |
| Step 1 of adding fractions | Find the LCD |
| Step 3 of adding fractions | Add/subtract the numerators |

**Worked Example 1 — 3/4 + 5/6:**

| Blank | Answer |
|---|---|
| LCD of 4 and 6 | 12 |
| 3/4 = ___/12 | 9/12 |
| 5/6 = ___/12 | 10/12 |
| ___/12 + ___/12 | 9/12 + 10/12 = 19/12 |
| Simplified | 1 7/12 |

**Explain Step 2:** Multiplying numerator and denominator by the same number is multiplying by 1 (e.g., 3/3 = 1) — it changes the form but not the value.

**Worked Example 2 — −1/3 + (−3/4):**

| Blank | Answer |
|---|---|
| LCD | 12 |
| −1/3 = −___/12 | −4/12 |
| −3/4 = −___/12 | −9/12 |
| −___/12 + (−___/12) | −4/12 + (−9/12) = −13/12 |
| Simplified | −1 1/12 |
| Pattern | Adding two negative rationals always gives a **negative** result |

**Worked Example 3 — −5/6 + 1/2:**

| Blank | Answer |
|---|---|
| LCD | 6 |
| 1/2 = ___/6 | 3/6 |
| −5/6 + ___/6 | −5/6 + 3/6 = −2/6 = **−1/3** |

**Subtraction: 5/8 − (−3/8)**

= 5/8 + **3/8** = **8/8 = 1**

**Alberta context — Fort McMurray temperature:**
Temperature = −7.5 + **11.25** = **3.75°C**

## Section 3 — Multiplying Rational Numbers

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Product | Result of multiplication | (−2/3) × (3/4) = −1/2 |
| Simplify before multiplying (cross-cancel) | Divide a numerator and a different fraction's denominator by their GCF before multiplying | (4/9) × (3/8): cancel 4↔8 and 3↔9 → (1/3) × (1/2) = 1/6 |
| Reciprocal | Flip numerator and denominator | Reciprocal of 3/4 is 4/3 |

### Guided Notes

| Blank / Prompt | Answer |
|---|---|
| Multiply ___ × ___ and ___ × ___ | numerators × numerators; denominators × denominators |
| (a/b) × (c/d) = ___/___ | ac/bd |

**Sign rules:**

| Signs | Product |
|---|---|
| Positive × Positive | Positive |
| Negative × Negative | **Positive** |
| Positive × Negative | Negative |
| Negative × Positive | Negative |
| Quick rule: ___ number of negatives → negative | **odd** |

**Worked Example 1 — (−3/5) × (2/7):**

| Blank | Answer |
|---|---|
| Numerators: ___ × ___ | −3 × 2 = −6 |
| Denominators: ___ × ___ | 5 × 7 = 35 |
| Sign | negative × positive = **negative** |
| Result | **−6/35** |

**Cross-cancellation — (8/15) × (5/4):**

| Blank | Answer |
|---|---|
| 8 and 4 share factor ___ | 4 → 8/4 = 2 |
| 5 and 15 share factor ___ | 5 → 5/15 = 1/3 |
| Now multiply | (2/3) × (1/1) = **2/3** |
| Can you cancel 8 and 4? | Yes — 8 is numerator of first fraction, 4 is denominator of second (across the ×) |

**Worked Example 2 — (−3/4) × 8:**

| Blank | Answer |
|---|---|
| Rewrite 8 as ___/1 | 8/1 |
| (−3/4) × (8/1) = −___/4 | −24/4 |
| Simplified | **−6** |

**Alberta context — pipeline:** (−5/6) × (3/4) = −15/24 = **−5/8**

### Retrieval Check — Section 3

| Question | Answer |
|---|---|
| 1. (−2/3) × (−3/4) | Neg × Neg = Pos. 6/12 = **1/2** |
| 2. (5/6) × (−9/10), cross-cancel | Cancel 5↔10 (÷5) and 3↔6 (÷3): (1/2) × (−3/2) = **−3/4** |
| 3. (−3) × (−2/5) | Neg × Neg = Pos. 6/5 = **1 1/5** |
| 4. Student gets −8/15 for (−2/3)×(−4/5). Error? | Ignored sign rule: neg × neg = positive. Correct answer is **+8/15** |
| 5. (Stretch) (−3/4)³ | (−3/4)² = 9/16 (pos). × (−3/4) = **−27/64** |

## Section 4 — Dividing Rational Numbers

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Reciprocal | Flip the fraction | Reciprocal of 3/4 is 4/3 |
| Quotient | Result of division | 6 ÷ 2 = 3 |
| Divisor | The number you divide by | In 6 ÷ 3, divisor is 3 |

### Guided Notes

| Blank / Prompt | Answer |
|---|---|
| Dividing is the same as ___ by the reciprocal | multiplying |
| a ÷ (b/c) = a × ___/___ | c/b |
| Reciprocal of a/b is ___/___ | b/a |

**Reciprocal table:**

| Fraction | Reciprocal |
|---|---|
| 3/4 | 4/3 |
| −5/2 | −2/5 |
| 7 (= 7/1) | 1/7 |
| −1/3 | −3 (= −3/1) |

**Misconception check:** 6 ÷ (1/3) = **18** (bigger — 18 thirds fit in 6 wholes)

**Worked Example 1 — (−3/4) ÷ (2/5):**

| Blank | Answer |
|---|---|
| Rewrite as ×: (−3/4) × (___) | (5/2) |
| Result | −15/8 |

**Worked Example 2 — 2½ ÷ (−3/4):**

| Blank | Answer |
|---|---|
| Convert: 2½ = ___/2 | 5/2 |
| Rewrite: (5/2) × (−___/3) | (−4/3) |
| Sign | positive × negative = **negative** |
| Result | −20/6 = **−10/3** |

**Why the rule works:**
n = (2/3) × (5/4) = 10/12 = **5/6**

**Alberta context:** (2/3) ÷ 3 = (2/3) × (1/3) = **2/9**. Each family receives **2/9** of the total.

### Retrieval Check — Section 4

| Question | Answer |
|---|---|
| 1. Reciprocal of −4/7 | **−7/4** |
| 2. (3/4) ÷ (−9/8) | (3/4) × (−8/9) = −24/36 = **−2/3** |
| 3. (−5/6) ÷ (−5/3) | (−5/6) × (−3/5) = 15/30 = **1/2** |
| 4. Why dividing by 1/3 = multiplying by 3? | 1/3 is smaller than 1; you're asking "how many thirds fit?" — the count is 3 times larger, same as ×3. (a ÷ (1/3) = a × 3/1) |
| 5. (Stretch) 5¼ ÷ ¾ | 5¼ = 21/4. (21/4) ÷ (3/4) = (21/4) × (4/3) = 84/12 = **7 complete batches**, no remainder |

## Section 5 — Order of Operations with Rational Numbers

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| BEDMAS | Brackets, Exponents, Division/Multiplication (L→R), Addition/Subtraction (L→R) | 2 + 3 × 4 = 14, not 20 |
| Evaluate | Find the numerical value of an expression | Evaluate 3 + 2 × 4 = 11 |
| Nested brackets | Brackets within brackets; work innermost out | (2 + (3 × 4)) = (2 + 12) = 14 |

### Guided Notes

| Blank / Prompt | Answer |
|---|---|
| (−2/3)² = ___ | **4/9** — even power, always positive |

**Worked Example — (−1/2 + 3/4)² ÷ (−1/4):**

| Step | Answer |
|---|---|
| B: −1/2 + 3/4 | −2/4 + 3/4 = **1/4** |
| E: (1/4)² | **1/16** |
| D: (1/16) ÷ (−1/4) = (1/16) × (−4) | **−4/16 = −1/4** |

**Explain B step:** The bracket creates a new quantity that becomes the base of the exponent. Squaring before adding would square each fraction separately — a different calculation entirely.

**Common sequence error — 1/2 + 3/4 × (−2/3):**

| Blank | Answer |
|---|---|
| Wrong (adds first): (5/4) × (−2/3) | = −10/12 = **−5/6** |
| Correct (× first): 3/4 × (−2/3) | = −6/12 = −1/2 |
| Then: 1/2 + (−1/2) | = **0** |

**Sign traps:**

| Expression | Answer |
|---|---|
| −(3/4)² | −(9/16) = **−9/16** — exponent applies to 3/4 only, then negated |
| (−3/4)² | **(−3/4) × (−3/4) = 9/16** — negative base, even power → positive |

**Interleaved practice:**

| Expression | First step | Answer |
|---|---|---|
| 3/4 × (−2/3) + 1/2 | Multiplication | −1/2 + 1/2 = **0** |
| (1/3 + 1/6) ÷ (−1/2) | Bracket | B: 1/3+1/6 = 1/2; D: (1/2) ÷ (−1/2) = **−1** |
| −(−2/3)² | Exponent | (−2/3)² = 4/9; then **−4/9** |
| 1/2 ÷ 1/4 − 3/2 | Division | 1/2 ÷ 1/4 = 2; then 2 − 3/2 = **1/2** |

### Retrieval Check — Section 5

| Question | Answer |
|---|---|
| 1. (−3/4 + 1/2) × (−8/3) | B: −3/4+2/4 = −1/4. Then (−1/4)×(−8/3) = 8/12 = **2/3** |
| 2. 2/3 ÷ (1/3)² | E: (1/3)²=1/9. D: (2/3)÷(1/9) = (2/3)×9 = **6** |
| 3. (−1/2)³ + 3/4 × (−2/3) | E: −1/8. M: 3/4×(−2/3) = −1/2. A: −1/8+(−4/8) = **−5/8** |
| 4. Error in 1/2 + 3/4 × (−2), gets −5/4 | Added first (broke BEDMAS). Correct: M first: 3/4×(−2) = −3/2. A: 1/2+(−3/2) = **−1** |
| 5. (Stretch) (1/3−2/3)²÷(−1/9)+(−1/2)² | B: −1/3. E: 1/9 and 1/4. D: (1/9)÷(−1/9) = −1. A: −1+1/4 = **−3/4** |

## Unit Synthesis

### Part A — Key ideas

| Question | Model answer |
|---|---|
| 1. What makes a number rational? Two non-obvious examples. | Any number expressible as a/b (integers, b ≠ 0). E.g., √4 = 2 = 2/1 is rational; 0.666... = 2/3 is rational. |
| 2. Common denominator for addition but not multiplication? | Addition: denominators name the *size of pieces* — you can't add different-sized pieces. Multiplication: you multiply the pieces themselves; the size relationship doesn't need to match. |
| 3. Why does dividing by a fraction < 1 give a larger result? | You're asking "how many of this small piece fit?" Since the piece is smaller than 1, more fit — the count exceeds what you started with. |
| 4. Sign rule for neg × neg | **Negative × negative = positive** (even count of negatives → positive product) |
