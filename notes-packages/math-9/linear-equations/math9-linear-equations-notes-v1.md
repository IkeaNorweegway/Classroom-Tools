>

### Guided Notes

**When an equation has fraction coefficients, the most efficient first step is to eliminate all fractions by multiplying every term by the LCD.**

---

**Worked Example 1 — Fraction coefficients:**

x/3 + 1/2 = 5/6

> LCD of 3, 2, 6 = ___
>
> Multiply every term by ___:
> 6(x/3) + 6(1/2) = 6(5/6)
>
> ___x + ___ = ___
>
> Solve: x = ___
>
> **Verify:** ___/3 + 1/2 = ___ + ___ = ___ ✓

**Explain the first step:** Why does multiplying every term by the LCD eliminate the fractions? Use the first term (x/3) as an example.

_______________________________________________
_______________________________________________

---

**Worked Example 2 — Mixed fractions and whole numbers:**

(2/3)x − 4 = x/4

> LCD of 3 and 4 = ___
>
> Multiply all terms by 12:
> 12(2/3)x − 12(4) = 12(x/4)
>
> ___x − ___ = ___x
>
> Move variable terms: ___x = ___
>
> x = ___

---

**Worked Example 3 — Decimal coefficients:**

0.3x + 1.2 = 0.9

> Option 1 — multiply by 10 to clear decimals:
> 3x + 12 = 9
>
> Solve: x = ___
>
> Option 2 — work with decimals directly:
> 0.3x = 0.9 − 1.2 = ___
>
> x = ___ / 0.3 = ___

Both options give the same answer. Option 1 is usually less prone to rounding errors.

---

> **MISCONCEPTION: You only multiply SOME terms by the LCD**
>
> Wrong idea: In x/3 + 1/2 = 5/6, a student multiplies only the fraction terms by 6, missing any whole number terms.
>
> Why it fails: Every term on both sides must be multiplied by the same number. The LCD clears ALL denominators simultaneously. If you miss a term, you have changed the equation's balance.
>
> Rule: If you multiply any term by the LCD, you must multiply EVERY term on BOTH sides.

---

**Practise:**

1. x/2 − x/3 = 1/6

2. (3/4)x + 2 = (1/2)x + 5

3. 0.5x − 3 = 0.2x + 0.6

## Section 4 — Solving and Graphing Linear Inequalities

**Learning target:** I can solve a one-variable linear inequality, apply the sign-flip rule correctly, and represent the solution on a number line.

### Vocabulary

| Term | Definition in your own words | One example |
|---|---|---|
| Inequality | | |
| Solution set | | |
| Open circle | | |
| Closed circle | | |
| Flip the sign | | |

### Guided Notes

**An inequality states that two expressions are NOT equal.** The solution is a range of values, not a single value.

| Symbol | Meaning | Number line endpoint |
|---|---|---|
| > | greater than | open circle |
| < | less than | open circle |
| ≥ | greater than or equal to | closed circle |
| ≤ | less than or equal to | closed circle |

---

**Solving works the same as equations — EXCEPT one critical rule:**

> **When you multiply or divide both sides by a NEGATIVE number, you must flip the inequality sign.**

---

**Worked Example 1 — No sign flip:**

2x + 3 > 7

> 2x > 7 − 3
>
> 2x > ___
>
> x > ___ (divide by positive 2 — NO flip)

**Graph on a number line** (open circle at ___, arrow pointing ___):

```
◄──────────────────────────────────►
          0   1   2   3   4   5
```

**Verify:** Pick a value in the solution (e.g., x = 3): 2(3) + 3 = ___ > 7? ___
Pick a value NOT in the solution (e.g., x = 1): 2(1) + 3 = ___ > 7? ___

---

**Worked Example 2 — Sign flip required:**

−3x + 6 ≤ 15

> −3x ≤ 15 − 6
>
> −3x ≤ ___
>
> Divide by −3 — FLIP: x ___ (≥ or ≤?) ___

**Graph** (closed circle at ___, arrow pointing ___):

```
◄──────────────────────────────────►
    -5  -4  -3  -2  -1   0   1
```

---

> **MISCONCEPTION: Always flip the inequality sign when solving**
>
> Wrong idea: "Inequalities are different from equations, so the sign always flips somewhere."
>
> Why it fails: You only flip when you multiply or divide by a *negative* number. Multiplying by a positive number — or adding/subtracting anything — does NOT cause a flip. The sign flips specifically because multiplying by a negative reverses the order of all numbers: if 3 > 1, then −3 < −1.
>
> Test: If 6 > 2 and we divide by −2: −3 ___ −1. Did the direction change? ___

---

**The sign-flip reason — visualized:**

On a number line: 3 > 1

Multiply both by −1: −3 ___ −1 (circle the correct symbol: < >)

The positions swap sides relative to zero. That is why the symbol flips.

---

> **MISCONCEPTION: Flipping the sign when dividing by a positive**
>
> Wrong idea: "Any time I solve an inequality, the sign flips."
>
> Why it fails: Only negative multipliers/divisors flip the sign. 2x > 8 gives x > 4 (divide by +2, no flip). Test: if 2(5) = 10 > 8, is 5 > 4? Yes. The direction held.

---

**Practise:**

1. 4x − 1 < 11

2. −2x + 5 ≥ 1

3. 3(x − 2) ≤ 2x + 1

**Graph each on a number line.**

## Section 5 — Problem Solving with Equations

**Learning target:** I can translate a word problem into a linear equation or inequality, solve it, and interpret the answer in context.

### Vocabulary

| Term | Definition in your own words | One example |
|---|---|---|
| Define the variable | | |
| Translate | | |
| Interpret | | |
| Reasonable answer | | |

### Guided Notes

**The four-step problem-solving sequence:**

1. **Define:** Let x = _______ (specify what x represents and its units)
2. **Translate:** Write the equation or inequality from the words
3. **Solve:** Apply the algebraic steps
4. **Interpret:** Write a sentence answering the original question, using units

---

**Common translation patterns:**

| Words | Math |
|---|---|
| "is," "equals," "the same as" | = |
| "more than," "increased by" | + |
| "less than," "decreased by" | − |
| "times as much," "of" | × |
| "is at least," "no less than" | ≥ |
| "is at most," "no more than" | ≤ |
| "exceeds," "more than" | > |

---

**Worked Example — Write, solve, interpret:**

"A plumber charges a $75 call-out fee plus $50 per hour. A homeowner can spend at most $350. How many full hours of work can they have done?"

> **Define:** Let h = number of hours of work
>
> **Translate:** 75 + 50h ___ 350
>
> **Solve:**
> 50h ≤ 350 − 75
> 50h ≤ ___
> h ≤ ___
>
> **Interpret:** The homeowner can have at most ___ hours of work done.
>
> **Check reasonableness:** 75 + 50(5) = ___ ≤ 350 ✓

**Explain:** Why do we write the inequality ≤ rather than <? What does "at most" mean?

_______________________________________________

---

**Worked Example 2 — Consecutive integers:**

"Three consecutive even integers sum to 48. Find them."

> **Define:** Let n = the first even integer.
> Then the next two are ___ and ___.
>
> **Translate:** n + ___ + ___ = 48
>
> **Solve:** 3n + ___ = 48 → 3n = ___ → n = ___
>
> **Interpret:** The three integers are ___, ___, ___.
>
> **Verify:** ___ + ___ + ___ = ___  ✓

---

**Alberta context — Break-even:**

A Lethbridge student council is selling hot chocolate for $2.50 per cup. They spent $75 on supplies. How many cups must they sell to make a profit?

> Define: Let c = number of cups sold
>
> Revenue: ___c
> Profit = Revenue − Cost > 0
>
> ___c − 75 > 0
>
> Solve: c > ___
>
> Interpret: They must sell more than ___ cups to make a profit.
