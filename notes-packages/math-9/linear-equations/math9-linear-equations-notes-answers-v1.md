## Section 1 — Review: One- and Two-Step Equations

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Equation | A mathematical statement that two expressions are equal | 2x + 3 = 11 |
| Solution | The value of the variable that makes the equation true | x = 4 for 2x+3=11 |
| Inverse operation | An operation that undoes another | Subtraction undoes addition |
| Balance model | The principle that both sides of an equation must be treated equally | Adding 5 to both sides maintains balance |
| Verify (check) | Substituting the solution back into the original equation to confirm it works | 2(4)+3=11 ✓ |

### Guided Notes

| Blank | Answer |
|---|---|
| Two expressions are ___ | **equal** |
| Solving = finding the value that makes equation ___ | **true** |
| Same operation on both sides — whatever you do to one ___ | **the other** |

**Inverse operations:**

| Operation | Inverse |
|---|---|
| Addition | **Subtraction** |
| Subtraction | **Addition** |
| Multiplication | **Division** |
| Division | **Multiplication** |

**Worked Example 1 — x + 7 = −3:**

| Blank | Answer |
|---|---|
| Inverse of +7 is ___ 7 | **subtract** |
| x = ___ | **−10** |
| Verify: −10 + 7 = ___ | **−3 ✓** |

Explain verify: Checking in the original guards against errors introduced in the solving steps. A derived equation might have a mistake; the original has not been changed.

**Worked Example 2 — 2x − 5 = 9:**

| Blank | Answer |
|---|---|
| Add ___ to both sides | **5** → 2x = **14** |
| Divide by ___ | **2** → x = **7** |
| Verify: 2(7)−5 = ___ | **9 ✓** |
| Undo ___ first, then ___ | **subtraction; multiplication** |

**x/4 = −3:** Multiply by 4. x = **−12**. Verify: −12/4 = **−3 ✓**

**Practice table:**

| Equation | Solution | Verified |
|---|---|---|
| x − 9 = −4 | **x = 5** | 5−9=−4 ✓ |
| 3x = −18 | **x = −6** | 3(−6)=−18 ✓ |
| x/−2 = 5 | **x = −10** | −10/−2=5 ✓ |
| −4 + x = 7 | **x = 11** | −4+11=7 ✓ |

### Retrieval Check — Section 1

| Question | Answer |
|---|---|
| 1. 5x = −35 | x = **−7**. Verify: 5(−7)=−35 ✓ |
| 2. x/3 + 4 = 1 | x/3=−3 → x=**−9**. Verify: −9/3+4=−3+4=1 ✓ |
| 3. Student gets x=5 for x−7=12 | Error: subtracted 7 instead of adding. **x = 19**. Verify: 19−7=12 ✓ |
| 4. What does "verify" mean? | Substitute the answer back into the original equation and confirm both sides are equal. Use the original, not a derived step, in case an error crept in. |
| 5. (Stretch) −x = 4 | Multiply both sides by −1. **x = −4.** The variable represents a negative number. |

## Section 2 — Multi-Step Equations

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Distribute | Multiply each term inside a bracket by the factor outside | 3(x+4) = 3x+12 |
| Collect like terms | Combine terms with the same variable and exponent | 3x+5x = 8x |
| Multi-step equation | Equation requiring more than one step before isolating the variable | 3(x+4) = 21 |

### Guided Notes

| Blank | Answer |
|---|---|
| Brackets must be ___ first | **expanded/distributed** |
| Like terms must be ___ first | **collected/combined** |

**Worked Example 1 — 3(x+4) = 21:**

| Step | Work |
|---|---|
| Distribute | 3x + **12** = 21 |
| Subtract 12 | 3x = **9** |
| Divide by 3 | x = **3** |
| Verify: 3(**3**+4) = 3(**7**) | = **21 ✓** |

Explain: must distribute first because the 3 applies to the whole bracket. Dividing by 3 first would only cancel the leading factor, leaving 3 × (bracket) incorrectly simplified.

**Worked Example 2 — 5x − 3 = 2x + 9:**

| Blank | Answer |
|---|---|
| Subtract 2x: ___ − 3 = 9 | **3x** |
| Add 3: ___ = 12 | **3x** |
| x = ___ | **4** |
| Verify: 5(4)−3=17 and 2(4)+9=17 | **Equal ✓** |

Moving 5x to right instead: −3 = −3x + 9 → −12 = −3x → x = 4. Same answer — direction doesn't matter.

**Worked Example 3 — 4(x−2) = 2x + 6:**

| Blank | Answer |
|---|---|
| Distribute: ___x − ___ = 2x+6 | **4x − 8** |
| Move variable: ___x = ___ | **2x = 14** |
| x = ___ | **7** |
| LHS: 4(7−2)=4(5) | = **20**; RHS: 2(7)+6 = **20 ✓** |

**Misconception:**
- 3(x+4) = 3x + **12**
- −2(x−5) = **−2x + 10**

**Practice:**
1. 2(3x−1)=16 → 6x−2=16 → 6x=18 → **x=3**
2. 5x+3=3x−7 → 2x=−10 → **x=−5**
3. −4(x+2)=2x−8 → −4x−8=2x−8 → 0=6x → **x=0**

### Retrieval Check — Section 2

| Question | Answer |
|---|---|
| 1. 3(2x−4)=18 | 6x−12=18 → 6x=30 → **x=5**. Verify: 3(6)=18 ✓ |
| 2. 6x−5=4x+3 | 2x=8 → **x=4**. Verify: 24−5=19=16+3 ✓ |
| 3. 2(x+3)=−(x−9) | 2x+6=−x+9 → 3x=3 → **x=1**. Verify: 2(4)=8; −(1−9)=8 ✓ |
| 4. x+5=10 shortcut | Works here because both sides can be divided by 2. Could fail if the equation had additional terms that couldn't cleanly be divided first. |
| 5. (Stretch) | 3x+6−2x+2=5x−5+3 → x+8=5x−2 → 10=4x → **x=5/2**. Verify: LHS=21/2, RHS=21/2 ✓ |

## Section 3 — Equations with Rational Coefficients

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Rational coefficient | A fractional or decimal coefficient | (2/3)x or 0.3x |
| LCD | Least common denominator — smallest number divisible by all denominators | LCD of 3, 4, 6 = 12 |
| Clear the fractions | Multiply every term by LCD to eliminate all fractions | ×6 turns x/3+1/2=5/6 into 2x+3=5 |

### Guided Notes

**Worked Example 1 — x/3 + 1/2 = 5/6:**

| Blank | Answer |
|---|---|
| LCD of 3, 2, 6 | **6** |
| 6(x/3) + 6(1/2) = 6(5/6) | **2**x + **3** = **5** |
| Solve: x = ___ | **1** |
| Verify: 1/3 + 1/2 = 2/6 + 3/6 = 5/6 | **✓** |

Explain: Multiplying (x/3) by 6 gives (6/3)x = 2x — the fraction cancels. Doing this to every term simultaneously preserves the equation's balance.

**Worked Example 2 — (2/3)x − 4 = x/4:**

| Blank | Answer |
|---|---|
| LCD of 3 and 4 | **12** |
| 8x − 48 = 3x | *(12×2/3=8; 12×4=48; 12×1/4=3)* |
| Move: 5x = 48 | x = **48/5** |

**Worked Example 3 — 0.3x + 1.2 = 0.9:**

| Blank | Answer |
|---|---|
| Option 1 (×10): 3x+12=9 → x = ___ | **−1** |
| Option 2: 0.3x = 0.9−1.2 = ___ | **−0.3** → x = **−1** |

**Practice:**
1. x/2−x/3=1/6: LCD=6. 3x−2x=1 → **x=1**
2. (3/4)x+2=(1/2)x+5: LCD=4. 3x+8=2x+20 → **x=12**
3. 0.5x−3=0.2x+0.6: ×10: 5x−30=2x+6 → 3x=36 → **x=12**

### Retrieval Check — Section 3

| Question | Answer |
|---|---|
| 1. x/4 + x/6 = 5/12 | LCD=12: 3x+2x=5 → 5x=5 → **x=1** |
| 2. (2/3)x−1/2=(5/6)x | LCD=6: 4x−3=5x → **x=−3** |
| 3. 0.4x+1.8=0.6x−0.6 | ×10: 4x+18=6x−6 → 24=2x → **x=12** |
| 4. Why multiply all terms? | Multiplying every term by the same number is the multiplication property of equality — same operation on both sides maintains balance. |
| 5. (Stretch) (x+1)/3−(x−2)/4=1 | LCD=12: 4(x+1)−3(x−2)=12 → 4x+4−3x+6=12 → x+10=12 → **x=2** |

## Section 4 — Solving and Graphing Linear Inequalities

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Inequality | Statement that two expressions are not equal; uses <, >, ≤, ≥ | 3x + 2 > 8 |
| Solution set | All values that satisfy an inequality | x > 2 (infinitely many values) |
| Open circle | Endpoint NOT included (< or >) | x > 3: open circle at 3 |
| Closed circle | Endpoint IS included (≤ or ≥) | x ≥ 3: closed circle at 3 |
| Flip the sign | Reverse the inequality direction | When dividing by a negative |

### Guided Notes

**Worked Example 1 — 2x + 3 > 7:**

| Blank | Answer |
|---|---|
| 2x > 7−3 | 2x > **4** |
| x > ___ | **2** (no flip — divided by +2) |
| Graph: open circle at ___, arrow ___ | open circle at **2**, arrow **right** |
| Verify x=3: 2(3)+3=9 > 7? | **Yes ✓** |
| Verify x=1: 2(1)+3=5 > 7? | **No ✗ (correct — not in solution)** |

**Worked Example 2 — −3x + 6 ≤ 15:**

| Blank | Answer |
|---|---|
| −3x ≤ 15−6 | −3x ≤ **9** |
| Divide by −3 — FLIP: x ___ ___ | x **≥** **−3** |
| Graph: closed circle at ___, arrow ___ | closed circle at **−3**, arrow **right** |

**Misconception:** 6>2 ÷ by −2: −3 **<** −1. Direction changed: **yes**. (The ">" became "<".)

**Sign flip visualized:** 3 > 1. Multiply by −1: −3 **<** −1 (circle **<**). Positions swap sides relative to zero.

**Practice:**
1. 4x−1<11 → 4x<12 → **x<3** (open circle at 3, arrow left)
2. −2x+5≥1 → −2x≥−4 → **x≤2** (flip; closed circle at 2, arrow left)
3. 3(x−2)≤2x+1 → 3x−6≤2x+1 → **x≤7** (closed circle at 7, arrow left)

### Retrieval Check — Section 4

| Question | Answer |
|---|---|
| 1. 5x+2>17 | 5x>15 → **x>3** (open circle at 3, arrow right) |
| 2. −4x≤20 | x≥−5 (flip) (closed circle at −5, arrow right) |
| 3. 3−2x<x+9 | −3x<6 → **x>−2** (flip) (open circle at −2, arrow right) |
| 4. Why flip for multiply/divide negative, not for subtract negative? | Multiplying/dividing by negative reverses the position of all numbers relative to zero. Subtracting negative (= adding positive) shifts all numbers by the same amount — order is preserved. |
| 5. (Stretch) −3x+9>0 | −3x>−9 → **x<3** (flip). Student got x>3 — forgot to flip when dividing by −3. |

## Section 5 — Problem Solving with Equations

### Vocabulary

| Term | Definition | Example |
|---|---|---|
| Define the variable | Specify what x represents with units | "Let h = hours of work" |
| Translate | Convert words into a mathematical expression or equation | "more than" = + |
| Interpret | Explain the solution in the context of the original problem | "The homeowner can have at most 5 hours of work." |
| Reasonable answer | Check that the answer makes sense in context | Negative hours of work is not reasonable |

### Guided Notes

**Worked Example — Plumber:**

| Blank | Answer |
|---|---|
| Translate: 75+50h ___ 350 | **≤** |
| 50h ≤ ___ | **275** |
| h ≤ ___ | **5.5** |
| At most ___ full hours | **5** (whole number only) |
| Check: 75+50(5) = ___ ≤ 350 | **325 ≤ 350 ✓** |

"At most" means ≤ — the spending can equal $350 (not just be less than it).

**Worked Example 2 — Consecutive even integers sum to 48:**

| Blank | Answer |
|---|---|
| Next two: ___ and ___ | n+**2** and n+**4** |
| Equation: n + ___ + ___ = 48 | n+(n+2)+(n+4)=48 |
| 3n + ___ = 48 → n = ___ | 3n+**6**=48 → n=**14** |
| Integers: ___, ___, ___ | **14, 16, 18** |
| Verify: 14+16+18 = ___ | **48 ✓** |

**Alberta context — Hot chocolate:**
2.5c − 75 > 0 → c > **30**. They must sell more than **30** cups.

### Retrieval Check — Section 5

| Question | Answer |
|---|---|
| 1. Double, decrease by 9, equals 15 | 2x−9=15 → 2x=24 → **x=12**. The number is 12. |
| 2. Two shares, one $20 more, total $90 | x+(x+20)=90 → 2x=70 → x=35. **$35 and $55.** |
| 3. 68 marks + assignment ≥ 75 | 68+m≥75 → **m≥7**. She needs at least 7 marks. |
| 4. Why is interpret important? | The algebraic answer (a number) may not directly answer the question. Units, context, and whole-number restrictions all require the interpret step. |
| 5. (Stretch) Two cars catching up | Car 1: d=80t. Car 2: d=100(t−1.5). Equal: 80t=100t−150 → 20t=150 → t=7.5 h. Car 2 catches up **7.5 hours after Car 1 departs** (6 hours after Car 2 starts). |

## Unit Synthesis

### Part A — Key ideas

| Question | Answer |
|---|---|
| 1. Steps for multi-step equation | (1) Distribute brackets. (2) Collect like terms each side. (3) Move variable terms to one side. (4) Move constants to other side. (5) Divide to isolate. (6) Verify. |
| 2. When to flip inequality sign | When multiplying or dividing both sides by a **negative** number — negative multiplication reverses the order of the number line. |
| 3. Open vs. closed circle | Open: endpoint NOT included (< or >). Closed: endpoint IS included (≤ or ≥). |
| 4. Verifying equation vs. inequality | Equation: substitute and confirm LHS=RHS. Inequality: choose a value from the solution set, confirm it satisfies; choose one outside the set, confirm it doesn't. |

### Part B — Solve from memory

**a) 3(2x−1) − 2(x+4) = 5**

> 6x−3 − 2x−8 = 5 → 4x−11=5 → 4x=16 → **x=4**
> Verify: 3(7)−2(8)=21−16=5 ✓

**b) −(2/3)x + 4 ≤ (1/6)x − 2**

> LCD=6: −4x+24 ≤ x−12 → −5x ≤ −36 → **x ≥ 36/5** (flip)
> Graph: closed circle at 36/5 (=7.2), arrow right

### Part C — Pre-Knowledge Check reflection

- 3x+5=14: 3x=9 → **x=3**. Verify: 9+5=14 ✓
- Inequality changes: same steps BUT sign flips when dividing by negative; solution is a range, not one value.
- Special cases: **one solution** (2x=6 → x=3); **no solution** (2x+3=2x+7 → 3=7, contradiction); **infinitely many** (2x+4=2(x+2) → 4=4, always true).
